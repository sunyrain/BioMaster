# EQIR V3 数学新颖性审计（2026-08-14）

## 裁决

截至本审计时，EQIR V3 是**预注册的候选学习过程**，不是已经成立的核心算法创新。Stage 0 尚未完成，Stage 1 未获准实现或训练，总声明保持 `NO_FULL_SOTA_CLAIM`。

## 1. 概率残差损失的代数等价性

冻结基模型给出 logit `b` 和概率 `p₀ = σ(b)`；结构头给出 logit 修正 `a·rθ`，最终概率为 `pθ = σ(b + a·rθ)`。目标修正定义：

- 伪结局：`u = y − p₀`
- 概率增量：`Δθ = pθ − p₀`

于是严格有：

`u − Δθ = (y − p₀) − (pθ − p₀) = y − pθ`

因此 `Huber(u, Δθ)` 与 `Huber(y, pθ)` 的逐样本误差完全相同。冻结基 offset 会限制结构头只能作增量修正，但“把标签写成概率残差”本身没有产生新的统计目标，也不能单独作为算法贡献。

## 2. 各组成部分的创新等级

| 组成部分 | 数学/实现性质 | 当前等级 |
|---|---|---|
| 冻结的 DTIAM–BioMaster 基础 offset | 传统凸组合与 stacking | 强非创新基线 |
| 小型结构 MLP | 常规监督学习器 | 非创新组件 |
| 概率残差重写 | 与最终概率误差代数等价 | 不构成独立创新 |
| `a(t)` 标签独立二值资格 | 基于冻结 QC 的确定性选择 | 数据/证据路由机制 |
| `a(t)=0` 时 bitwise 精确回退 | 嵌套函数不变量 | 可审计工程约束 |
| 靶点查询与老药查询 pairwise loss | 已有 ranking/retrieval 方法 | 非创新组件 |
| 双方向、双冷轴、置换与 bootstrap 晋级门槛 | 面向老药新靶点任务的联合验证 | 评价与选择机制贡献 |

## 3. 仍可能形成算法贡献的最小整体

EQIR 不能以“新网络层”“残差融合”“双向排序”或“缺失模态回退”任一单项主张新颖性。唯一仍可检验的候选差异是以下不可拆分整体：

1. 结构资格只由与 pair 标签独立的冻结受体/口袋证据决定；
2. 结构学习器嵌套在最强的交叉拟合非结构基模型之上；
3. 无资格区域与基函数逐位相同，而不是学习插补；
4. 模型选择同时约束“靶点找药”和“老药找靶点”的增量价值；
5. 晋级必须同时通过同源冷靶点与骨架冷药物两个聚类轴的统计门槛。

这更接近“带结构证据选择的双查询增量学习过程”，而不是一种全新的神经网络架构。即使 Stage 1 性能通过，也只能先称为候选算法证据；是否可形成论文级算法创新，还取决于完整消融是否证明上述联合约束不可替代，以及同数据最近方法对照是否通过。

## 4. 证伪规则

- Stage 0 任一门槛失败：结构增量路线停止，EQIR 不进入训练。
- Stage 1 仅超过单一 BioMaster 或仅提高 micro-AUPRC：失败。
- 去掉资格、精确回退或任一查询方向约束后性能不变：联合机制新颖性论证显著削弱。
- 五种子、靶点同源簇 bootstrap、药物骨架 bootstrap 或老药内置换任一失败：不得宣称算法创新。
- 未完成锁定确认折、同数据比较与外部/来源隔离验证：不得宣称 SOTA。

## 5. 当前诚实表述

当前已经成立的是数据范围治理、证据路由、双方向老药重定位任务定义和严格冷启动评价体系。当前尚未成立的是核心模型算法创新。模型层面只能说：已提出并事前冻结一个可被严格证伪的 EQIR 候选学习过程，正在先验证结构证据是否具有无泄漏增量价值。
