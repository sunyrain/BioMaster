# 64靶点 / 512对 SPR候选设计（2026-09-09）

已生成独立的分子—靶点清单及内部/角色盲化工作簿。**这是可复核的计算设计，不是已通过实验放行的高命中清单。** 原32靶点冻结包未被覆盖。本次没有训练新模型。

## 1. 预算与设计

| 项目 | 原32靶点方案 | 本次64靶点方案 |
|---|---:|---:|
| 高排候选 | 320（每靶点10） | 320（每靶点5） |
| 中排候选 | 96 | 64 |
| 低排背景 | 64 | 64 |
| 参考阳性对照 | 32 | 64 |
| 合计 | 512 | 512 |
| 未知候选对 | 480 | 448 |
| 候选药物实体 | 120 | 120 |

本次含对照共181种分子实体，不能把120当作全部备料数。512指不同分子—靶点配对，不包括浓度梯度、重复注射、空白/溶剂校正、阳性复测和确认实验。64套蛋白体系增加建立与质控成本，配对数不增加不意味着总费用不增加。

每靶点5高+1中+1低+1对照。扩覆盖有利于探索更多靶点，但单靶点高排样本减半；每靶点只有1个中排和1个低排，不能据此稳定估计该靶点富集率。低排背景不等于已知不结合的阴性药。

## 2. 靶点变化与模型来源

保留原32靶点。相对上轮64靶点草案，实际排除已知关系后，JAK1、PTGS1、VDR分别仅剩4、3、2个高排候选，不够每靶点5个。因此换为JAK2、CA2、RXRA。替换满足候选与设计约束，**不表示对应疾病价值更高，也不表示同家族靶点可互换疾病结论**。

新增32靶点：DPP4、HSD11B1、HMGCR、ACHE、BCHE、MAOA、MAOB、COMT、FAAH、PTGS2、CA2、ALOX5、EPHX2、PDE4D、PDE9A、PDE10A、PARP1、PARP2、EZH2、DHODH、CTSK、CTSS、PPARD、RXRA、MMP13、ESR2、F2、F10、JAK2、BTK、MAPK14、ESR1。

52个核心靶点沿用历史冻结 `independent_validation_rank_score` 在完整384靶点中的药物内排名；高排≤20，中排80–180，低排>250。12个扩展靶点沿用历史FULL_FIT生化路由排名/367；高排≤30，中低区间相同。没有重排为rank/64，也不能将这些候选归因于9月6日selected模型或尚未完成的ContextPocket。

两种来源应分别汇报命中率，不能将混合结果当作单一模型无偏性能。此次设计使用既有模型排序探索新配对；不是模型独立测试集的重新定义。

## 3. 选择和审查规则

先排除本地ChEMBL各标签已知精确配对、KIRHub配对、FULL_FIT训练精确配对、已知MoA冲突和已有BindingDB/GtoPdb快照命中。快照排除不等于论文、专利或当前全部数据库查新完成。

进一步排除上一轮明确识别的两个前药实例enalapril、serdexmethylphenidate，以及原化学风险启发式分数>1的配对。**这不是完整前药/活性物种审查，也不是化学干扰检测通过。**

联合优化满足：120种候选药，每药2–6个靶点；不同实体不重复连接骨架标识；每个非空Murcko骨架最多5种候选药，同靶点高排中同骨架最多2个；已标注激酶药最多30种。中/低组对高组的配对加权平均分子量差≤40 Da、cLogP差≤0.5。实际均值：高组345.72 Da/2.472，中组341.28 Da/2.301，低组363.78 Da/2.608。这只限制整体化学偏差，不是逐靶点匹配或因果校正。

优化器在设定相对间隙0.001内完成（实际0.000353）；检查了取整后的约束。优化目标是排序与设计惩罚，不是实测命中率或临床收益。

## 4. 最关键的结果：证据缺口仍然大

对选定候选追加了同靶点ChEMBL37阳性/阴性参考的Morgan指纹相似度审查（radius=2、2048位、含手性）。它在选择后计算，使用全部本地参考数据，**不是留出测试、预测概率或独立验证**。

320个高排候选中：

- 274个最近阳性参考Tanimoto<0.4，标为低阳性化学支持待审；阈值是审查启发式，不能推导不结合概率。
- 2个与阴性/不活性参考相似度≥0.7且超过最近阳性相似度，优先检查原始实验适用性。
- 其余44个也仍待文献及实验适用性检查，不能称为44个已确认好候选。

因此本轮证明的是**64靶点方案可以排出满足约束的512对**，尚未证明“每个靶点都有5个值得投入的高质量候选”。不要为了凑64靶点把缺乏支持的配对自动放行。具体相似分子的身份、参考实验及标记见内部主表，靶点汇总见`TARGET_HIGH_SUPPORT_REVIEW.csv`。

对照方面：28个有Kd记录、30个仅有Ki而无Kd、6个仅IC50（AKR1B1、TPH1、NT5E、BCHE、ALOX5、PDE9A）。混合端点pChEMBL不能当SPR Kd。ALOX5–Zileuton、PPARD–GW501516保留了本地冲突标签和外部参考链接，均未解决冲突，必须先核验。其余对照也需验证在选定构建与SPR体系可用。

64个构建均待确认明确边界/异构体/活性状态。MAOA、MAOB、FAAH、PTGS2、ALOX5、EZH2、DHODH、F2、F10、COMT另列特殊体系复核标记；表内构建文字是讨论起点，不能直接当采购规格或实验SOP。

## 5. 下一步怎样花实验预算

先完成64靶点的蛋白构建和参考对照核验，再对320个高排配对逐一填写：分子实际测试物种、现有结合证据、已知阴性证据及条件、靶点疾病关联、希望的激动/抑制方向、结果可解释性。TxGNN/Open Targets能提供疾病线索，但不能替代分子直接结合和作用方向验证。

依据这轮核验决定保留、替换或暂停具体靶点。若希望改成证据优先候选，应另存版本并重新报告排序组变化；不能把后验筛掉的不利结果算进原始盲测性能。当前不预设所有64靶点都会最终通过。

清单分为4个物流批次，每批16靶点/128对，仅便于整理，**尚不是优先开做顺序**。建议在体系质控后按证据及可解释性确定小批启动顺序；实际重复和确认消耗必须在512配对之外另计，或由实验团队明确调整总预算。此处没有给出未经数据支持的命中率保证。
