# DTI模型的相关性、共同错误与实验决策：研究方案

日期：2026-09-18。状态：**研究设计草案，尚未预注册；未启动本方案中的新增训练或湿实验。**

2026-09-20实施更新：模型权重登记、五种训练划分、87项分阶段受控拟合清单及评估协议已落地，见[准备交付报告](BIOMASTER_DTI_RESEARCH_PREPARATION_20260920_ZH.md)和[执行协议v1](protocols/DTI_RELIABILITY_PROTOCOL_20260920_ZH.md)。新增训练尚未启动，下文保留原探索方案及其证据时间点。

本方案承接[七模型分歧调研及复核](BIOMASTER_MODEL_DISAGREEMENT_LITERATURE_20260918_ZH.md)。既有计算测试已被多次查看，属于探索证据。SPR384实验结果是否已被查看、用于调整模型，尚待确认；在确认前不称其为未揭盲验证集。

## 1. 文章要回答的核心问题

**不同DTI模型在什么条件下共享真实结合信号、共享错误或提供互补信息？这些差异能否帮助研究者在有限实验预算下作出更好的选择？**

建议工作题目：**药物—靶点预测中的共同信号、共同错误与实验决策**。

英文工作题目：*Shared signals, correlated errors, and experimental decisions in drug–target prediction*。

文章应交付三个相互支持的成果：可复用的评估资源；经控制实验支持的科学判断；实际筛选中可检验的使用原则。能否成为领域重要文章，取决于证据是否改变模型评估和使用方式，以及资源能否被其他团队复用，不能由模型数量或图表数量保证。

### 已有研究与我们需要建立的增量

- 2025年已有在FDA药物上比较七种靶点预测工具的工作。因此“比较多个模型”和“推荐不一致”本身不足以构成核心新意。[A precise comparison of molecular target prediction methods](https://doi.org/10.1039/d5dd00199d)。
- 单实体偏差、划分偏差和蛋白表征消融已有系统研究。我们应检验这些因素能解释多少**共同错误和双向选择性失败**，而非将偏差的存在当成首次发现。[All That Glitters Is Not Gold](https://doi.org/10.1021/acs.jcim.5c00395)。
- DTI置信估计及实验筛选已有EviDTI；亲和回归也已有多种不确定性方法的比较。“用分歧表示不确定性”需要和这些思路及简单近邻基线比较。[EviDTI](https://doi.org/10.1038/s41467-025-62235-6)、[Uncertainty quantification enables reliable deep learning](https://doi.org/10.1038/s41598-025-27167-7)。
- 2026年的DrEval将可复现框架、实体均值基线、跨数据集测试和消融结合，是可借鉴的研究组织方式。其任务是**药物—细胞响应**，不能把结论直接移植为蛋白—分子DTI结论。[DrEval](https://doi.org/10.1038/s41467-026-72903-w)。

本方案的潜在增量是：在同一体系中连接**预测关系、错误关系、受控原因和实验效用**。这仍需逐项结果与进一步文献对照支持，不预先宣称“首次”。

## 2. 相关性究竟研究什么

| 层次 | 要比较的对象 | 能回答的问题 | 不能直接推出的结论 |
|---|---|---|---|
| 分数关系 | 同一终点、同方向输出；必要时用验证集校准 | 数值响应和校准是否接近 | 异构原始分数Pearson低，不等于推荐不同 |
| 排名关系 | 同一查询、相同候选集合上的秩 | 模型是否推荐同一批对象 | 一致不等于正确，不一致不等于互补 |
| 错误关系 | 有实验标签的共同假阳性、共同假阴性及排序错误 | 多模型是否在同一位置失败 | 不能将无记录关系认定为假阳性 |
| 条件关系 | 按终点、家族、近邻程度、数据来源分层后的关系 | 整体相关是否主要由样本构成或先验造成 | 条件相关不是因果证明 |
| 训练来源关系 | 标签来源、预训练语料、表征、检查点谱系 | 多个模型是否真的提供独立证据 | 七个名字不等于七份独立证据 |
| 表征关系（可选） | 相同样本上的隐藏表示、CKA/RSA | 表征相似是否对应错误相似 | 相似表征不证明相同机制，也不保证相同决策 |

**主文优先研究排名、错误和条件关系。** 表征可视化放在已有结果提示其能解释现象时开展，避免把主线扩成无边界的模型分析合集。

有标签时至少区分四种情况：

| 现象 | 待检验解释 | 实际意义 |
|---|---|---|
| 排名相似且都较准确 | 共享有效信号 | 可能可以用较便宜的模型替代 |
| 排名相似但共同犯错 | 共享偏差或共同盲区 | 简单多数票可能增加错误信心 |
| 排名不同但各有独立正确发现 | 存在有用互补 | 有机会通过验证确定融合或探索策略 |
| 排名不同且一方主要错误 | 弱模型或失配输入引入噪声 | 增加该模型可能降低筛选效率 |

## 3. 六组研究问题及证伪方式

| 研究问题 | 主要实验 | 什么结果会削弱假设 |
|---|---|---|
| Q1：推荐分歧有多大，在哪些任务更明显？ | 双向逐查询相关、TopK重合、家族/终点/适用范围分层；同模型多种子对照 | 分歧主要被版本、候选分母或输入错误解释；或不超出训练随机性 |
| Q2：一致是否意味着正确？ | 标签分层的共同错误矩阵；高排名共识的实测失败；与各模型错误边际保持一致的参照比较 | 共识的有效增益在严格外部测试中稳定成立，未见所假设的额外共同错误 |
| Q3：模型学到多少配对选择性？ | 单药物、单蛋白、加性实体先验、靶点内化学近邻基线；同药多靶和同靶近似药物实测面板 | 完整模型稳定明显超越这些基线，置换正确配对会损害对应任务表现 |
| Q4：什么改变了分歧与正确性？ | 同数据/划分下控制终点、样本量、采样、目标函数、表征和种子 | 推测原因的效应在控制实验中消失，或只在一个家族成立 |
| Q5：分歧能否提供额外的错误预警？ | 在验证集确定风险模型，外部比较“分数+近邻+覆盖”等基线与加入分歧后的风险—覆盖曲线 | 加入分歧不改善误差识别，或只在已见开发集改善 |
| Q6：新增模型是否值得付出计算和实验成本？ | 同预算的最佳单模型、近邻基线、简单融合、互补选择；测独有推荐的真实增益 | 融合不胜出，或更便宜的单模型/基线达到相同有效命中 |

Q1建立现象；Q2/Q3是科学中心；Q4提供原因证据；Q5/Q6检验使用价值。即使Q5或融合的结果为阴性，只要证据充分，仍能明确指出何时不应依赖模型投票。

## 4. 本项目已有资产与证据边界

以下为现有冻结文件的口径，不代表后台今天已完成的全部推理覆盖：

| 资产 | 已核对规模 | 本研究可利用之处 | 边界 |
|---|---:|---|---|

| 七模型冻结共同快照 | 8靶点×719药物，5,752对 | 统一方向与身份后已确认分歧 | 早完成的较短蛋白集合；不能代表全部靶点 |

| A/B训练成员 | A 337,570对；B 1,116,270对 | 数据和任务变化的受控比较基础 | A/B终点和组成不同，不能将差异全归于数量 |
| 明确失活 | A/B各105,368对 | 识别实测困难阴性的共同误报 | 两组相同计数不能相加为独立阴性数 |
| Palinova训练消融 | A/B分类、排序、回归组合；另有30次assay-aware拟合 | 重用已完成的目标函数、采样、多种子实验 | 既有测试结果已查看，重分析是探索 |

| 七模型共同标签面板 | 378对，103阳性/275阴性 | 初步错误关系和异常检查 | 稀疏、反复查看，不能作为新确认性测试 |
| 其中A/B关系未见层 | 141对，33阳性/108阴性 | 描述A/B成员重叠的影响线索 | 非所有公共模型未见；非分子/靶点冷启动 |
| SPR384 | 已交湿实验的候选384对，对照另计 | 原方案的实测结果和选择池内比较 | 原流程预选；揭盲状态、有效测量数尚待核实 |

当前七通道包含分类、方向排序、口袋相似度等输出，并非七个同定义的Kd回归器。主分析须明确“用于同一DTI决策的模型”；连续亲和分析只使用有该输出语义的模型。Nesso binder与连续头、DTBind occurrence与亲和分支分别登记，不能挑表现好的头后再宣称为预设主结果。

现有一个值得追踪的现象：在五模型共同目录上，DTIAM A与ReTargetMap固定靶点排药物的平均Spearman约0.002，反向固定药物排靶点约0.248。它提示双向任务必须分开，但不证明某一模型学到了或未学到真实机制。详见[审计结果](../outputs/model_disagreement_literature_20260918/AGREEMENT_SUMMARY.csv)。

## 5. 两条模型轨道、三层数据证据

### 模型轨道

**部署轨道：** 冻结现有公共/生产版本及官方预处理，回答“用户下载后实际得到什么”。记录训练重叠已知/未知、覆盖、失败、耗时和硬件。这里不能将模型间差异直接归因于架构。

**控制轨道：** 在可重训模型上统一监督成员、划分、训练预算和调参规则；表征、目标函数作为明确的干预因素。至少使用已有三种子，报告完整模型与简单双方/单方基线。训练预算还须报告样本曝光和收敛状态，不能把相同epoch视为相同计算量。

### 数据证据

1. **无标签部署矩阵：** 描述相关性、排名稳定性、覆盖及输入敏感性，不计算虚构准确率。
2. **独立实测面板：** 优先同assay/同系列、同药多靶的系统测量，保留明确失活、删失范围和测量条件；覆盖多种蛋白家族，并留出来源独立的测试。配对未见、骨架未见、蛋白家族未见和双侧未见是不同任务，不能混成一个“外部集”。
3. **湿实验验证：** 先完整报告SPR384有效、无效和待复测状态。在其选择范围内检验预先冻结的分数与分层。若要公平比较各模型独有TopK，需要额外独立验证覆盖，或一个已有充分测量的公共面板。

来源独立不能只看文件名或数据库：ChEMBL/BindingDB可能复用同一原始论文或专利。新下载月份也不等于新发表、未入训练的数据。划分需要追踪原始document/assay、分子身份、序列/构建体及近邻。

Kd、Ki、IC50、EC50分别保留。Kd提供直接结合终点，Ki和功能终点单列解释；同蛋白名称但不同突变、结构域、复合物不直接合并。浓度上限内未见信号只在该检测能力下定义失活；无有效响应的坏蛋白/技术失败不能计为真阴性。

## 6. 指标与统计设计

### 排名与稳定性

- 主报告逐靶点排药物、逐药物排靶点的Spearman和TopK重合曲线。预设一个实际决策K为主终点，其他K为敏感性分析；K应与待比较实验预算和候选集合规模对应。
- Kendall tau-b用于并列秩敏感性分析。常量输出的相关系数记为未定义，并报告退化率，不填成0或完全一致。TopK边界同分报告随机打破并列的期望或固定可审计规则。
- 对n个共同候选独立均匀随机各选k个，期望交集为k²/n。这只是无信息参照，不能替代保持家族、先验和缺失模式的条件参照。
- 同模型多种子、可解释的输入预处理变化作为稳定性对照；它们不是跨模型分歧的数学下限。
- 全模型共同覆盖用于严格横向比较；两两共同覆盖作为补充，明确不同分母。推理失败和不支持的目标单独报告，并评价端到端可用覆盖，避免只比较最容易的交集。

### 错误关系

- 对阳性和明确失活分别建立共同漏报/共同误报表，报告两模型的各自错误率和共同错误率。阈值在验证集按预设目标确定；测试分布改变后不保证仍达到同样召回率。
- 比较共同错误是否超出相应分层内边际错误率所期待的程度，并给出不确定区间。零事件或极低基率下，相关系数可能不稳定或不可定义。
- 原始残差相关会受到共享真值、类别比例和终点尺度影响；不能单独用它证明共享偏差。配合类别、查询、来源和近邻分层，以及受控消融。
- 连续亲和的成对排序只比较终点及条件可比、测量差异可分辨的对象。使用重复测量估计实验排序自身的稳定性；落在测量不确定范围内的顺序差异单独报告。

### 配对特异性与控制实验

将分数概念性拆为“药物倾向+蛋白倾向+配对相关部分”，比较扣除实体主效应前后的模型关系。完整均衡矩阵可以做双向中心化描述；稀疏矩阵需要交叉拟合的实体基线，不能把缺失格补零。所有使用实验标签的基线只从训练侧学习；输出矩阵的中心化仅是描述，不证明分离出了真实物理相互作用。

必须包括：药物单侧、蛋白单侧、加性实体先验、靶点内化学近邻、充分调参的树模型，以及全模型。结合保持输入边际分布的家族内/家族间置换；输入置换和重训消融回答的问题不同，均应注明。

A/B数量与质量的实验先在共同目标、类别和化学覆盖下构造匹配子集，再比较添加同终点数据、添加不同终点数据、采样策略的作用。不能只比较A全量和B全量就宣称“终点噪声造成下降”，也不能把现有150轮换上限直接等同永久删数据。

### 核心准确性与效用指标

- **查询内宏AP及固定预算有效命中数**优先，分别报告两个方向。按查询等权与按真实部署频率加权回答不同问题，须预设。
- 单类别查询不得悄悄丢弃：报告总数、组成和适用指标；全阴性查询特别适合分析误报。未知标签不进入阴性分母；只在有足够完整测量的面板上计算相应TopK精度/召回。
- 校准、风险—覆盖曲线和明确失活FPR作为配套指标。将候选按分歧丢弃后剩余更少，必须在相同保留量/实验预算下比较，防止只展示精度提高。
- 比较最佳单模型、近邻基线、验证集确定的简单融合和互补策略。模型选择、融合权重、拒绝阈值都使用内层验证，外部测试只用于最终评价。
- 以独立查询/目标家族/化学簇为统计单位设计区间；同药跨多靶等交叉依赖采用相应聚类重采样，并做敏感性分析。报告实际独立单位数，不能将27万相关配对当作27万个独立实验。
- 少量预设主比较与探索性大规模比较分开；后者控制多重比较。功效规划根据独立靶点、预期命中差、查询内相关和技术失败率确定，不凭“384”这一总数宣称充分。

## 7. SPR384怎样进入论文

必须保存原始候选清单、原始入选规则、模型版本、分数快照、选样和结果访问时间。已有384无需为论文叙事而删掉失败或不利结果。

- 如果结果尚未查看：可以在揭盲前冻结剩余分析，但已有计算探索仍需披露。
- 如果已查看部分结果：已见部分作为探索；只有确实未用于选择/调整的保留集才可能承担确认性检验。不能通过重新命名划分恢复独立性。
- 当前状态未确认：暂按结果访问情况未知处理。

384能回答原方案实际表现、该选择池内不同排序和分歧分层的关系。它不能回答某模型未被测量的独有Top10究竟有多少命中，也不能估计整个720×384目录的召回率。

若后续确有额外实验条件，优先用能区分假设的样本：高共识高排名、各模型独有高排名、模型严重分歧、适用范围匹配的随机参照。分层概率和纳入规则在结果前确定，记录重叠候选并按唯一配对计费；阳性对照、空白和复测另计。只从“各模型TopK并集”选样时，推断对象仍受该并集限制，不能靠事后加权推到没有纳入概率的全目录。

此处为设计选项，未分配额外湿实验额度，也未修改正在执行的实验表。

## 9. 执行顺序与停止条件

| 阶段 | 优先产物 | 完成/升级条件 |
|---|---|---|
| P0：版本与证据审计 | 模型登记表、成员/来源/分数哈希、终点字典、已查看数据清单、SPR访问状态 | 解决方向、身份、版本和官方例子重放问题，冻结分析协议 |
| P1：重用现有结果 | 双向相关、共同错误、多种子稳定性、强基线和分层图 | 确认现象不只是实现错误、覆盖偏差或随机性；不需要先新增昂贵模型 |
| P2：补独立标签面板 | document/assay及相似性审计、未知重叠标识、来源独立保留集 | 有足够独立查询、困难失活和多家族覆盖；小标签面板不足则先补数据 |
| P3：有限受控训练 | 对关键假设的匹配数据/目标函数/表征干预 | 由P1/P2决定必要实验，不做无边界全因子扫描；效应报告跨种子与来源稳定性 |
| P4：实验结果与决策检验 | SPR384完整结果；若有追加预算再做独立选样 | 冻结选择策略与测量判定，报告技术失败和负结果 |
| P5：公开基准与文章 | 标准接口、版本化预测、来源清单、复现命令、报告与失败记录 | 按数据/模型许可发布；第三方能复算关键结论并加入新模型 |

新增JEPA可作为控制轨道的一个后续模型，用本框架检验其是否增加配对选择性；本研究不应依赖JEPA必须胜出。TxGNN/OpenTargets属于疾病证据和选题价值层，可保留为部署背景，不用疾病关联替代直接结合真值。

**当前建议：先把现有七模型和A/B实验组织成“排名关系—共同错误—配对选择性”的可复现实证，再由缺口决定补哪些数据与训练。** 若最终只能证明本项目七个部署版本的相关性低，文章应限定为实用比较；若能在独立数据与实验中解释分歧来源、检验错误预警并给出可复用的决策标准，才形成更广泛的领域贡献。
