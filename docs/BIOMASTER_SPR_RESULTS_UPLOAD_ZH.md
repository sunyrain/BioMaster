# SPR 实验结果上传

入口：网站 **SPR 设计 → 实验结果 · 上传与记录**。

默认入口为 **在线填写**，也可切换 **CSV 批量上传**。

## 在线填写

1. 在分组、排序、靶点筛选中确定范围，搜索药物 / 靶点 / 原实验编号。
2. 填写实验批次，选择配对。药物名称、靶点、实验编号、精确身份自动带入。
3. 填写样本编号、实验日期、响应和质控。KD、动力学、构建、浓度与备注按实际测量填写；选择未检出或无法判定时清空 KD。
4. 点击「加入待提交列表」。重复实验用不同样本编号；列表支持编辑、移除和继续添加。
5. 点击「校验在线记录并预览」，核对后确认入库。列表尚未入库时仅保留在当前页面，请完成提交后再离开。

## CSV 模板与顺序

旧模板仅显示原候选编号。该编号在优先排序中会跳号，容易被误认为乱序。新版分开显示连续模板序号、实验分组、优先顺序、优先级、药物与靶点名称。

- 默认 **基线候选 384 项 / 优先顺序**，以 `SPR384_PRIORITY_DETAILED.csv` 的明确「排序」列为准，原候选编号保持不变。
- 支持 **原实验编号** 或 **靶点 → 优先顺序**；可单独下载参考对照、扩展候选，或全部分组。
- 全部分组固定为基线候选 → 参考对照 → 扩展候选。对照及扩展候选不填基线优先级，按各自实验编号排序；按靶点排序时先按靶点，再按其组内顺序。
- 下载模板严格使用当前范围、排序、靶点与搜索条件。模板序号在筛选后从 1 连续排列；「优先顺序」仍是原全局优先顺序，不随筛选重排。
- 保留模板版本列（SPR_RESULTS_V2）及全部中文表头，响应填写「检出响应 / 未检出响应 / 无法判定」，质控填写「通过 / 未通过 / 待确认」。旧版模板已退役，必须使用当前 SPR_RESULTS_V2 模板及中文表头 / 选项。
- 保留实验编号与配对编号；识别信息列仅供阅读，服务器按实验编号核对精确配对并填入真实名称，不会将人工修改的展示列作为身份依据。
- Excel 另存为 **UTF-8 CSV**，最大 2 MB、最多 2,000 行。未填写实验结果的模板行自动跳过。
- 选择文件后校验并预览，全部通过才能确认入库。预览 30 分钟有效。

在线表单与 CSV 使用同一个校验、单位换算和事务保存流程。可在已上传记录中检索、展开详情并导出。

## 字段

| 字段 | 规则 |
| --- | --- |
| experiment_id | 必填，保留模板的基线候选 / 对照 / 扩展编号 |
| pair_id | 模板自动填写；如填写必须与该编号的完整 InChIKey + ChEMBL 靶点一致 |
| sample_id | 必填，同一批次唯一；重复实验使用不同样本编号 |
| experiment_date | 必填，YYYY-MM-DD，不晚于当前 UTC 日期 |
| result | detected（检出响应）、not_detected（未检出响应）、inconclusive（无法判定） |
| qc | pass（通过）、fail（未通过）、review（待确认）；为上传者填报质控 |
| KD / KD_unit | 可选，须配套；KD 为有限正数，支持 M、mM、uM、µM、μM、nM、pM，保留原值并换算为 nM；仅 detected 可填写 |
| ka_M_inv_s_inv / kd_s_inv | 可选，有限正数，分别为 M⁻¹s⁻¹ 与 s⁻¹ |
| Rmax_RU / chi2 | 可选，有限非负数；χ² 保留仪器报告值 |
| construct / max_concentration_uM / notes | 可选，蛋白构建、最高检测浓度、备注；浓度为有限正数 |

## 保存与解释

- 新记录保存到 `outputs/biomaster_explorer/spr_results/results.sqlite3`，不修改冻结设计、优先清单、模型分数或已知关系。
- 导入采用事务：任何重复冲突均整批回滚。确认请求重复发送不会重复写入。同批次同样本不能覆盖；修订使用新批次并在备注引用原记录。
- 保存原字段、规范化单位、设计身份、上传账号、UTC 时间、文件名、源行号和文件 SHA-256（上传批次表）。备份时备份此 SQLite 文件；数据库为本地服务数据，重启后保留。
- 所有记录的审核状态为 `pending`。qc 是上传者填报，不是平台审核。检出响应不自动认定特异性结合，未检出也不能脱离检测范围认定无结合。
- 此版接收结果 CSV，不解析原始传感曲线、仪器工程或 PDF 拟合报告，也不提供审核放行功能。原始资料由实验档案保存，建议在 notes 填写档案编号。
- 启用网站登录时，上传与查询沿用现有登录权限；已登录研究成员共享结果记录。预览只能由创建者确认。无登录配置的本地服务记为 `local`。

接口：`GET /api/spr-results/catalog`、`GET /api/spr-results/template.csv`、`POST /api/spr-results/preview`、`POST /api/spr-results/commit`、`GET /api/spr-results`、`GET /api/spr-results.csv`。查询支持 `search`、精确 `pair`、`page`、`page_size`（最多 200）；CSV 导出不受当前分页限制。

目录及模板支持 `scope=baseline|control|expanded|all`、`order=priority|id|target`、`target` 和 `search`。在线预览提交 `{batch, rows:[...]}`，CSV 预览提交 `{batch, filename, content}`；确认仍使用预览 token。
