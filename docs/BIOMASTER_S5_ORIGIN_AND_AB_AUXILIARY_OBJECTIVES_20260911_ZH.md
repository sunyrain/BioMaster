# 65,276对的来源与A/B排序、亲和辅助目标设计

2026-09-11。核对本地原始文件、准备记录、S5划分及当前A/B训练成员。本轮完成数据审计和训练方案设计，尚未添加或运行新的训练目标。

**65,276对来自受采样上限限制的历史ChEMBL校准集，经S5留出与特征检查后得到；它不是当时全部可用的训练数据。A/B可以保留二分类，同时增加实测配对排序和分端点回归；是否改善实验选样，需要受控比较。**

## 1. 从哪里得到65,276对

### 来源是ChEMBL实验标签

官方准备记录为：

`outputs/current_production_package_v2/conplex_target_calibration_v5_official/CONPLEX_CALIBRATION_PREPARATION_V5.json`

它记录输入509,172行、输出86,674对、每靶点每类最多150对。输入的SHA256与下列ChEMBL 37 SQLite正式抽取结果一致：

`outputs/current_production_package_v2/chembl37_target_calibration_v5/PROJECT463_CHEMBL37_STRICT_BINDING_PAIR_CALIBRATION_V5.csv.gz`

SHA256：`2dd28252e62164fa8b4122a35b22d8a679ffd3db578a1b6aa334694d7ef4e125`。

509,172行是当时463个项目靶点相关的配对记录，含331,404阳性、96,122阴性、77,596灰区、4,050冲突；不是全库所有靶点数据，也不是509,172条独立、可直接训练的二分类样本。

`scripts/prepare_conplex_calibration_v5.py`对相同序列与母体化合物合并去重，处理冲突与分子结构，保留正负标签，采用偏好不同Murcko骨架的确定性采样，每个序列靶点的每类标签最多150对，最终86,674对。它最初服务于校准和基准比较，后来被用于同数据模型对照；不意味着其余数据都无效。

目录名中的ConPLex表示用途，**标签来自ChEMBL实验记录，不是ConPLex预测生成的标签**。同时存在448,680行的API中间抽取，它不是这套86,674对的正式输入；不能仅按脚本默认路径判断历史运行来源。

### S5留出后，只有65,276对进入该版本模型训练

从冻结的`CHEMBL37_86674_INDEXED_PAIRS_V1.csv.gz`，按原`split_masks`逐行复算：

| 去向 | 配对数 | 阳性 | 阴性 |
|---|---:|---:|---:|
| 实际训练 | **65,276** | 35,684 | 29,592 |
| 验证集 | 16,668 | 9,067 | 7,601 |
| 项目老药测试集 | 2,556 | 354 | 2,202 |
| 与老药同骨架的其他分子，隔离不用 | 2,173 | 878 | 1,295 |
| 特征不可用，隔离 | 1 | 0 | 1 |
| 合计 | **86,674** | **45,983** | **40,691** |

即：**86,674 − 2,556 − 2,173 − 16,668 − 1 = 65,276**。

S5先把有实验标签的项目老药作为测试，并把共享其骨架的其他分子一并排除出训练/验证；剩余骨架分组后，fold 0作验证，其余作训练，最后过滤不可用分子特征。训练与验证不共享骨架。测试集代表720药目录中有该基准标签的302个药物，不是全部720药都有测试数据。

该训练集含48,057个化合物、423个靶点。历史5个随机种子各自使用同一65,276对，不能相加为326,380个不同配对。

## 3. 排序目标怎么加入

保持当前二分类训练，并用同一连续logit增加两种约束：

1. **固定一个靶点，排序药物**：已测阳性药物应高于该靶点的已测阴性药物。
2. **固定一个药物，排序靶点**：该药物已测阳性靶点应高于其已测阴性靶点。这尤其对应我们给每个老药选择新靶点的场景。

对一个查询内的实测阳性分数`s_pos`和实测阴性分数`s_neg`，使用成对损失：

```text
L_query = mean(softplus((s_neg - s_pos) / temperature))
```

先在查询内平均，再在查询间平均；先采样查询，再分别采样正负候选，避免标签多的靶点占据几乎全部排序训练。不存在测量的配对不作为阴性；只有单类标签的查询不计算该项，仍可参与二分类。

首轮按现有监督任务分池，B分别处理Kd/Ki、IC50、EC50，避免把不同端点的正负标签随意拼成一组。Kd/Ki是当前合并的亲和任务；同任务仍不等于同实验条件。若进一步监督连续强弱次序，应尽量限定相同端点、相容的实验条件/筛选面板，不能跨不同条件强制细微差值的次序。

在**现有A/B训练成员内**，具有正负两类标签的查询数如下：

| 模型 | 监督任务 | 固定药物、排序靶点的查询数 | 固定靶点、排序药物的查询数 |
|---|---|---:|---:|
| A | Kd/Ki | 8,012 | 1,287 |
| B | Kd/Ki | 7,891 | 1,271 |
| B | IC50 | 32,389 | 1,936 |
| B | EC50 | 4,797 | 529 |

这些是按原任务合并后的可用查询计数，不是全部满足同端点、同实验条件的排序组。不同任务可包含同一药物/靶点，不能把各行相加当作独立实体总数。B的Kd/Ki略少，源于其当前训练成员还受跨端点冲突过滤约束。

明确失活保留在二分类；其端点或实验适用范围能够确认时，才加入对应任务的排序负例。没有端点的失活不能强行指派到四个端点。输出的`POOLED_RANK_QUERY_AVAILABILITY.csv`另给出混合标签统计，包含这类失活，不能拿它替代上表的任务内计数。

实现可复用`biomaster/best_model_training.py`的`ObservedQueries`与`measured_pair_loss`。同文件另有从未知关系采样的`RollingStage.retrieval`，不适用于本轮仅用实测正负的方案。

## 4. 亲和/活性数值辅助目标怎么加入

二分类把10 nM与1,000 nM都归为阳性时，丢失了强弱信息。精确回归可保留这种差别：`p = 9 − log10(value_nM)`，10 nM对应8，1,000 nM对应6。

在共享表示后增加独立输出头：

- **A：pKd、pKi两个头。**
- **B：pKd、pKi、pIC50、pEC50四个头。**后两者是活性辅助，不能统称直接结合亲和。

每条数据只监督有精确数值的端点。缺失端点通过显式mask跳过，不填0，也不能依赖`NaN × 0`屏蔽。明确失活而没有数值时只监督二分类/适用的排序；`Kd > 10 µM`是`pKd < 5`的界限，不能直接编造成`pKd = 5`。界限约束可在后续单独增加单侧损失。

目前`TRAIN_REGRESSION.parquet`保留质量合格的精确`=`测量，以每配对、每端点的去重数值中位数为标签；要求无任务冲突、数值跨度不超过1 log且不违反有效删失界限。将它与当前A/B的训练成员相交，得到：

| 精确端点记录 | A | B |
|---|---:|---:|
| Kd | 20,660 | 20,749 |
| Ki | 171,809 | 172,012 |
| IC50 | — | 530,921 |
| EC50 | — | 75,564 |
| 合计端点记录 | **192,469** | **799,246** |
| 对应不同配对 | **191,189** | **766,314** |

同一个配对可能有多个端点，因此端点行数不等于独立配对或独立实验数。这些数值本来就在联合数据库中，首轮不需要下载或扩大训练配对范围。现有成员外另有A的37,571条Kd/Ki记录、B的180,819条四端点记录；首轮先不加入，避免把“目标变化”和“训练成员变化”混在一起。后续可以专门研究灰区数值的回归监督，并重新核对特征与隔离规则。

每个端点只用训练集计算标准化参数，以Huber损失训练，按端点分别平均与加权，避免B的IC50行数压倒Kd/Ki。Huber对大残差采取线性惩罚，定义见[PyTorch 2.10官方文档](https://docs.pytorch.org/docs/2.10/generated/torch.nn.HuberLoss.html)。

旧S5脚本已有单个`affinity_head`，但监督是混合端点的`mean_pchembl`。ChEMBL的pChEMBL可来自Kd、Ki、IC50、EC50等测量，见[ChEMBL官方数据说明](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions)。数值在同一对数尺度，不表示生物学含义相同；新方案应保留端点身份。

## 5. 接入现有A/B网络与验证顺序

现有`UnifiedInteraction.forward(batch, return_representation=True)`已经可以返回分类logits与共享表示，不需要更换编码器。A/B使用192维共享表示，增加两个/四个线性回归头分别只增加386/772个参数；训练数据组织、损失权重及验证方式比这点参数开销更关键。

```text
共享药物—蛋白表示
  ├─ 原二分类输出：保留当前两个logit的监督和均值评分
  │    ├─ 二分类损失
  │    ├─ 靶点内实测正负排序损失
  │    └─ 药物内实测正负排序损失
  └─ 分端点回归头：精确值、显式mask、端点分别标准化

L = L_binary + λ_target × L_rank_target
             + λ_drug × L_rank_drug
             + λ_aff × Σ(endpoint_weight × L_Huber_endpoint)
```

首轮两种排序都使用当前均值logit。若改成两个方向各自使用一个输出头，应作为另一项消融，否则无法区分排序目标与评分接口变化。辅助回归首先用于改善共享表示，不直接把pKd数值与分类分数相加生成新综合分。

历史S5的总目标为BCE＋0.12×靶点内排序＋0.06×pChEMBL辅助；旧排序用查询内正负均值差，并非上述逐对损失，也没有药物内排序。**可以借鉴其目标结构，不能直接认定旧权重适合新的损失尺度和百万数据。**

建议A/B各做四种变体，每种3个种子，共24次拟合；这是待执行方案：

| 变体 | 二分类 | 实测双向排序 | 分端点数值回归 |
|---|---|---|---|
| 基线 | 是 | 否 | 否 |
| 排序辅助 | 是 | 是 | 否 |
| 数值辅助 | 是 | 否 | 是 |
| 联合辅助 | 是 | 是 | 是 |

同一组A或B固定数据成员、特征、初始化规则、二分类损失及采样约定；各变体保留同样形状的回归头，关闭辅助时相应权重为0。保证相同二分类样本曝光并报告附加计算量，不能把相同优化步数直接称为相同计算成本。权重与检查点只根据验证集选择，不按测试集或“保留旧384最多”调参。

开始前补上训练中验证与学习曲线。按靶点、按药物分别报告AP和P@K，单列明确失活的误报率；回归按端点分别报告MAE/RMSE与有足够测量的查询内相关性。预先固定主检查点选择指标，并比较充分训练的BCE基线，避免“辅助多训了一些”成为唯一差异。已交付SPR配对、现有测试集不进入任何辅助采样或预处理拟合。

**排序辅助可能改善候选次序，数值辅助可能改善强弱信息；两者也可能引入任务冲突或无效监督。只有共同隔离测试和后续湿实验才能判断提升，不能承诺加上就会恢复旧384或提高命中率。**
