# BioMaster亲和预测的前沿方法与下一轮训练设计

**核心判断。** BioMaster应保留完整数据，优先恢复实验上下文，把结合预测设为明确的主任务，再检验温和的数据平衡。当前证据不支持将B的全部新增活性数据判定为无用，也不支持把“每靶点每类150条”恢复为默认永久截断。更值得借鉴的方向是：按实验组织监督、区分发现结合与预测功能活性、控制不同任务的训练份额，并用符合实际筛选场景的评估判断增益。

**有必要修正一个过于简单的推断：混合端点并不必然要求每种端点单独建头。** MBP实际将IC50与K={Ki,Kd}分为两类任务；Boltz-2则报告混合多种端点的单连续值头效果最好。两者都强调同一实验内的比较。端点拆分是可检验的设计选择，实验可比性才是更基础的问题。[1](https://doi.org/10.1093/bib/bbad451)[2](https://jeremywohlwend.com/assets/boltz2.pdf)

**1. 当前A/B的结果应如何理解**

A/B的24次拟合已经完成，均按预设验证平台期停止，没有触发200,000步紧急上限。这说明本轮不能再主要用“B只训练了很少的步数”解释差距；它也不证明找到了所有架构、损失和数据组织方式下的最优解。

同一测试面板上，纯二分类变体的三个种子均值如下。AP只在同一行内比较，不把阳性率不同的测试面板横向排列成难度排行榜。

| 测试面板 | A | B | 可支持的判断 |
|---|---:|---:|---|
| Kd/Ki AP | 0.9555 | 0.9170 | A更适合当前结合标签面板 |
| IC50 AP | 0.8636 | 0.9824 | B明显学到了新增IC50监督 |
| EC50 AP | 0.8353 | 0.9634 | B明显学到了新增EC50监督 |
| 全端点合并AP | 0.8749 | 0.9613 | B的总体活性识别收益不能忽略 |

数据量从A的337,570对增加到B的1,116,270对，但有Kd/Ki数值任务的配对从286,787变为284,797，占比由84.96%降到25.51%。少量成员差异来自两组的冲突过滤。B增加的主要是另一个监督方向，而不是把同质量、同分布的亲和标签增加了三倍。

当前BCE已经通过类别系数平衡全局正负权重。仍然没有平衡的是端点、靶点、实验来源和化学系列。明确失活配对均为105,368对，但其预期BCE系数份额从A的35.41%降到B的15.19%；这些是采样与系数统计，尚不是实测梯度贡献，不能据此认定因果。

排序也不是全面失败。A同时加入排序和回归后，靶点宏平均AP与药物宏平均AP的均值从0.6532升到0.6615，但Top-5和明确失活误报没有同步改善。B加入回归后，该均值从0.6000升到0.6335。既不能说辅助任务一律无用，也不能仅凭某一个指标提高就切换实验推荐。

上述数据来自本地[任务与平衡审计](BIOMASTER_AB_TASK_BALANCE_REVIEW_20260911_ZH.md)和[24次拟合结果](BIOMASTER_AB_MULTITASK_RESULTS_20260911_ZH.md)。现有测试面板已经多次查看，应继续作为诊断面板；后续确认需要保留新的独立证据。

**2. 国际代表性工作实际采用了什么**

这里的“前沿”指与BioMaster问题直接相关、截至2026-09-11可核实的代表性工作，重点覆盖2024—2026年，补充仍在使用的基础路线。各论文使用的数据、负例和划分不同，不以跨论文排行榜宣称某一个模型全面最强。

| 工作与发表情况 | 实际方法 | 对BioMaster的适用边界 |
|---|---|---|
| MBP，Briefings in Bioinformatics，2023在线/2024卷期 | IC50与K={Ki,Kd}两类任务；各有回归和实验内排序；按实验大小比例抽实验 | 不是每个端点都独立，也不是所有实验均匀采样；原方法需要复合物结构输入 [1](https://doi.org/10.1093/bib/bbad451) |
| ActFound，Nature Machine Intelligence，2024 | 实验内活性差值学习，跨实验元学习；160万活性记录、35,644个ChEMBL实验 | 说明百万级数据本身并不异常；主要面向有少量标注支持的新任务适应 [3](https://www.nature.com/articles/s42256-024-00876-w) |
| Boltz-2，2025技术预印本 | 分类与连续值双任务；混合端点单连续值头；更重的实验内差值损失；按来源和实验信息量采样 | 可以借鉴训练组织；不等于需要重新部署整个结构模型 [2](https://jeremywohlwend.com/assets/boltz2.pdf) |
| AssayCTX，JCIM，2025 | 将实验描述与类别用于活性建模；部分数据集受益 | 端点名称不足以描述实验；上下文增益并非所有数据集都一致 [4](https://pubs.acs.org/doi/10.1021/acs.jcim.5c00603) |
| AdaMBind，Nature Communications，2026-03-10 | 靶点任务元学习，依据损失和梯度一致性动态安排任务 | 主要研究5—40个标注支持样本条件；不是零标注新靶点的普遍保证 [5](https://www.nature.com/articles/s41467-026-70554-5) |
| DTIAM，Nature Communications，2025 | 自监督分子/蛋白表示加AutoML，分别支持DTI、DTA和作用机制任务 | “统一框架”不等于所有标签被压成一个共享二分类目标 [6](https://www.nature.com/articles/s41467-025-57828-0) |
| DrugCLIP，Science，2026-01-08 | 口袋与分子的对比表示，用于大规模检索 | 检索库大小不是实测亲和训练标签数；不能把余弦相似度直接解释为Kd [7](https://pubmed.ncbi.nlm.nih.gov/41505557/)[8](https://github.com/THU-ATOM/Drug-The-Whole-Genome) |
| ConPLex，PNAS，2023 | 预训练蛋白表示、分子表示和对比学习；提供训练及推理代码 | 对比学习的诱饵与实验确认失活应区别管理；公开结果不是本地模型的自动保证 [9](https://github.com/samsledje/ConPLex) |

三条路线值得优先理解。第一，**实验内学习**解决同一量纲下仍存在的实验偏差；第二，**任务组织与采样**决定额外数据帮助哪个目标；第三，**预训练与下游适应分离**允许广泛数据提供表示，而由目标实验的数据决定最终用途。模型名称和总数据量无法替代这些设计信息。

MBP的规模也揭示了一个常见统计误区：313,224个蛋白—配体配对对应约280万个计算对接构象。后者不能计算为280万条独立实测标签。DrugCLIP公布的约一万人类蛋白、五亿分子是筛选覆盖空间，也不是这些组合都有亲和实验。[1](https://doi.org/10.1093/bib/bbad451)[7](https://pubmed.ncbi.nlm.nih.gov/41505557/)

**3. 最有价值的共同点是实验可比性，而不只是端点名**

Landrum和Riniker对ChEMBL的研究发现，即使都叫IC50，在仅按活性做基本整理的可比记录中，跨实验测量也有27%相差超过一个log单位；严格匹配更多实验元数据后降到13%。Ki同样存在明显跨实验差异。这些是论文特定重叠数据的统计，不是BioMaster的实测错误率。[10](https://pubs.acs.org/doi/10.1021/acs.jcim.4c00049)

这意味着，仅用Kd/Ki也不能完全免除实验异质性；把IC50拆成独立头也不意味着头内标签已经可比。蛋白构建体、竞争配体、底物、细胞环境、测量技术和条件，仍可能改变观测值及其含义。

可用一个近似模型理解实验内比较：

```text
某实验观测值 = 分子与靶点的可学习效应 + 实验偏移 + 剩余误差
同一实验中两分子之差 ≈ 两分子的效应差 + 剩余误差之差
```

这里的抵消依赖“偏移大致共享”这一假设。不同作用机制、非线性响应、测量上下限仍可能破坏它。因此应比较同一来源实验、同一靶点构建体、同一端点中的有效记录，而不是把同一篇论文、同一个靶点或相同IC50标签视为足够条件。

BioMaster当前的辅助排序，是在同一数值任务内按靶点或药物分组，再比较已测阳性和阴性；它没有按assay分组。当前回归标签则按药物—靶点—端点聚合确切值，经过冲突、跨度及上下界检查，仍可能把不同实验压成一个中位数。两项设计各有用途，但都不等同于ActFound或MBP中的实验内监督。

**下一版应增加一种独立训练视图，而不是改写证据库：** 保留每条测量的来源、实验编号、端点、关系符、数值、构建体和上下文。在可靠组内计算相对活性损失；全局分类和端点回归继续用经过清洗的成员。具体可比较同组两条确切测量的预测差与实测差，采用Huber损失；差值权重和有效动态范围由训练/验证确定，不从测试结果反推。

还要区分两个排序方向。一个单靶点实验通常能教模型“同靶点哪些药更强”，并不能自动教会“同一药对不同靶点的选择性”。后者更适合统一条件下的靶点profiling面板，或有充分跨靶点可比性的证据。本项目应保留两个方向的独立评估，避免用一个方向的成功替代另一个。

Boltz-2的启发是，单连续值头也可以与精心组织的实验内监督配合使用；其连续值来源与二分类来源按专门比例采样，实验内批次大小为5，连续值实验还按活性四分位差安排曝光。它另外使用合成诱饵。BioMaster可检验前两项思想，不能把这种诱饵当成新增实验阴性，也不能直接移植其比例或把全部输出命名为物理Kd。[2](https://jeremywohlwend.com/assets/boltz2.pdf)

**4. 本地数据已经具备实施基础，但训练表还没有利用它**

原始证据表含`assay_id`，语义却随来源不同。ChEMBL存储的是来源assay编号；BindingDB导入时存储的是`BindingDB Entry DOI`。官方定义后者为数据库条目DOI，不能保证条目下所有记录都来自同一实验。[11](https://ww.bindingdb.org/rwd/bind/chemsearch/marvin/BindingDB-SDfile-Specification.pdf)

BindingDB九月版提供两张单独的官方映射：从Reaction Set ID映射到Entry ID与Assay ID，再连接实验描述。两份压缩文件合计约17 MB，已经下载并通过各自官方MD5校验；无须重新下载主库。它们恢复的是实验元数据，不是凭空增加亲和测量。[12](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp)

| 当前通过QC的来源记录 | 记录数 | 可定位来源实验编号的记录数 | 说明 |
|---|---:|---:|---|
| ChEMBL37 | 1,427,612 | 1,427,612 | 现有编号保留；本地37版数据库还保留描述及相关上下文字段 |
| BindingDB九月 | 1,470,303 | 1,450,277 | 通过新映射且能找到非空实验描述，约98.64% |

在**保持原A/B成员、原训练划分及现有确切回归标签资格**的条件下，按来源实验编号、精确序列靶点和端点分组，并要求每组至少5个不同分子：

| 指标 | A | B |
|---|---:|---:|
| 原有合格回归配对—端点数 | 192,469 | 799,246 |
| 可分入上述实验组的不同配对—端点数 | 166,764 | 713,342 |
| 占原有合格回归记录比例 | **86.64%** | **89.25%** |
| 涉及不同药物—靶点配对 | 166,064 | 689,534 |
| 来源实验—靶点—端点组 | 14,907 | 52,528 |
| 覆盖靶点 | 1,044 | 2,083 |

这些数字是**可恢复分组的覆盖率，不是模型提升或最终可训练规模**。“至少5个”是可行性统计阈值，完整CSV还包含1、2、10个的统计；它不是已优化参数。来源编号仍需检查描述一致性、构建体及有效动态范围。ChEMBL与BindingDB保持独立命名空间，尚未跨库合并同源assay，表内组数不能当成完全独立实验总数；训练时还需要防止同一文献证据重复加权。

现有划分主要按分子骨架隔离，并未强制同一实验全部进入同一划分。若进一步从上述辅助视图排除所有与validation/test共享来源实验的组，至少5分子条件下，A剩36,831、B剩115,712个不同配对—端点，分别为原回归记录的19.14%和14.48%。

这个变化不等于原测试全部无效。原测试可以回答“已知实验体系下，新骨架是否可预测”；它不能充分代表“全新实验体系”的泛化。若要评估后者，必须对分类、回归和排序的全部训练入口同步隔离，而不只是从辅助排序池中移除共享assay。

九月数据库版本也不等于所有测量都首次发表于九月。做时间外推评估时，要区分实验发表时间、数据库收录时间和文件版本，并核对旧训练来源是否已经包含同一证据。新增下载记录不能自动算作独立的新测试数据。

可复现统计见[ASSAY_TRAINING_FEASIBILITY.csv](../outputs/biomaster_frontier_research_20260911/ASSAY_TRAINING_FEASIBILITY.csv)和[审计脚本](../scripts/audit_assay_context_frontier_20260911.py)。脚本只读原训练成员与证据，记录输入哈希，并验证运行前后未变。

**5. 150截断的价值与替代方法**

历史150规则有合理动机：限制热门靶点主导模型，并优先保留化学骨架多样性。但是在审阅的代表性方法中，没有发现把“每靶点每类150条”当成普适标准的依据。相反，MBP按实验大小比例采样；Boltz-2按来源和实验信息量采样；AdaMBind依据任务学习状态动态安排。它们优化的目标不同，采样方式也不同。[1](https://doi.org/10.1093/bib/bbad451)[2](https://jeremywohlwend.com/assets/boltz2.pdf)[5](https://www.nature.com/articles/s41467-026-70554-5)

| 方法 | 可能收益 | 代价与适用方式 |
|---|---|---|
| 全量逐行学习 | 充分利用全部记录，易复现 | 曝光由数据库分布决定，热门靶点与系列可能占优 |
| 静态150视图 | 控制靶点预算，训练便宜 | 当前A只剩48.29%、B只剩30.33%的配对；结果依赖具体保留成员 |
| 每轮轮换150 | 控制当轮预算，长期可见更多分子 | 需记录累计不同配对覆盖；稀疏靶点仍会被频繁重复 |
| 温和靶点×类别权重 | 保留全量，减少长尾偏斜 | 需要平滑或增益上限，避免放大少量错误标签 |
| 实验/任务级采样 | 控制可比性和监督方向 | 来源、靶点、类别与化学系列的平衡要分别计量 |

建议保留150作为消融对照，主方案先试温和平衡。例如以`(n(靶点,类别)+τ)^(-1/2)`作为初始系数，再在每个类别内归一化，使全局正负系数总量各占50%。`τ`和权重上限只在训练/验证确定。这是BioMaster的候选方案，不是引用某篇论文的已证实最优配置。

若使用上述加权，就替换原类别权重；若改成平衡采样，就根据新的抽样分布重算损失系数。把过采样、逆类别加权和逆靶点加权机械叠加，可能造成重复校正。稀疏靶点也不应为了凑满批次而制造未知负例。

平衡还应有化学结构维度。一个靶点的一千条近似同系列化合物，与一千种分散骨架提供的信息不同。优先记录不同骨架、近邻相似度与测量来源覆盖；先用这些统计判断是否被少数系列主导，再决定是否增加骨架采样。不能只根据条数认定哪个靶点已经“学够”。

**6. B应怎样帮助结合预测**

最优先的问题不是让B在全端点AP上再涨一点，而是让它利用额外活性信息，同时保住实验所需的结合识别和前排排序。建议把以下两条路线作为竞争假设，而不是预设其中一条必胜。

第一条是**广数据学习后亲和专门适应**：用B学习通用的分子—蛋白关系，再在与A相同的亲和/合格失活训练成员上进行低学习率适应；与A从头训练、等计算预算延长训练等对照比较。这可以回答“B是否学到了可转移表示，但最终评分需要回到亲和任务”。需监控功能端点是否遗忘；最后的亲和模型与通用活性模型可以承担不同角色。

第二条是**共享表示、任务有明确用途的联合学习**：结合分类作为SPR主任务；功能活性采用有上下文的辅助输出；确切数值与实验内差值作为辅助约束。每项监督按可用标签mask，单独记录其样本曝光、损失和共享表示梯度。当前两个分类输出都学同一个合并标签，不属于这种任务分工；当前Kd、Ki、IC50、EC50回归头则已经分开，不能把它当成尚未实现的改进。

对连续值，保留“共享头与端点头”的对照；对分类，需要先明确阳性的含义。一个细胞EC50阳性不应无条件变成纯化蛋白直接结合阳性；没有明确端点和实验上下文的失活，也不应复制到所有输出头。实测上下界继续保留关系符，既可作为合格分类证据，也可在后续专门设计的区间损失中使用，不能冒充确切Kd。

如采用联合学习，主任务预算应由目的确定，而不是自然等于数据行占比。可从预先固定的少量主/辅比例开始，在验证集选择；不把某个70:30或80:20比例宣称为领域标准。先检查辅助任务与主任务的梯度方向、目标靶点覆盖及误报变化，再决定是否需要更复杂的动态权重或梯度冲突处理。

当前模型的分子和蛋白编码大部分冻结，融合网络约123.5万参数。即使标签增加，表示能力也未必同步增加。只有在数据组织与目标权衡得到控制后，仍出现训练与验证均受限，才有理由单独比较更强交互层或部分编码器适应；直接放大模型会使原因更难判定。

**7. 如何组织下一轮，才能得到可解释的答案**

建议采用有停止条件的顺序实验，而不是立刻把新架构、采样、划分、损失和数据成员全部改掉。

| 阶段 | 最小对照 | 固定项 | 要回答的问题 |
|---|---|---|---|
| 数据准备 | 恢复assay与描述；来源重复、动态范围和划分审计 | 原证据库、实验清单 | 能否获得可比且可追溯的训练视图 |
| 平衡试验 | A/B现有逐行BCE、温和权重、轮换150 | 原成员、特征、输出与BCE含义 | 单独调整曝光是否改善前排筛选 |
| 实验内监督 | 固定采样后，对比无辅助、现有辅助、同assay差值辅助 | 同成员、相同可用端点、主任务预算 | 改善来自实验可比性还是仅增加计算 |
| B的任务使用 | B→A适应；共享表示的主辅任务方案 | 各自配对的同划分基线 | 新活性数据能否帮助结合任务 |
| 确认 | 最佳少数方案多种子、独立留出与真实实验结果 | 预先固定选择规则 | 是否值得更新生产模型 |

当前24次拟合可作为旧配置的诊断基线。若为新实验条件泛化重建划分，应同时重训对应基线，不能拿新划分的分数直接与旧表比较。初筛可用单种子筛除明显无效方向，但正式保留结论至少复核三个种子及按查询配对的置信区间；单种子小涨幅不作为更换理由。

评估至少覆盖四层。**结合层**分别报告Kd、Ki及其合并面板；**筛选层**报告每靶点与每药物的宏平均AP、Top-5/Top-10及有足够实测标签时的富集指标；**误报层**使用实测阴性与来源分层，并在固定召回率等可比条件下比较；**泛化层**区分新骨架、新靶点家族、新实验/文献以及未来数据。

DataSAIL支持同时考虑药物与蛋白相似性，并提醒双实体划分可能牺牲部分交互记录。其2026年补充文章还扩展了对相关方法的比较。BioMaster不必只用最严格的双冷启动：720种既有药寻找新靶点，与新骨架寻找已知靶点是不同部署场景，应分别评价。[13](https://www.nature.com/articles/s41467-025-58606-8)[14](https://www.nature.com/articles/s41467-025-67495-w)

不能把未测矩阵格子当作负例来计算“全矩阵命中率”；也不能只看384保留了多少来评价模型。历史推荐使用过组合分数、图谱证据和覆盖约束，比较模型贡献时应固定相同候选池与相同选择规则。真实实验回流后，还需要区分确认阴性、测量失败和不确定结果。

**8. 实验资源与现有模型的角色**

国际论文中的成功案例应增加方法可行性的信心，而不是变成对当前384的命中承诺。Science版DrugCLIP在两个具体靶点的湿实验中报告15%和17.5%的命中率；ConPLex报告19个激酶—药物预测中验证12个。样本选择、靶点及检测流程不同，不能把这些比例套到BioMaster的112个靶点。[7](https://pubmed.ncbi.nlm.nih.gov/41505557/)[9](https://github.com/samsledje/ConPLex)

前沿模型同样有迁移限制。2026年独立ActFound复用研究在抗菌天然产物任务上没有复现原研究全部跨域精度，但在低样本条件下仍有竞争力。这支持“按真实应用验证、积累自身实验反馈”，不支持因模型有基础模型称号就自动取代现有路线。[15](https://www.nature.com/articles/s42256-026-01187-y)

对已经开展的SPR，最有价值的安排是保留可追溯的预测快照、实验批次与条件，完整记录成功和失败，并将部分后续结果留作模型改进之后的确认。不能先用全部384结果调模型，再把同384上的表现包装成独立验证。按模型一致/分歧、已有/稀疏监督、靶点家族分层统计，才能判断哪种预测信号值得继续投资。

TxGNN与Open Targets仍回答疾病关联、机制解释和研究价值问题；亲和模型回答结合假设。图谱高分不会自动补救缺少结合信号，也不适合作为直接结合的训练真值。当前矩阵与实验页面若将来增加新模型，应显示模型版本、评分用途和不确定性，避免把不同分数当作同一种概率。

**推荐决策。** 完整数据库继续保留；A作为亲和对照，B作为值得继续开发的广数据路线；先恢复assay上下文和审计划分，再比较温和平衡与实验内监督。150保留为训练预算对照，端点拆头保留为结构对照。只有在同规则筛选、误报控制和独立证据上取得一致收益，才升级实验推荐。

本报告交付的是研究结论、可复现元数据覆盖审计与下一轮设计。原训练数据、生产模型、网站排序和已交付384清单均保持原版本；未启动新一轮训练。
