# A/B实验上下文重训：完成核验与两轮结果分析

30次拟合全部完成，均达到预先规定的验证平台期，全部训练成员均被实际访问。包括最终评估，总耗时116.46分钟；拟合累计97.99分钟。**本轮优化没有整体超过上一轮A模型，不支持替换生产模型或据此重排已交付的SPR384。** 有局部收益：B的实验内监督方案改善了靶点内排序，Kd数值回归也有所改善；这些收益没有同步转化为更好的结合分类及药物跨靶点排序。

这里的“上一轮A/B”指九月整理数据上完成的24次多任务实验，**不是最早的生产模型，也不是生成SPR384的历史组合评分**。A使用337,570对，B使用1,116,270对；各自包含105,368对明确失活。研究采用冻结分子/蛋白特征训练融合模型，没有重新端到端训练特征编码器。

## 比较口径

两轮共用A/B训练成员、骨架划分、特征、三个随机种子及Kd/Ki验证选择指标。共同Kd/Ki测试集有34,327对，23,190阳性、11,137阴性。查询评估要求至少10个已测配对且同时有正负标签，纳入516个靶点查询、54个药物查询。

- Kd/Ki AP：共同测试集的总体平均精度，越大越好。
- 双向AP：靶点宏平均AP与药物宏平均AP的均值，两个方向各占一半。
- 靶点P5：给定靶点，在其有标签药物中取前5个，计算阳性比例，再对靶点平均。
- 药物P5：给定药物，在其有标签靶点中取前5个，计算阳性比例，再对药物平均。

下面均为三个种子的均值。**P5反映这个已测测试面板上的排序，不是完整720×888空间或SPR384的预计命中率。** 各方案曝光次数和辅助计算量不同，详见收敛记录。

## 哪些改动有用，哪些没有

**150轮换没有得到支持。** 相对各自原二分类基线，A双向AP从0.6532降至0.6333，B从0.6000降至0.5832；药物P5也分别下降。各方案实际访问了100%成员，不能将结果归因于剩余数据根本没读到。这里是每靶点每类别150条的轮换预算，没有复刻历史静态骨架精选；这次结果不能反证当时150精选一定无效，也不支持把当前数据库永久截成150条。

**实验内监督有方向性收益。** B完整实验内方案相对上一轮B二分类，靶点宏平均AP从0.6569升至0.6805，靶点P5从0.6058升至0.6156；药物P5却从0.5198降至0.5123。它的双向AP仍低于上一轮B加回归的0.6335。上述跨轮差异同时包含平衡与辅助目标变化，不能全部归功于实验内差值；在本轮B回归基础上加入差值，双向AP从0.6084升到0.6237，而靶点P5从0.6164略降到0.6156。

A完整实验内方案的靶点P5从0.6410微升到0.6421，但药物P5从0.5790降到0.5407。对于我们“给药物寻找新靶点”的目的，后一项损失值得重视，不能只展示前一项改善。

查询配对bootstrap提供了这一取舍的辅助证据：B实验内方案相对B二分类的靶点P5差值为+0.00982，95%区间[+0.00271,+0.01667]；A对应靶点P5差值区间跨0，而药物P5差值为−0.03827，区间[−0.06049,−0.01605]。区间以三个种子的查询均值为条件，未校正多方案比较，也不包含所有化学/靶点相关性，不作为独立确认。完整结果见[PAIRED_QUERY_INTERVALS.csv](../outputs/biomaster_assay_aware_20260911/PAIRED_QUERY_INTERVALS.csv)。

**B→A迁移未显示结合任务收益。** 与相同下游A数据、损失和学习率的A→A继续训练相比，双向AP为0.6254对0.6377，Kd/Ki AP为0.9078对0.9368。两者也都未超过上一轮A基线。上游数据和计算不同，因此这里只比较这两条实际训练路线。

**数值Kd回归有局部改善，但还不足以精确报亲和力。** 同一3,603条确切Kd测试记录上，上一轮B回归方案的pKd MAE为1.2046，本轮B回归为1.1319，加实验内差值后为1.1044；上一轮B排序＋回归为1.1873。改善没有扩展到全部端点：Ki的MAE由上一轮B回归0.7247变为本轮完整实验内方案0.7456。pKd约1.1个对数单位的平均绝对误差仍较大。以上只比较训练过的回归头；二分类模型未训练的回归头不参与优劣判断。

## B的数据究竟有没有价值

有，但其优势更符合它获得的监督类型。同一IC50测试面板上，上一轮B二分类AP为0.9824，A为0.8636；EC50面板上分别为0.9634和0.8353。本轮B实验内方案仍有0.9775和0.9584，明显高于A对应值0.8685和0.8418。A没有直接使用IC50/EC50训练，因此这些差异不能解释为等监督条件下的模型架构优势。

这支持“新增活性数据帮助活性任务”，没有支持“更多IC50/EC50记录就一定改善Kd/Ki结合排序”。本轮仍将分类监督汇入同一分类任务；端点分头只用于回归，最终选药分数仍来自分类logit。共享表示的多任务取舍、不同实验端点的条件差异，以及辅助回归和最终分类排序不完全一致，都是合理的解释假设；本轮没有将它们逐一隔离，不能宣称已找到唯一原因。

这也不是对前沿论文方法的完整复现：本轮借用了实验内比较与端点监督的思想，保留了我们自己的冻结特征、分类头和初始损失权重。阴性结果约束的是这套实现与评估条件。

## 更严格的来源检查

严格结果使用原始来源assay编号，未知上下文排除。同一编号即使出现在不同靶点或端点，也算共享实验。训练脚本`TEST_METRICS.csv`中的`source_assay_disjoint`只检查“实验—靶点—端点”组合，口径较宽；严格结论以[STRICT_SOURCE_ASSAY_METRICS.csv](../outputs/biomaster_assay_aware_20260911/STRICT_SOURCE_ASSAY_METRICS.csv)为准。

仅要求原始assay未见时，A有3,485对，B有3,381对，各自面板不同，不能直接把两组AP横比。A二分类AP为0.8392，本轮A温和平衡0.8356、完整实验内方案0.8377，没有显示明确提升。

同时要求原始assay和文献未见时，A/B都是同样的488对；本次逐一核对了pair_id集合完全相同，其中324阳性、164阴性。A二分类AP为0.9157，本轮A温和平衡0.9087；B二分类0.9150，本轮B温和平衡0.9213、完整实验内方案0.8875。B温和平衡在这个小子集有局部收益，不能据此宣称在完整任务上获胜，也不能忽略这个例外说所有维度都变差。均值汇总见[STRICT_SOURCE_ASSAY_MEANS.csv](../outputs/biomaster_assay_aware_20260911/STRICT_SOURCE_ASSAY_MEANS.csv)。

这些都是已经查看过的原测试集的分层诊断，不是新增独立实验。各方案失活FPR采用各自在验证集最大F1处的阈值，召回率可能不同；不能将FPR数值直接比较成固定召回率误报能力，更不能将其解释为SPR失败比例。

## 完成核验与后续判断

重新校验了30个最终模型文件哈希、14个训练身份文件、迁移父模型、生产模型及3份实验交付文件；逐个重放验证平台期控制器，全部与历史记录一致，保存的检查点均对应各自最高验证指标。停止步数为13,000—65,430，没有触发200,000步异常上限；每个方案都实际访问了全部训练成员。见[COMPLETION_VERIFICATION.json](../outputs/biomaster_assay_aware_20260911/COMPLETION_VERIFICATION.json)、[CONVERGENCE_SUMMARY.csv](../outputs/biomaster_assay_aware_20260911/CONVERGENCE_SUMMARY.csv)。这确认达到预设验证收敛条件，不是数学上的全局最优证明。

现阶段保留上一轮A二分类作为结合分类与前排筛选的参照，同时保留上一轮A排序＋回归作为双向排序参照；B保留用于活性任务研究。当前结果不足以把本轮新模型部署到网站，或仅凭模型分歧改动SPR384。

如果继续建模，下一项值得单独检验的是让Kd/Ki与IC50/EC50拥有明确区分的分类目标，并使“给药物选靶点”的排序目标直接作用于实际使用的分类分数。这是待验证的设计方向，不是已经证明能改善的方案，也未在本次结果汇报中启动。当前更有价值的外部检验是接收湿实验的真实结合结果，按冻结评分、原优先级和模型分歧分层汇总，避免反复利用现有测试面板筛选新配置。
