## 使用规则

- 当前指标优先从冻结 JSON/CSV 审计摘要读取，不从旧文档手工转抄。
- 引用归档材料时必须注明快照日期和当时的查询方向。
- 归档材料中的内部版本号仅用于追溯，不用于面向项目的统一方法命名。

仍暂留在`docs/`顶层的历史快照见`DEPRECATED_TOP_LEVEL_SNAPSHOTS_20260901_ZH.md`。它们因保留旧链接而未物理移动，但状态等同归档。
