## `reverse_query_20260822/`

该批材料把“给定靶点，在720种老药中排序”作为主任务。2026-08-25起项目主任务改为药物到靶点排序；2026-08-31进一步将745个非GPCR靶点定义为完整登记目录，将450个路由后可比较靶点定义为下一版主生产候选集，384靶点保留为已评分比较核心。因此旧版主线文档与案例PDF仅用于解释历史结论，不再作为当前汇报入口。

关联的冻结协议 `configs/biomaster_recent_quantitative_case_panel_20260820.json` 仍保留在原路径，因为历史特征构建和评分脚本依赖该路径；它不是当前主任务配置。

## 使用规则

- 当前指标优先从冻结 JSON/CSV 审计摘要读取，不从旧文档手工转抄。
- 引用归档材料时必须注明快照日期和当时的查询方向。
- 归档材料中的内部版本号仅用于追溯，不用于面向项目的统一方法命名。

仍暂留在`docs/`顶层的历史快照见`DEPRECATED_TOP_LEVEL_SNAPSHOTS_20260901_ZH.md`。它们因保留旧链接而未物理移动，但状态等同归档。
