# BioMaster 与 DTIAM 差距及优化审计

> **状态说明（2026-09-01）**：本文件是技术差距审计，不是项目唯一入口。KIRHub统一解释为1 μM功能抑制回顾性审计；当前模型角色、训练规模和384/450/745分层以`CURRENT_PROJECT_CONTRACT_ZH.md`为准。

更新日期：2026-08-27

## 1. 结论先行

BioMaster 并不是整体弱于 DTIAM。按完全一致的数据与切分复算，BioMaster 在 S1（化学骨架冷启动）和 S5（老药实体冷启动）三个 AUPRC 指标全部领先，在 S4（2023–2025 时间外推）领先 Micro 与靶点宏 AUPRC；稳定缺口集中在 S2（靶点同源簇冷启动）和 S3（严格双冷启动）。

缺口的主因不是训练未收敛，也不是简单少加了一种结构特征，而是以下因素叠加：

1. 冻结二分类数据在“给定药物找靶点”方向极度稀疏，只有约 11% 的行能形成同一药物内的正负排序监督；
2. 当前主干最初按“给定靶点排药物”组织采样、排序损失与模型选择，优化目标与当前生产问题不完全一致；
3. S2/S3 同时放大了蛋白外推和交互外推难度，而 19 维结构上下文是 target-specific，不是 drug–pocket pair-specific；
4. DTIAM 的 BerMol/ESM2 表征加多模型树集成，在中等规模、异质、稀疏的冷启动表格任务上具有很强的方差控制；
5. 强行把稀疏药物排序损失写回共享骨干，会把药物查询噪声传播到 pair 与靶点方向，受控实验已经复现了这一点。

因此，当前正确的工程结论是“双输入共享 pair 主干 + 方向独立的查询头/融合层”，而不是要求一个标量头同时在 Micro、靶点宏和药物宏三个互相不等价的目标上最优。

### 2.3 720 × 384 部署矩阵

历史部署矩阵共276,480对，由720种老药与384个已评分靶点组成。其中338个靶点有严格实验口袋，46个靶点属于无实验口袋恢复分支。该384集合现在只作为冻结比较核心；下一版主生产范围为450个有直接小分子证据且属于五类可建模实验通道的靶点，需新增评分66个。另有42个特殊体系直接证据靶点和8个高新颖性探索靶点单列；745个非GPCR靶点只是完整登记目录，不作为统一排名分母。

这张矩阵是推理候选空间，不是完整实验标签矩阵。未报告 pair 不能直接当作可靠负样本，否则会系统性惩罚真正的新作用靶点。

## 3. 当前模型与 DTIAM 的差异

### 3.1 BioMaster 主干

当前综合主干输入包括：

- 药物 Morgan 2048 位指纹；
- 蛋白 ProtBERT 1024 维与 ESM2 1280 维表征；
- 19 维蛋白结构/口袋上下文及缺失掩码；
- 低秩 FiLM 交互、6 个专家与 pair 分类/亲和力辅助任务；
- 多种子集成和验证集拟合的查询融合层。

主干约 352 万参数。19 维结构输入描述“这个靶点有什么结构上下文”，不能表达“这个药物在这个口袋中的局部几何是否匹配”。已有 47 维扩展、局部图和简单 pocket 增强没有稳定改善 S2/S3，说明缺少的是可信的 pair-specific 局部相互作用，而不是继续堆 target-only 统计量。

### 3.2 DTIAM 对照

当前 DTIAM 对照使用官方 BerMol 768 维药物表征与 ESM2 1280 维蛋白表征，在完全相同的冻结监督数据和切分上训练 11 个基学习器，并由 AutoGluon WeightedEnsemble 汇总。

这是兼容环境复训，不是论文 AutoGluon 0.5.2 环境的位级复现；但输入、监督数据和测试 pair 已对齐，足以作为强同数据对照。

DTIAM 的优势不是“网络更深”，而是：

- BerMol 对冷药物具有比纯 Morgan 更平滑的语义邻域；
- ESM2 对冷靶点同源关系有直接归纳偏置；
- 树/boosting/stacking 的异质集成对 8 万级表格数据更省样本；
- 加权集成能降低单个神经模型在冷簇上的方差。

## 4. 完全一致口径下的结果

以下均为最新五种子 BioMaster 与 DTIAM 在相同 pair 上复算的 AUPRC。

| 协议 | 模型 | Micro | 靶点宏 | 药物宏 |
|---|---|---:|---:|---:|
| S1 化学骨架冷启动 | BioMaster | 0.9307 | 0.8812 | 0.8551 |
|  | DTIAM | 0.8829 | 0.8386 | 0.8413 |
| S2 靶点同源簇冷启动 | BioMaster | 0.7939 | 0.7546 | 0.5540 |
|  | DTIAM | 0.8145 | 0.7769 | 0.5787 |
| S3 严格双冷启动 | BioMaster | 0.6425 | 0.6750 | 0.6213 |
|  | DTIAM | 0.6517 | 0.6903 | 0.6597 |
| S4 2023–2025 时间外推 | BioMaster | 0.8325 | 0.7832 | 0.8251 |
|  | DTIAM | 0.7962 | 0.7653 | 0.8333 |
| S5 老药实体冷启动 | BioMaster | 0.5569 | 0.6415 | 0.7759 |
|  | DTIAM | 0.3988 | 0.6061 | 0.7365 |

所以“没有全面超过”不能概括成 BioMaster 整体能力不足。实际是 S2/S3 的蛋白与双实体外推仍弱于 DTIAM，S4 只有药物宏一项略低。

## 5. 本轮受控优化实验

### 5.1 直接加入药物查询平衡训练：未晋级

新增了药物 query、靶点 query 与覆盖 batch 三路混合采样，并加入双方向模型选择指标。S3 fold 0 的同种子结果如下：

| 配置 | Micro AUPRC | 靶点宏 AUPRC | 药物宏 AUPRC |
|---|---:|---:|---:|
| 原统一主干 | 0.6231 | 0.6645 | 0.6790 |
| 查询平衡屏幕 1 | 0.6430 | 0.6819 | 0.6130 |
| 查询平衡屏幕 2 | 0.6361 | 0.6534 | 0.6048 |

Micro 可以提高，但药物宏明显下降。原因是药物 query 数少、长度短、重复抽样高，listwise/pairwise 梯度在共享主干中被放大，学到的是不稳定 query 偏差而不是可泛化的药物–靶点相互作用。

### 5.2 增加药物 query 多样性：只改善中后段召回

把每个药物 query 的行数由 16 降到 2，在相同步数下增加不同药物的覆盖。三种子均值显示 Recall@20 从 0.3472 提高到 0.3639，但 AP 从 0.1302 降到 0.1245，MRR 从 0.1628 降到 0.1582，不能单独晋级。

三种子按 query 做秩集成后，盲测 MRR 为 0.2038、Recall@20 为 0.4583，说明多种子稳定化有效，但不能弥补监督本身的稀疏性。

### 5.3 给组内 BioMaster 残差加权：确认集过拟合

只在 folds 0–2 选择 BioMaster 的药物内残差权重，再一次性测试 folds 3–4：

- S2 的药物宏 AUPRC 相对 DTIAM 下降 0.0496；
- S3 的药物宏 AUPRC 相对 DTIAM 下降 0.0562。

这直接证明开发 query 上看似更好的方向权重不能稳定迁移，继续搜索权重会扩大选择偏差。

### 5.4 方向保持校准：内部有效，但部署压力测试失败

方向保持校准只改变每个药物 query 的常数偏置，严格保留 DTIAM 在同一药物内的靶点顺序。folds 0–2 选参、folds 3–4 确认时：

| 协议 | DTIAM Micro | 校准 Micro | DTIAM 靶点宏 | 校准靶点宏 | 药物宏 |
|---|---:|---:|---:|---:|---:|
| S2 | 0.8168 | 0.8262 | 0.7820 | 0.7896 | 0.6326 → 0.6326 |
| S3 | 0.6630 | 0.6936 | 0.6918 | 0.7089 | 0.7002 → 0.7002 |

锁定系数不经 S4 调参直接迁移到 2023–2025 数据，Micro/靶点宏从 0.7962/0.7653 提高到 0.8218/0.8004，且 bootstrap 支持提升。

但是，把相同方法放入完整 384 靶点候选集后，严格 KIRHub Micro AUPRC 从 0.1755 降到 0.1083，靶点宏从 0.3041 降到 0.2690。原因是其药物均值依赖当前候选集合；冻结 benchmark 与完整 384 靶点矩阵的候选分布不同。

结论：该方法保留为“为什么三个评价轴冲突”的机制诊断，不进入生产排序。

## 6. 当前可用的生产方案

### 6.1 给定老药找靶点

采用冻结 S5 验证集拟合的 DTIAM–BioMaster routed fusion，特征只来自同数据监督模型与训练集派生的相似度/先验，不使用 KIRHub 标签拟合。

严格 S5 测试：

| 模型 | Micro AUPRC | 靶点宏 AUPRC | 药物宏 AUPRC |
|---|---:|---:|---:|
| DTIAM | 0.3988 | 0.6061 | 0.7365 |
| DTIAM–BioMaster routed fusion | 0.5789 | 0.6674 | 0.7709 |

其 Micro AUPRC 相对 DTIAM 提升 0.1801，按药物实体 bootstrap 的 95% CI 为 0.1183–0.2420。

严格 KIRHub 未报告作用对上的点估计：

| 模型 | Micro AUPRC | 靶点宏 AUPRC | 药物宏 AUPRC |
|---|---:|---:|---:|
| DTIAM | 0.1755 | 0.3041 | 0.3867 |
| DTIAM–BioMaster routed fusion | 0.1913 | 0.3457 | 0.4027 |

三项点估计均提高，但KIRHub只有33个双标签药物，配对bootstrap的95% CI仍跨0。因此可作为当前生产候选证据，不应宣传为“确认性显著超过DTIAM”。

### 6.2 给定靶点找老药与通用 pair 分类

继续保留 BioMaster 多种子 pair 主干和靶点方向排序头。S1、S4 与 S5 已显示它在这些方向上的独立价值。DTIAM 或验证融合是系统层辅助证据，不应改写成“BioMaster 单模型全面 SOTA”。

## 7. 下一阶段应如何真正突破 S2/S3

优先级从高到低：

1. 构建固定 canonical target panel。所有药物偏置都在同一固定靶点面板上估计，消除候选集均值漂移；
2. 为 720 老药构建 positive–unlabeled 排序数据。已知作用为正，明确失活为高置信负，未报告 pair 只作为低权重未标注项，不能全部硬标负；
3. 独立训练药物→靶点查询头。共享编码与 pair 分类头，ranking head、sampler、early stopping 和 calibration 分离；
4. 用 cross-fitted DTIAM/多种子 BioMaster 软标签蒸馏查询头，避免在测试折或 KIRHub 上选权；
5. pair-specific 结构仅在有可信复合物/对接姿态时加入。候选特征应来自药物–口袋接触图、相互作用指纹、几何距离与姿态置信度，并通过缺失掩码回退；
6. 新增真正未使用过的 source-held 老药–靶点集合。KIRHub 已被项目多轮审视，只能作为 post-freeze 审计，不能继续承担模型选择。

## 8. 当前声明边界

- BioMaster 单模型：在 S1、S5 全面超过当前 DTIAM 兼容复训；S4 两项领先；S2/S3 尚未全面超过。
- 系统层：DTIAM–BioMaster 验证融合在 S5 显著提高，并在 KIRHub 三项点估计均提高。
- 方向保持校准：冻结确认与时间迁移有效，但完整候选集部署失败，不晋级。
- 结构输入：19 维为靶点结构上下文，不等于 drug–pocket pair-specific 结构证据。
- 回顾性结论：KIRHub样本量有限且已被项目检查过，当前只支持功能迁移候选排序与下一来源确认，不支持确认性SOTA声明。
