# 当前 SPR384 质量与9月BindingDB验证的联合评价

**判断：这是一批有模型筛选依据、具有跨领域探索价值、但质量不均匀的待验证候选。新的回顾性结果提高了对排序器的信心，足以支持从优先部分分批启动；不足以把384整体称为高命中率、已验证或最优组合。** 本次只读分析，没有重训、更换排序器、重排候选或改动网站。

## 1. 先澄清“9月份新数据”

BindingDB按月发布累计更新文件，并分别提供实验来源发表日期和入库日期，发布月份不能当成实验发生月份。[BindingDB官方下载说明](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp)

对本次479对有BindingDB Kd/Ki覆盖、训练配对未出现且可二分的切片，实际检查了对应来源日期：

- 1,236条有发表日期的来源记录，范围1993-12-28至2025-07-08。
- 1,278条有BindingDB日期的来源记录，范围2006-05-02至2026-06-06。
- 这些已提供日期的记录中，没有2026年9月新增发表或入库记录。该结论仅针对本次评价切片，不能推断整个9月BindingDB没有新增数据；缺日期的记录也不能当作新或旧。

因此，正确说法是“在9月快照中提取的历史亲和记录上做回顾性验证”，不能说“模型在9月新实验上得到前瞻验证”。本地训练配对/连接骨架配对未出现，也不代表新药物、新靶点、新骨架或所有外部预训练零泄漏。

## 2. 表现确实有信号，但要看对模型和样本

正类为Kd/Ki不高于1 µM，弱结合负类不低于10 µM；灰区、冲突、不确定上下界排除。没有报告的配对不作负类。BindingDB切片沿用此前合并ChEMBL等来源后的冲突审查标签，因此叫“BindingDB覆盖切片”，不是只用BindingDB单来源标签。

| 验证范围 | 配对／正类／弱负 | 当前SPR排序 AUROC / AP | FULL_FIT神经头 AUROC / AP |
| --- | --- | --- | --- |
| 原合并来源，训练配对未出现 | 488 / 133 / 355 | 0.747 / 0.622 | 0.855 / 0.715 |
| 本次明确有BindingDB Kd/Ki记录的切片 | 479 / 125 / 354 | 0.734 / 0.585 | 0.850 / 0.690 |
| BindingDB切片再通过项目身份与化学规则 | 382 / 94 / 288 | 0.781 / 0.620 | 0.827 / 0.646 |

479对覆盖76药、107靶点，正类比例26.1%。当前排序器的AP高于该比例；按药物分组的1,000次bootstrap给出AUROC 95%区间0.667–0.815。可以说当前排序器对这批已测记录具有区分能力，而不是没有筛选信号。AUROC不是准确率或预期实验命中率。

此前约0.85的AUROC属于FULL_FIT神经头，而当前384是按independent_validation_rank_score筛出的。不能把神经头的0.85直接归给当前384。两者任务指标和排序不同，神经头更高的全局成绩是后续比较线索，不能仅凭本次看过的评估就换生产模型并继续称独立验证。

## 3. 最贴近实际实验资源的观察：前10名更值得优先

按每药完整384靶点的当前SPR排名，对479对验证切片分层：

| 排名段 | 有合格标签的配对 | 正类 | 弱负 | 已测子集正类比例 |
| --- | ---: | ---: | ---: | ---: |
| 1–10 | 53 | 42 | 11 | 79.2% |
| 11–20 | 19 | 6 | 13 | 31.6% |
| 21–384 | 407 | 77 | 330 | 18.9% |

前10较强的富集是积极信号，支持优先投入前10中没有具体前置问题的部分。11–20样本只有19对，且药物/靶点及实验分布不同，不能把它们与前10的差异当成已经证实的因果效果，也不能直接删掉11–20。

尤其不能把79.2%或31.6%乘上候选数来预测命中数：分母只包含已有标签的配对，有文献和研究选择偏倚；我们的384则经过已知关系排除，分布不同。

## 4. 当前384的质量构成

| 维度 | 当前状态 | 实际含义 |
| --- | --- | --- |
| 覆盖 | 229药、112靶点 | 覆盖广，蛋白体系准备分散 |
| 当前SPR前10 | 179对，46.6% | 排名利用部分 |
| 当前SPR第11–20 | 205对，53.4% | 相对探索部分；仍属于每药前5.2% |
| 最新审查仍可探索 | 223对，58.1% | 没有据现有材料提前否决，不等于已测通 |
| 先解决具体问题 | 149对，38.8% | 逐项区分构建、实体、疾病方向等问题 |
| 有证据支持降低投入 | 12对，3.1% | 先读反证适用范围，不与其他候选等权投入 |
| 推荐疾病跨原用途大类 | 195对，50.8% | 有跨领域探索价值，不证明治疗方向 |
| 可用阳性近邻Tanimoto≥0.4 | 20对，5.2% | 大部分缺乏较强的这类化学近邻支持 |
| FULL_FIT神经头也排前20 | 78对，20.3% | 有一部分排序一致；模型相关，不能当独立双重验证 |
| 本次合格亲和证据直接覆盖384 | 0对 | 这384对的结合仍待实验回答 |

冻结时有240条（62.5%）属于独立支持有限的探索；模型、图谱和LLM三层并不等于三次独立结合验证。TxGNN与Open Targets主要补充疾病与机制解释价值，其加入能否提升实际SPR命中率，需要实验对比，现有结果没有证明这一点。

当前100条P1对应“前10且仍可探索”，涉及83药、53靶点。P2有123条，P3有149条，P4有12条。P1的100条中29条同时位于神经头前20；它们可以作为额外人工复核线索，但不是本次重新选出的更优子集。

## 5. 验证能否外推到未知关系：最关键的限制

BindingDB验证切片与当前384仅共享23/229种候选药、46/112个靶点，没有精确配对交集。因此整体AUROC不能直接校准每个候选的成功率。

如果进一步排除此前所有已知关系旗标和既有ChEMBL数值，BindingDB覆盖切片只剩78个可二分配对，全部为弱结合负类，没有正类可检验新关系发现能力。它们中的75对位于当前排名20之外、3对位于前10；这一事实也不能用作384的阴性结论。此前合并来源的严格切片多出的1个正类来自HiQBind，而不是BindingDB。

这说明：我们现在有更好的“历史未训练配对排序”证据，仍缺“真正新关系命中率”的前瞻校准。两者必须分开报告。

## 6. 对实验投入的建议

保留384作为实验候选库；不因回顾性成绩不错就把所有配对视作同等把握。首先从P1的100对中，按实际已测通的靶点和共同体系分批启动，再逐步纳入P2中有清楚机制假设、适合验证的问题。首批具体名单需结合实际蛋白状态，不能仅按CSV前若干行机械截取。

149条前置问题中，疾病方向不确定未必阻止纯蛋白结合实验；实体不一致、构建缺失结合域或对照未测通则直接影响实验是否可解释。12条降低投入者保留明细，但不与P1等额投入。

前一轮FDA对照修订改善了31靶点/84候选行的对照可追溯性和准备方案，不会自动增加候选本身的结合概率。FDA身份不是适用构建或实测活性的替代。

首批实测结果应区分初筛响应、重复可确认的结合、浓度依赖/竞争支持与功能结果。以实际可解释的实验配对为分母报告命中，并保留无效体系记录。若研究还要证明模型优于随机选择，需要预先安排匹配背景配对；已知阳性对照只能帮助验证体系，不能替代模型富集对照。
