# 蛋白—分子—亲和三元 JEPA 设计讨论（2026-09-14）

用户澄清的目标是联合建模 `(P, M, A)`：蛋白、分子、亲和，而非优先替换成现成 Mol-JEPA 分子表示。之前的表示替换路线不再作为实现本目标的前置条件。本页是设计草案，尚未启动新训练；已有 DTIAM 继续按冻结协议运行。

建议将主体定义为带亲和监督的条件 JEPA：学习蛋白和分子的交互表示，并由实测亲和锚定。蛋白/分子的预训练编码器可复用，联合编码器与预测器由我们的三元组训练。含亲和标签的部分属于监督或混合监督，不能称纯无监督。

| 条件 | 希望推断的对象 | 用途 |
|---|---|---|
| P、M | A 的条件分布或区间 | 对候选配对预测强弱与不确定性 |
| P、期望 A 范围 | 候选库中的一组 M | 针对蛋白筛选分子 |
| M、期望 A 范围 | 候选库中的一组 P | 寻找新靶点或潜在脱靶 |

后两项多解：单个蛋白和亲和范围不足以唯一确定一个分子，反向亦然。第一版通过逐候选评估共同交互模型来检索；若训练整模态反向预测，需多解/集合或条件分布目标。不能用单个真实对象的向量均方误差，强迫模型对本来多解的问题输出唯一对象；也不能把批内所有其他药物或蛋白自动当成阴性。

**A 的定义。** 以 pKd 为直接结合主目标，pKi 作为独立端点监督；两者都取 `-log10(浓度/M)`，但保留测量类型。IC50/EC50 属于活性任务，单独标记和解码，不混为同一个物理亲和值。端点、实验编号/条件、蛋白构建和来源可作为三元组附带上下文 C；缺失条件明确标记，推理时只使用实际可得条件，不能依赖实验后才知道的信息。

**第一版可实现结构。**

- 蛋白 P：已有 ESM2 表示起步；若采用残基/口袋掩码，需要另外准备相应 token/结构输入，现有池化向量不能冒充残基级数据。
- 分子 M：已有 BerMol/DrugCLIP 或分子图表示起步，选择一种作为固定基线。
- 亲和 A：端点标记＋连续 p 值/界限编码，保留物理大小顺序，不能只变成阳性/阴性 token。
- 联合交互模块：编码 P、M 及允许的 C，学习条件交互表示。学生分支预测缺失的亲和表示；亲和目标编码器提供停止梯度的目标，并由数值重建约束维持其物理意义。必要时使用 EMA 和方差约束等防塌缩机制，不能只用“有停止梯度”证明不会塌缩。
- JEPA 辅助任务：在有足够上下文时，结合 A 预测被遮蔽的分子局部/蛋白局部表示；完全遮蔽整模态的多解任务作为后续扩展。推断 A 的学生路径始终不能看到该配对真实 A，教师和辅助任务也不能读入留出标签。
- 推理：只需 P、M 及可得上下文，输出 A 的预测分布或区间。分布头给出的不确定性必须通过保留集覆盖率/校准检验，不能自动称为可信置信区间。

JEPA 的一般思想是预测缺失部分的表示，掩码必须保留足够信息。[I-JEPA 原论文](https://arxiv.org/abs/2301.08243)。上述三元关系设计是我们的研究方案，不是该论文已经验证的药物—靶点实现。

**与普通回归的区别必须用消融检验。** 仅把单个标量 A 编成向量再预测，仍非常接近标签嵌入回归，未引入额外实验证据。研究价值应来自亲和条件下的交互表示、有效的局部掩码预测以及对多种可靠观测的联合利用；不能因为名字是 JEPA 就宣称优于回归。

建议训练目标由数值/区间监督、潜在表示预测、防塌缩及真实失活辅助组成；系数和采样方案须在正式启动前确定。定量与失活必须按信息含量处理：

| 观测 | 正确使用方式 |
|---|---|
| 精确 Kd/Ki | 分端点的连续亲和监督及亲和表示目标 |
| `Kd > 10 µM` | `pKd < 5` 的单侧区间监督，不伪造精确 pKd=5 |
| 只有 inactive 注释 | 保留来源条件的辅助分类监督，不凭注释构造一个任意 Kd |
| 未测配对 | 无亲和监督；不当阴性，也不补假 A |
| IC50、EC50 | 独立活性端点；可共享表示，保留端点差异 |

现有训练回归文件实测：

| 端点 | 合格配对—端点记录 |
|---|---:|
| Kd | 26,984 |
| Ki | 203,056 |
| IC50 | 654,644 |
| EC50 | 95,381 |
| 合计 | 980,065 |

Kd/Ki 合计 230,040 行，涉及 228,686 个不同配对；全端点合计涉及 943,483 个不同配对。这些是训练部分经过现有 QC 的聚合回归目标，不是独立实验数，也不能与此前二分类配对数直接相加。删失观测及仅失活注释另保留在证据表，尚需整理成该设计的训练视图。没有把验证和测试成员加入本次计数。

数据规模支持复用预训练编码器、训练三元交互模块的首轮研究；这是工程可行性判断。需要再审计数据身份、端点/单位、上下界、重复来源、实验上下文和泄漏。蛋白独立身份数远少于配对数，模型评估应保留现有骨架划分并补充靶点同源簇冷启动和严格来源诊断，不能靠记住蛋白身份获得漂亮分数。

**最小比较。** 相同数据、编码器与相近计算预算下：①直接连续/区间亲和模型；②加入亲和 latent 预测；③再加入亲和条件的有效局部掩码任务。分别报告各端点误差、双向排序、低失活误报条件下召回及不确定性校准。它们是预定的研究对照，不覆盖当前 DTIAM 六套冻结实验；最终选择不依据反复查看 TEST。

第一版建议以 Kd/Ki 为主、保留真实失活约束，IC50/EC50 作为分端点扩展。先验证三元关系建模本身是否改善泛化，再决定是否加入结构数据或扩大编码器训练。这与用户提出的 `(P,M,A)` 目标一致，无需先下载 Mol-JEPA 全部预训练数据。
