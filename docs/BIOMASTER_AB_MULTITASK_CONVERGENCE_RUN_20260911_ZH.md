# A/B四种目标的收敛训练：解释、协议与启动记录

2026-09-11。用户授权比较A/B的“仅二分类、加排序、加回归、两者都加”，训练到验证平台期，先启动并报告ETA。

## 1. 150对上限有道理，为什么现在又显得不理想

**历史方法有价值，历史测试仍成立；当前出现了不同评分系统之间的排名分歧，尚无384对的湿实验结论证明旧推荐整体错误。** 需要把几个问题分开。

第一，150是每个靶点的每类标签上限。历史准备过程还偏好不同化学骨架，这有助于减少热门靶点和大量相近分子占据基准。由此得到的86,674对基准并非当时全部可用数据；S5再留出测试老药及其骨架、验证集和不可用特征，得到65,276训练对。减少数量换取更均衡的覆盖有合理性，不能简单认为样本越多每一种能力就越强。

第二，取消上限后，增加的数据可能集中在热门靶点、特定实验类型和相近分子。二分类可以先学到这些数据中的靶点阳性率，而不一定同步改善“固定一个老药，在许多新靶点中挑前几名”的能力。前轮诊断中，仅靶点训练阳性率的基线在完整Kd/Ki测试面板已有约0.9125的AP，而A约0.9357，说明总体AP需要结合查询内排序、分层表现解读；这不能证明A只学了先验。

第三，原384使用历史神经＋阳性化学近邻＋靶点先验的组合，后面还有图谱和逐对审核。仅从完整评分中拿出原神经分量，原384中药物内Top20就从384对降到148对。这是同一批候选对评分组成的敏感性，不能作为原组合更准确的独立验证，但足以说明“换评分后保留少”并不等于“原实验推荐全错”。

第四，过去测试的是特定留出条件下的模型/组合。后来的383,638对生产模型与历史65,276对模型也不是同一版本。不同版本、数据范围、端点混合、辅助损失与评分组合一起改变，不能把全部差异归因于新数据或旧数据不足。当前A/B在部分已测数据上确有提升，跨靶点排序、稀疏查询与新靶点外推仍需分别评估。

第五，上一轮A/B只完成固定6000步，缺少训练中验证与早停记录，不能视为各自优化充分的最终比较。历史S5已有靶点内排序和混合pChEMBL回归辅助，当前A/B却仅用二分类，这也是需要单独检查的差异。

因此，本轮保留完整A/B训练成员，在排序辅助中采用查询均衡采样，延续防止热门靶点主导的考虑；不同时加入新的150对截断或改变二分类采样规则，以便解释目标变化。将来若比较“截断、每靶点加权、全量”，应另设消融。

## 3. 目标和样本组织

- 二分类：与原A/B相同，1024对/步，全局类别平衡BCE，两路输出使用相同标签；洗牌遍历全部行后再重复。明确失活保留，未知关系不作为负例。
- 排序：固定靶点排序药物，以及固定药物排序靶点。每个数值任务、每个方向每步抽2个具有实测正负的查询，各抽16个正例和16个负例；不足16个时只在该实测类别内重复抽样。每个查询及任务等权，采用正负逐对softplus损失。
- 任务分池：A为Kd/Ki，B分别为Kd/Ki、IC50、EC50。Kd/Ki仍是现有的合并二分类任务；同任务不保证同实验条件。没有端点归属的明确失活不强行分配到各端点排序池。
- 回归：A分别输出pKd、pKi；B另加pIC50、pEC50。每端点每步抽128条现有训练成员内的精确记录，端点分别用训练数据标准化，Huber损失按端点等权。缺失端点不填0，删失界限与无数值失活不编造精确值。

本轮固定预注册起点：靶点排序、药物排序、数值辅助权重各0.1，温度1。它们不是已经搜索证明的最佳权重；本轮先回答这些目标组合是否有用，避免同时改变更多因素。端点记录及查询数见`SUPERVISION_COUNTS.csv`。

## 4. “训到收敛”的可检查定义

这里采用**验证平台期**的操作标准，不声称数学上的全局最优：

1. A每1000步验证，B每2181步验证；B的间隔约为两次完整数据遍历。
2. 固定使用公共Kd/Ki验证集。查询需至少10条实测配对且同时有正负，得到519个靶点查询、38个药物查询。主指标为这两个方向macro AP的等权平均。
3. 初始学习率3e-4，前200步预热。主指标连续4次验证未获得大于0.0002的改善，学习率减半，最低5e-6。
4. 至少完成10次完整训练遍历；连续12次验证无上述改善，并在该平台期经过至少2次学习率下降，才早停。已经处于最低学习率时无需再要求不可能的下降。
5. 保存主指标最高的EMA检查点，记录最佳步数与实际停止步数。同步记录分类AP/AUC、两个方向P@5/P@10/P@20、失活误报率和分端点回归MAE/RMSE。

P@20仅对至少20条配对的查询计算，其分母另行报告。失活误报率使用当前Kd/Ki验证集最大F1阈值；其变化不能直接当作SPR失败概率。未启用回归的随机回归头结果明确标记为`auxiliary_trained=false`，不能当作已训练的亲和预测器。

设置每次200,000步的异常保护。若仍未满足平台期条件，输出`NOT_CONVERGED_NEEDS_EXTENSION`并停止队列报警，绝不把达到上限记作收敛。正常的最佳/最近检查点、优化器、EMA、二分类/辅助采样状态和随机数状态均可恢复。

公共测试面板已在此前研究中查看过，本轮是固定协议下的后续比较，不是新的、从未触碰的前瞻测试。原SPR名单、参考对照与生产模型保持冻结。
