# 原384保留率低的原因，以及A/B与DrugCLIP、DTIAM的一致性

2026-09-11。复用已经冻结的分数，完成同范围、同身份轴的排名一致性审计，并让DTIAM重跑固定112靶点名额的反事实选择。未训练新模型、未修改实验清单或网站。

**当前证据显示：原384依赖特定历史排序与选样规则，跨模型稳定性有限；不能把它称为各模型共同确认的高命中率名单。但“新模型不选”不等于实验阴性，现有结果也没有证明原推荐全部错误。**

## 1. 为什么A/B只保留41/51对

此前的41/51不是只更换一个模型后、完整复刻原选样流程的结果。原384来自历史 `independent_validation_rank_score`，其中包含旧BioMaster logit、训练阳性近邻相似度和靶点先验，再经每药Top20、图谱同病证据、审核、跨领域和资源配额选择。

上一轮反事实实验固定112个靶点及各靶点名额，但将选择目标改成靶点内模型排名；取消原药内Top20硬门槛，也不再使用原化学/跨领域证据的加权效用。这同时改变了模型、排序方向与选择目标。

| 使用分数，均按固定112靶点名额重选 | 原384保留数 |
|---|---:|
| 原历史组合分数 | 171 |
| 旧生产神经模型 | 57 |
| A三种子共识 | 41 |
| B三种子共识 | 51 |
| **DTIAM兼容重训版，本次补测** | **56** |

DTIAM同样只保留56，说明低保留不是A/B独有现象。不过，这并不能排除模型本身能力不足：名单对评分与规则的敏感性是真实的，需要在结果中明确保留。

DTIAM两次重选（冻结排除条件、再加九月精确既有证据排除）均为56对；固定靶点名额、每药/连接结构最多4对、至少128种药均相同。所选384中61项属于原574审核范围，其他项不能当作已通过逐对审核。

## 2. 外部模型版本和覆盖

- **DTIAM**：项目已有的官方表征兼容AutoML/S5重训版本，完整720药×384靶点；不是在本次同训练集上重新训练的官方最优模型，历史训练曝光也不同。
- **DrugCLIP**：现有六折均值cosine口袋检索分数。经精确规范SMILES和精确蛋白序列映射，共同完整矩形为 **548药×269靶点＝147,412对**。
- DrugCLIP可比较的当前384候选为 **272对，覆盖172种药、86个靶点**；其余112对缺少这条可比评分路线，不记为负面投票。
- A/B为上一轮的三种子验证校准分数均值，仅用于研究一致性分析。旧神经模型按方向使用相应输出。历史组合分数本来主要面向药物→靶点；其逆向重排只作诊断。

DTIAM、A/B和旧神经模型可能共享数据或公共编码器；A/B还使用DrugCLIP分子表征。因此，“多模型同意”也不是多份完全独立的实验支持。

## 3. 同一候选范围内，前20名单重合多少

下表全部限定在同一 **548药×269靶点**，每个查询先取各模型前20，再计算交集并对查询平均。药物→靶点每次从269个靶点选20；靶点→药物每次从548种药选20。这里是**平均共同项数/20**，不是阳性命中率，也不是384保留率。

| 两个模型 | 药物→靶点平均共同项数 | 靶点→药物平均共同项数 |
|---|---:|---:|
| A 与 DTIAM | 2.99 / 20 | 2.03 / 20 |
| B 与 DTIAM | 5.10 / 20 | 4.57 / 20 |
| A 与 DrugCLIP | 1.95 / 20 | 0.64 / 20 |
| B 与 DrugCLIP | 1.96 / 20 | 0.85 / 20 |
| DTIAM 与 DrugCLIP | 1.55 / 20 | 1.01 / 20 |

如果两个前20集合独立均匀随机抽取，平均交集分别为 **1.49 / 0.73项**。这只是数学参照，不是经过化学/靶点结构校正的统计显著性检验。

完整排名的平均Spearman也支持这个描述：A/B对DrugCLIP，药物方向为 **0.0377 / 0.0657**，靶点方向为 **0.0015 / 0.0042**，一致性很弱。A/B对DTIAM分别为药物方向 **0.1553 / 0.2790**、靶点方向 **0.2506 / 0.3081**。B相对更接近DTIAM，但远未达到同一套名单。

因此，不能用DrugCLIP作为裁判，简单判定其余模型错误；DTIAM本身也与它明显分歧。它们的输入、训练目标、口袋表示与覆盖不同，模型间差异不是直接结合证据。

## 4. 当前384获得了多少额外排名支持

为公平比较，下表统一使用DrugCLIP可覆盖的 **同272对**，也统一在每药 **269个共同靶点**或每靶点 **548种共同药物**中重新排名。

| 模型 | 当前272对中，药物→靶点Top20 | 当前272对中，靶点→药物Top20 |
|---|---:|---:|
| 原历史组合分数 | 272 | 66 |
| 旧神经模型 | 65 | 19 |
| A | 53 | 7 |
| B | 49 | 7 |
| DTIAM | 60 | 6 |
| DrugCLIP | 37 | 16 |

原历史组合分数的272/272是筛选机制决定的，不能作为独立验证成绩。同272对中，DTIAM与DrugCLIP在药物→靶点方向共同排前20的有 **8对**、至少一个排前20的有 **89对**。这些是相对排名支持，不证明相应结合，低排名也不是明确失活标签。

作为完整范围补充，在全部720药×384靶点中，当前384的药物→靶点Top20数分别为A **50**、B **49**、DTIAM **53**。这些数字与上表不同，是因为上表将所有模型的排名分母共同缩小了，不能混用。

另一个重要限制：上述原始完整排名包含已知结合关系；当前384则刻意排除了很多既有关系，并加入新用途和实验可行性取舍。因此，不能要求所有新颖性候选都在未经排除的全模型原始Top20内。但这也不能自动为低排名提供正面证据。

## 6. 对原推荐应该如何定性

可以确认的是：原名单对历史组合评分及规则依赖较强，跨模型稳定性不足；现有评估不能支持“384已经有很高成功把握”。此前说明应当更清楚地区分整体分类性能、逐查询排序能力与实验名单可靠性，以及历史排序器与旧生产神经检查点。

仍不能确认的是：哪些具体配对真实不结合，或者原推荐“全错”。AP、模型交集、未进入Top20和未被配额选择都不是该配对的实验阴性。一个模型投票否定另一个模型不能取代亲和测量。

对已启动实验，保持已冻结名单及所有有效结果完整回收，附加本次A/B/DTIAM/DrugCLIP分组和可比性标记。先按预先记录的方向和靶点分层评价真实SPR结果，再决定下一轮训练或追加候选。当前不应根据模型分歧直接替换为另一批尚未逐对审核的新名单。
