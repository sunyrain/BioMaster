**ODTI V4 R1测试集审计与汇报更正（2026-09-06）**

**本次确认了评测选集与“项目老药找新靶点”任务不匹配的问题。** 上一轮1,024×495表示候选评分范围，并非密集实验测量面板；所选1,024个一般化合物与项目720老药清单按InChIKey和模型SMILES精确匹配均为0。不能把该结果作为老药新靶点发现能力的主要评价，也不能仅据此决定采用近邻主导架构。

旧指标和预测未被修改。这次审计区分了可复核的分数、评测覆盖问题和结论范围；没有产生一套“纠正后”的模型排名。

**实际使用的数据**

入口是[综合关系表](../outputs/retrain_20260901/comprehensive_training_v1/COMPREHENSIVE_TRAINING_RELATIONS_V1.csv.gz)，经过旧V3二元观测过滤及实体去重得到[RELATIONS_V3.csv.gz](../outputs/biomaster_v3_20260905/data/RELATIONS_V3.csv.gz)。其中BindingDB affinity-only行的`binary_observed=0`，未进入本轮二元训练或测试。

按化学实体InChI/标准化特征关联分组后做SHA256哈希80/10/10划分，得到训练342,031条、验证43,331条、测试42,032条。它不是时间、骨架、文献或assay独立切分。完整实测测试集有28,874个化合物，32,649条阳性和9,383条阴性；来源为42,016条ChEMBL37综合关系和16条ChEMBL37补回关系。

标签沿用历史ChEMBL校准定义：聚合pChEMBL均值≥6且无冲突标为阳性，≤5或明确inactive且无冲突标为阴性；灰区和冲突排除。上游数值记录以Ki/Kd/IC50为主，明确inactive路线另包含多种测量类型。跨端点、跨实验聚合尚未重建，不能当作同一实验条件下的统一亲和力标签。

本轮未使用DTIAM或DrugCLIP论文的标准测试协议，也没有新跑KIRHub/DAVIS外部测试。

**1,024×495面板如何产生**

从测试集“至少有一个阳性”的化合物中，按`SHA256(V3_DENSE:drug_feature_index)`排序取前1,024个；495个候选是当前全部二元关系出现过的靶点索引并集。只把这些化合物已有的阳性关系标为检索相关项。候选数量固定，但不要求每个候选都有实测标签，也未按项目720老药名单选查询。

| 核查项 | 实际数量 |
|---|---:|
| 评分配对 | 506,880 |
| 有观测标签的配对 | 1,365 |
| 已知阳性 | 1,322 |
| 已知阴性 | 43 |
| 没有观测标签 | 505,515（99.73%） |
| 只有一条实测关系的化合物 | 823 / 1,024 |
| 只有一个已知阳性靶点的化合物 | 847 / 1,024 |
| 同时有阳性和阴性观测的化合物 | 29 / 1,024 |
| 与项目720老药的InChIKey精确匹配 | 0 |
| 与项目720老药的模型SMILES精确匹配 | 0 |

这1,365条观测全部来自`chembl37_comprehensive`。老药匹配结论限于上述当前标识，未据此断言所有化合物都不属于任何批准药物，也未完成额外盐型/别名身份解析。完整42,032条实测测试集中能匹配到54个项目老药，但本次抽取的1,024化合物面板没有命中。

因此“完整面板AP”应表述为**候选全集上的稀疏已知阳性检索AP**。训练没有把未知当阴性，但在这个排名指标里，未知靶点排在已知阳性前面仍会降低AP。例如只有A被记录为阳性时，把尚未验证的B排第一、A排第二会得到AP=0.5；即使B将来被实验证实，该旧标签指标也不会给它阳性计分。仅注明“未知是背景”不能消除这种不完整标签造成的限制。

**为什么近邻容易取得高分**

| 与训练支持的重叠 | 数量 |
|---|---:|
| 测试化合物的骨架在训练集中出现 | 768 / 1,024（75%） |
| 与某个训练阳性化合物的最大Morgan相似度≥0.7 | 912 / 1,024（89.06%） |
| 最大相似度<0.4 | 3 / 1,024 |
| 与训练阳性具有完全相同Morgan指纹 | 90 / 1,024 |
| 上述90对中去除立体化学后结构相同 | 80 / 90 |
| 已知阳性与同靶点最近训练阳性参照共享文献 | 1,197 / 1,322（90.54%） |
| 已知阳性与同靶点最近训练阳性参照共享assay | 1,192 / 1,322（90.17%） |

没有相同实体并不等于模型输入表示、骨架、化学系列或实验来源独立。该测试包含大量同一实验系列的相近化合物，正近邻利用训练阳性恢复这些稀疏记录很有效。上述事实与其高分一致，但本次未通过重新切分训练做因果消融，不能给每种重叠分配独立的分数贡献。

**有没有直接的数据泄漏或计分错误**

独立检查了完整测试面板的12,680,192条有效支持记录：非训练集/错误靶点/错误标签支持为0，同一化学实体支持为0。已保存的近邻分数与支持缓存中最大正Tanimoto逐项完全相同。没有发现这些范围内的直接测试标签泄漏；这不等于排除了所有数据处理或公共预训练语料重叠风险。

当前确认的是评测设计和任务覆盖问题，不能为迎合质疑而声称0.962算错；同样也不能把0.962解释为真实新靶点预测已接近完美。这个开发测试已在V3使用过，也不是新的确认性留出集。

**需要更正的结论和后续验证顺序**

上一轮指标只支持：在当前一般化合物、稀疏已知阳性重找任务中，近邻优于这些已训练模型。它不支持“预训练/结构交互没有价值”“近邻更适合真正的新靶点发现”，也不足以据此把检索主导确定为下一版架构。

后续应先为不同问题固定合适的评测：

- 老药找新靶点：明确项目老药查询清单、既有靶点排除规则和按原始记录年份构建的训练截止点，评估截止后独立确认的新增关系；未知预测需单列待验证，不能伪造阴性。
- 选择性：使用同一实验体系下覆盖足够靶点、包含真实阴性的测量面板；按端点、浓度及实验条件定义标签。KIRHub可以做功能任务开发，但项目已查看过，不能重新称为未触碰外部确认集。
- 新化学空间和新靶点：分别使用骨架/相似度与靶点同源组划分，并审计文献和assay来源；所有支持库只由对应训练折重建。
- 对照：在相同有效覆盖范围、切分、候选集合和标签规则下运行DTIAM、DrugCLIP、近邻与新架构，区分化合物池化表示基线和真正的局部几何交互模型。
