# 训练数据规模口径：BioMaster、DrugCLIP 与 DTIAM

本说明对应本地 ChEMBL37 与 BindingDB 202609 全量联合整理。**数据库测量数、独立配对数、具体模型的监督训练样本数和无标签预训练规模，不能直接比较。** 数据多也不能直接推出模型更强。

## 论文实际使用的口径

| 模型 / 阶段 | 论文给出的规模与范围 | 与本次全库整理的差别 |
|---|---|---|
| DrugCLIP 2023：PDBbind 基础数据 | PDBbind 2019，超过 17,000 个蛋白—配体复合物；另有 HomoAug 同源增强 | 复合物/口袋配对，对比学习；不是百万条标量亲和力回归 |
| DrugCLIP 2023：扩大数据版本 | BioLip 过滤后 122,861 个蛋白—分子配对；论文另比较 ChEMBL 扩展版本 | 论文区分 DrugCLIP-S/M/L，不能把全部版本或公开权重都说成只用约 1.7 万条 |
| DTIAM：监督 DTI 基准 | Yamanishi_08 有 5,127 条已知相互作用；Hetionet 有 49,942 条 | 这些是基准已知关系总数，不能直接叫每次划分后的训练行数，也不包含所有负例处理 |
| DTIAM：分子预训练 | GuacaMol 约 160 万个分子 | 无标签分子预训练，不是 160 万个已测定药物—靶点亲和力 |
| BioMaster 当前生产模型 | 本地实际训练文件 383,638 个二分类配对，覆盖 362 个有监督标签的靶点 | 是我们已有监督模型的实际规模；本次整理不会自动改变该模型 |
| BioMaster 本次全量整理 | 人源单蛋白，不再受项目 720 药、384/888 靶点名单限制；具体最终数量见生成报告 | 同一配对可能有多个测量、多个端点、多个数据库转载，先归并，再按任务划分 |

DrugCLIP 规模及版本来自 [NeurIPS 2023 原论文 §3.4、§4.5](https://papers.neurips.cc/paper_files/paper/2023/file/8bd31288ad8e9a31d519fdeede7ee47d-Paper-Conference.pdf)。公开仓库说明其训练包为 PDBbind 与 HomoAug 组合，不能据此认为覆盖论文所有扩展版本：[官方仓库](https://github.com/bowen-gao/DrugCLIP)。DTIAM 的基准与预训练说明来自 [Nature Communications 2025 原论文 Methods](https://doi.org/10.1038/s41467-025-57828-0)。这里描述论文口径，不声称已经核实本地每个外部 checkpoint 的完整训练成员。

## 为什么本地会出现上百万条

1. ChEMBL / BindingDB 是跨年份、跨文献与专利的累计数据库。九月发布版本不代表里面每条记录都在九月首次出现。
2. 化学结构、蛋白序列与测量值即可构成标量监督数据，本次不要求每一对都有实验解析的三维结合复合物。
3. 全量包括大量研究化合物，并非只含已上市药物或我们的 720 种候选药。
4. 同一个药物—蛋白可有 Kd、Ki、IC50、EC50，以及不同实验条件下的重复值。ChEMBL 数据还可能被 BindingDB 收录。它们不能逐行相加作为独立训练配对。

本次交付分为来源证据表、去重配对/任务标签、训练/验证/测试三个层次。二分类中同一配对/任务只产生一个标签，重复转载不增加票数；同任务明确阳性与阴性冲突时隔离。`AFFINITY_KD_KI`、`ACTIVITY_IC50`、`ACTIVITY_EC50`、明确失活注释分别保存。主训练表是多任务长表，使用时不能丢弃 `task` 列。

## 本次最终数量及推荐入口

通过来源记录质控后保留 2,897,915 条测量证据；按配对/任务归并并隔离灰区与冲突后，有 1,457,138 行可判定二分类标签，对应 1,409,474 个不同分子—蛋白配对、867,739 个分子身份、4,777 条不同蛋白序列。这里包含训练、验证、测试与独立保留集。

主训练部分的构成为：

| 类别 | 训练行数 | 阳性 | 阴性 | 使用建议 |
|---|---:|---:|---:|---|
| Kd/Ki | 287,296 | 189,128 | 98,168 | 首轮直接亲和力分类训练入口 |
| IC50 | 721,383 | 541,497 | 179,886 | 单列活性辅助任务；不直接当成 Kd |
| EC50 | 102,821 | 72,224 | 30,597 | 单列活性任务；不等同于激动机制或直接结合 |
| 明确失活注释 | 46,603 | 0 | 46,603 | 附加负证据，**不能单独训练一个有区分能力的二分类头**；需要核对适用的实验端点与上下文 |
| 合计 | 1,158,103 | 802,849 | 355,254 | 多任务/证据长表，不能直接混成纯亲和力任务 |

**建议第一轮直接读取 `TRAIN_AFFINITY_KD_KI.parquet`，配套使用同名任务的验证/测试文件。** 如果做连续值回归，应读取 `TRAIN_REGRESSION.parquet` 并选择 Kd 或 Ki 端点，保留端点区别；回归与二分类训练行数不相同。主 `TRAIN.parquet` 保留完整任务信息以便后续实验，并不意味着应把四类全部不加区分地输入同一个损失。

此版 Kd/Ki 是直接亲和力核心子集，但仍含来源明确的野生型片段、accession 解析而未逐篇确认的构建等情况；需要更严格构建口径时可通过证据表筛选。清洗并不替代逐篇实验方法核验。

这也意味着：**联合数据集的总数不等于相对旧模型的新增训练数据量。** 旧模型见过的连接身份—蛋白配对有显式标记；它只说明旧监督模型成员重叠，不能证明外部预训练编码器没见过这些分子或蛋白。

## 如何判断扩大量有没有用

建议后续在固定留出集上分别比较：旧数据基线、全靶点 Kd/Ki、加入 IC50 辅助任务、再加入其他活性任务。只有相同评价口径下的排序富集、校准和泛化改善，才能支持扩大数据确实有益。小型基准上报告的指标不能与本地更宽范围的指标直接比较。

本轮仅交付数据，不执行这组训练实验。已交付湿实验的 384 配对及参考对照有独立保留，不通过新训练静默回填已选候选的分数。
