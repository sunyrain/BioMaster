# 原子—残基与口袋几何为何未带来增益

当前证据支持两个主要结论：额外训练使已有全局排序能力退化；局部模块没有学到足以补偿这种退化的增量，尤其几何对老药排序几乎没有影响。这个结论针对现有输入组织、局部实现和训练方案，不能推广为原子—残基交互或结构信息无用。

本次在已冻结的12个局部检查点上补做36项BF16推理干预，以及6个geometry检查点上的18项FP32复核。只使用≤2018训练/2019–2020验证、≤2020训练/2021–2022验证的开发窗口。没有训练新权重、重新选型或读取新的2023–2025/KIRHub标签；已交付模型包保持原样。

## 一、主要降幅首先出现在继续训练

| 固定协议，两窗口三种子均值 | 综合分 |
|---|---:|
| 选中的全局父模型 | 0.437493 |
| 全局继续训练4轮 | 0.400174 |
| 继续训练＋等容量MLP | 0.398010 |
| 继续训练＋原子—位点残基 | 0.395466 |
| 继续训练＋受体CA几何 | 0.393675 |

原父模型到geometry的全部降幅不能都算到几何头上：没有局部模块的继续训练对照已下降约0.0373，geometry相对同曝光全局对照再下降约0.0065。

与此同时，六个继续训练全局模型的平均训练BCE从额外第1轮的0.0763降到第4轮的0.0354；检索损失从1.0144降到0.9457。训练拟合改善而新关系检索变差，符合过拟合或训练目标与未来排序任务不匹配的表现；仅凭这些曲线还不能分清两者的因果份额。

训练实现让所有父模型参数继续更新，优化器重新初始化，所有参数使用同一学习率；局部阶段强制训练4轮，只在最后一轮做验证。它严格控制了额外曝光，但没有检验局部模型是否在第1–3轮短暂获益，也没有检验冻结父主干、分组学习率或保持原表示的正则。代码：[固定拟合训练](../scripts/fit_biomaster_selected_model.py)。

## 二、关闭局部修正后，退步仍保留在共同训练后的全局部分

把一个已经训练完成的局部模型写为：

`score = head(g_joint + delta_local)`

诊断只将`delta_local`去掉，保留该模型共同训练后的全局参数与输出层。这是在同一检查点上做前向干预，不等于再训练一个没有局部模块的模型。

| 检查点及推理干预 | 两窗口三种子综合分 |
|---|---:|
| Site：完整前向 | 0.395468 |
| Site：关闭局部修正，保留共同训练后的全局参数 | 0.393596 |
| Geometry：完整前向 | 0.393675 |
| Geometry：关闭局部修正，保留共同训练后的全局参数 | 0.393249 |

相对上述关闭版本，Site修正约补回0.00187，Geometry的整个局部修正约补回0.00043。原全局父模型为0.43749，说明大部分退步在局部修正被关闭后仍存在。局部模块并非所有情况下都有害，但对当前任务的补偿很有限。

修正向量与全局向量范数之比在Site平均约5.94%、Geometry约1.89%，个别Site模型达到20%。因此不能称局部通道“全部为零”；向量幅度也不等于排序增益。完整结果见[BF16汇总](../outputs/biomaster_local_failure_audit_20260906/SUMMARY.csv)、[逐模型结果](../outputs/biomaster_local_failure_audit_20260906/RUNS.csv)。

重新打包查询批次带来很小的BF16数值差异：本次完整前向与原始验证综合分最大差约0.0000157。全部干预使用同一批次组织，并将FP32几何结论另行核验。

## 三、当前几何信息对老药排序几乎没有影响

对每个geometry检查点做三种推理：完整前向；将几何有效掩码关闭；在每个靶点内打乱有效CA坐标与残基的对应关系，保留残基状态、位置、质量和掩码。后者是一个固定随机种子的扰动，不代表所有几何干预。

| Geometry推理条件 | BF16综合分 | FP32综合分，关闭TF32 |
|---|---:|---:|
| 完整模型 | 0.39367532 | 0.39475431 |
| 关闭几何 | 0.39367820 | 0.39475345 |
| 打乱坐标对应关系 | 0.39367331 | 0.39475381 |

FP32中，关闭几何的平均综合分差约−0.00000086，单模型绝对变化最大约0.00000982；打乱坐标的平均变化约−0.00000050。这个现象不是仅由bf16推理舍入造成的。

几何关闭仍使FP32原始logit产生约0.00174的平均绝对变化，个别配对变化更大，说明通道确实连接并参与了计算；但它几乎没有改变这些开发查询的AP与R@20。不能将“排序不敏感”改写为所有分数逐位不变，也不能从这里推断对所有生物学任务都无用。证据：[FP32结果](../outputs/biomaster_local_failure_audit_20260906/fp32/SUMMARY.csv)、[分数变化](../outputs/biomaster_local_failure_audit_20260906/fp32/SCORE_SENSITIVITY.csv)。

## 四、可以明确指出的架构和数据问题

**1. 位点残基与全序列背景被混在一起，位点身份没有显式传给注意力。**

384个靶点共输入36,864个残基token，其中17,196个来自所选预测口袋，19,668个即53.35%为全序列补点。这里的“补点”只表示不属于所选预测口袋，不断言它们是真实非结合残基。Site使用`residue_indices>=0`作为注意力有效掩码；`TARGET_SITE_MEMBER`虽在特征准备时生成，未被加载到局部交互输入。网络因而没有显式的位点/背景身份信息，注意力与均值池化同时处理这些token。

其中248个靶点有至少两个被选口袋，当前最多三个口袋的残基被取并集后混合；口袋编号和预测概率也没有进入交互层。这是实际存在的信息组织缺陷，可能稀释与当前药物有关的局部信号，但其性能影响仍需“保留口袋身份/严格口袋mask”的受控训练确认。[残基选择代码](../scripts/prepare_biomaster_unified_interaction.py)、[实际输入代码](../biomaster/unified_features.py)、[覆盖审计](../outputs/biomaster_local_failure_audit_20260906/FEATURE_DIAGNOSIS.json)。

**2. 公共token预训练没有自动变成药物—口袋匹配预训练。**

当前原子token取自DrugCLIP分子编码器，残基token取自ESM2；两边被冻结后，交互投影和32维pair模块重新初始化。我们没有同时迁移DrugCLIP的口袋编码器和原有的分子—口袋对齐空间。DrugCLIP论文的核心是利用配对数据对齐分子与蛋白口袋表示，因此仅取其分子token，不等于继承完整匹配能力。[DrugCLIP原论文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/8bd31288ad8e9a31d519fdeede7ee47d-Abstract-Conference.html)。

原子—残基层目前只有一轮交互，pair宽32，用同一个标量注意力矩阵做行、列聚合，随后池化成全局修正。它可以学习token兼容性，但没有原子接触真值、配体姿态、结合位点归属等监督，不能把其attention直接解释为实际接触。代码：[交互块](../biomaster/unified_interaction.py)、[局部残差](../biomaster/refined_interaction.py)。

**3. “几何”目前是粗粒度受体消息传递，还不是结合构象建模。**

几何层只使用受体残基CA距离、距离RBF和pLDDT质量权重，在24Å内做归一化加权聚合。中位数每个有效残基连接34个邻居。距离核本身不以药物为条件，药物条件是在后续交互块中进入；没有侧链原子布局、氢键方向、配体—受体共同坐标或直接接触几何。单个独立分子构象内部的3D信息存在于DrugCLIP token中，但没有直接构造跨分子物理距离。

这会限制模型表达局部化学匹配的方式，密集距离平滑也可能弱化细节；后者是待检验机制，不能仅凭邻居数断言发生过度平滑。无共同配体—受体坐标不意味着模型必然失败，DrugCLIP本身就能用无对接的表示匹配；但这要求匹配的预训练目标与表示。

**4. 训练存在“已有强全局路径先学，新局部路径难以提供独立增量”的风险。**

局部最终投影零初始化，保证加入模块时原预测完全不变；这也意味着最初一步局部上游梯度为零。后续梯度可以恢复，之前的性质测试已覆盖这一点，不能说永久断梯度。与此同时，全局主干和共享头从一开始就直接受监督，且没有冻结或表示保持约束。局部模块还通过`global_state`条件化以及`context-g`等路径得到全局信号，因此即使局部修正非零，也未必在利用新增结构信息。

当前只有关系级二分类和既有关系检索损失；一个整对标签并不说明药物结合哪个候选口袋或接触哪个残基。由这些事实推断，优化更容易沿原有全局路径继续拟合，而新局部模块没有充分的任务约束。这个机制与关闭实验相符，具体梯度竞争和最优训练策略仍需分阶段训练消融确认。

## 五、不应当被当成主要结论的解释

“因为大多数样本没有结构”不符合数据。352/384靶点有几何；2019–2020的60条老药验证阳性有57条覆盖，2021–2022的53条阳性全部覆盖。预测口袋的CA pLDDT中位数约92.9，不能笼统称结构缓存质量很差。pLDDT衡量局部结构置信度，并不直接证明具体药物的口袋选择或结合构象正确；AlphaFold数据库也明确说明预测可能只反映多构象中的一种。[AlphaFold官方说明](https://alphafold.ebi.ac.uk/faq)。

“因为96个残基截断了一切”也过度归因。只有18/384个靶点的预测口袋并集超过96；两个开发窗口的老药阳性中分别只有3/60和2/53落在这些靶点。截断需要改进，但覆盖数字不支持它解释全部退步。

“P2Rank预测口袋就是真实药物结合位点”同样不成立。P2Rank根据蛋白表面特征预测可结合区域，而本项目没有在输入选择时验证每个老药究竟结合哪个区域。[P2Rank官方算法说明](https://github.com/rdk/p2rank#algorithm)。

## 六、下一步应怎样验证

| 优先顺序 | 实验变化 | 需要回答的问题 |
|---|---|---|
| 1 | 固定父主干和共享头，只训练局部修正；再以更低学习率解冻父模型 | 局部是否能在不损害已有排序的前提下提供增量？ |
| 2 | 保留每个候选口袋的独立身份，严格区分位点与背景token；与同曝光/同容量对照比较 | 当前的残基混合是否淹没了有效局部信息？ |
| 3 | 引入匹配的分子—口袋对齐训练，或在合格复合物上加入位点/接触监督 | 模型能否学到与结合有关、且对正确坐标或残基对应关系敏感的信息？ |
| 4 | 在上述增量建立后，再检验侧链、方向或可靠姿态几何 | 更精细几何能否超过一个已学会利用局部信息的基线？ |

所有新方案仍应在开发窗口选型，不回看2023–2025/KIRHub最高分挑模型。当前结论足以说明这套局部接入方式没有成功，尚不足以判定局部交互的上限。应优先修复监督、口袋组织和优化路径，再判断增加结构细节是否值得。
