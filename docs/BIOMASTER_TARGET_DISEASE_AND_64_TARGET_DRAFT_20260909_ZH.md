# 六个重点靶点的疾病意义与64靶点／512对扩展草案

日期：2026-09-09。按用户确认，总量保持约512个不同药靶组合，增加靶点覆盖至64。本次完成疾病依据核对和靶点层试算，未改变原SPR512 V2名单；新草案不是可以送实验的512对药物清单。

## 1. 原先六个靶点并非“没有意义”，问题在不同层面

上次点名AKR1B1、TPH1、NT5E是因为对照只有IC50记录，FKBP1A、REN、ELANE是因为严格预测口袋条件未通过。这些问题不等于疾病价值低；疾病价值也不能解决对照、候选结合和作用方向问题。

| 靶点 | 有依据的疾病／机制方向 | 对本项目的判断 |
|---|---|---|
| AKR1B1，醛糖还原酶 | 糖尿病周围神经病变；多元醇通路 | 有直接药理和临床研究先例。适合保留评审，但新老药候选需要显示结合、功能抑制与相对现有参照的价值 |
| TPH1，外周色氨酸羟化酶 | 类癌综合征相关腹泻；外周5-HT合成 | 该方向有明确治疗先例。肺动脉高压虽有机制依据，却有重要临床负面证据，不能列作优先成功方向 |
| NT5E／CD73 | 肿瘤微环境腺苷介导的免疫抑制 | 有合理转化研究价值；需要酶功能和免疫环境验证，SPR结合本身不足以说明抗肿瘤效应 |
| FKBP1A／FKBP12 | FKBP12参与的药物复合物机制；免疫抑制、mTOR相关疾病，另有肺血管BMPR2研究 | 生物学有意义，但新分子只结合FKBP12并不自动复制他克莫司或西罗莫司的下游作用，机制归因要求高 |
| REN，肾素 | 肾素—血管紧张素系统、高血压 | 靶点意义清楚，但已有成熟药理先例；新候选需解释优势、新机制或选择性，不能只因“与心肾有关”就优先 |
| ELANE，中性粒细胞弹性蛋白酶 | 蛋白酶失衡与肺组织损伤，尤其α1抗胰蛋白酶缺乏相关肺病 | 有实际临床研究支持继续研究，但现有试验结果不能外推成本批候选有效；需直接作用与功能抑制证据 |

### 证据与需要特别纠正的方向

- **AKR1B1：** epalrestat的糖尿病神经病变随机研究提供靶点方向的药理依据；不是本批药物的有效性证据。[三年多中心比较研究](https://pubmed.ncbi.nlm.nih.gov/16801576/)
- **TPH1：** Xermelo说明书将抑制外周5-HT合成与类癌综合征腹泻治疗联系起来。[官方说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=a4ac9d62-887c-4c8f-b04d-a5f31cec7c86) 肺动脉高压方面，ELEVATE-2的rodatristat ethyl试验出现不利血流动力学结果，因此不能只引用早期TPH1机制论文来包装新用途。[随机IIb期原始研究](https://pubmed.ncbi.nlm.nih.gov/39307144/)
- **NT5E：** NCI记载CD73抑制剂通过降低肿瘤微环境腺苷、解除免疫抑制的研究机制，这是潜在抗肿瘤路线而非确定疗效。[NCI药物词典](https://www.cancer.gov/publications/dictionaries/cancer-drug/def/cd73-inhibitor-atg-037) 同时，人类NT5E功能缺失与动脉钙化有关：疾病相关性可能意味着功能应保留，而非应该抑制。[人类遗传原始研究](https://pubmed.ncbi.nlm.nih.gov/21288095/)
- **FKBP1A：** 西罗莫司通过FKBP12形成复合物并影响mTOR，说明书包含淋巴管平滑肌瘤病用途；不能据此把任意FKBP12结合剂等同于西罗莫司。[官方说明书](https://dailymed.nlm.nih.gov/dailymed/lookup.cfm?setid=09f24e7a-0bea-4e02-b557-c60eb842d41a&version=1) FK506促进BMPR2相关信号是特定化合物和研究条件下的机制证据，不是新结合剂的保证。[原始研究](https://pubmed.ncbi.nlm.nih.gov/23867624/)
- **REN：** aliskiren是用于高血压的直接肾素抑制剂。[官方说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=41c0e5e0-eb26-4d9e-bcd2-d0f2cc8fc6db) 本地Open Targets的REN高分关联还包含肾小管发育不全等遗传病，不能将它们自动转换为“抑制REN能治疗这些病”。
- **ELANE：** alvelestat在α1抗胰蛋白酶缺乏患者的随机II期研究报告了靶酶抑制和疾病活动生物标志物结果；这提供临床研究背景，不能称已建立长期临床获益。[原始研究](https://pubmed.ncbi.nlm.nih.gov/40967767/)

本项目的优先级仍须按具体药靶pair决定。若主要研究肿瘤免疫，可先评NT5E；若重视代谢并发症可先评AKR1B1；若有肺病实验能力可评ELANE。TPH1应明确选类癌相关方向还是其他假说；FKBP1A需要额外复合物/下游机制论证；REN需要提出超过已知RAAS药理重复验证的价值。这些是条件性研究判断，不是已完成的实验放行。

## 2. 固定512对，靶点翻倍如何分配

| 项目 | 原32靶点方案 | 新64靶点草案 |
|---|---:|---:|
| 每靶点高排 | 10 | 5 |
| 每靶点中排 | 3 | 1 |
| 每靶点低排背景 | 2 | 1 |
| 每靶点阳性对照 | 1 | 1 |
| 高排总数 | 320 | 320 |
| 中排总数 | 96 | 64 |
| 低排总数 | 64 | 64 |
| 阳性对照总数 | 32 | 64 |
| 待发现候选 | 480 | 448 |
| 总不同pair | 512 | 512 |

这个5＋1＋1＋1方案保持320个高排候选及64个低排背景，增加了靶点广度，适合广谱发现；代价是每靶点验证深度下降，中间组减少，阳性对照增加。每靶点只有一个低排和一个中排，不足以单独估计该靶点稳定的排名富集或命中率，主要统计需跨靶点汇总并处理药物复用和靶点差异。

“不同pair数相同”不等于成本相同。64个蛋白意味着更多构建、表面和对照适配；512个pair也不包括所有浓度梯度注射、重复、空白参照和命中确认。如果预算指总实验操作数而不是不同组合数，64×8不能直接视作预算可行。

增加覆盖不会提高单个候选的结合概率，也可能扩入模型更弱或实验更难的靶点。因此建议以64作为评审草案规模，最终以候选和实验可用性确定，不为了凑数放宽条件。

## 3. 已完成的靶点层试算

从367生化路由登记靶点中，306个有至少8阳性＋8阴性参照。以原32靶点为待复核基底，提出下列32个新增评审对象。这个列表是机制覆盖导向的人工草案，经本地资产检查；不是经实验验证的最优靶点组合，也未逐个完成疾病临床证据审查。

| 评审组合 | 新增靶点 |
|---|---|
| 代谢和脂质／核受体 | DPP4、HSD11B1、HMGCR、EPHX2、PPARD、VDR |
| 神经递质与环核苷酸 | ACHE、BCHE、MAOA、MAOB、COMT、FAAH、PDE9A、PDE10A |
| 炎症和蛋白水解 | PTGS1、PTGS2、ALOX5、PDE4D、CTSK、CTSS、MMP13 |
| DNA修复、表观遗传与激素受体 | PARP1、PARP2、EZH2、ESR1、ESR2 |
| 免疫相关信号和代谢 | DHODH、JAK1、BTK、MAPK14 |
| 凝血蛋白酶 | F2、F10 |

ACHE/BCHE、MAOA/MAOB、PTGS1/PTGS2、PARP1/PARP2、ESR1/ESR2等成对保留，是为了给选择性比较留下可能；最终要让相应靶点共享部分查询药物，否则只有两个蛋白都在清单中并不构成选择性实验。成对靶点增加的是可解释比较，不能算作完全独立的新疾病覆盖。

本地检查结果：

- 原32＋新增32均在监督训练靶点词表内，均有8×8参照；这不是64个靶点都通过了模型准确率校准。
- 新增32中28个严格预测口袋条件通过；CTSK、CTSS、F2、F10需要额外结构／受体审查。结构标记不作为生物学否决。
- 初选SIRT1和PTPN11时，旧冻结rank/384中的Top20药物数仅0和2，达不到每靶点5高排要求，未放宽排名阈值，改为MMP13和ESR2进入草案。
- 替换后的64个靶点在**药物级排除前**都有足够原始高、中、低分区候选；FDA实体、训练/已知关系、新颖性和化学规则过滤后能否填满仍待验证。当前计数不能当作有足够合格候选。
- 沿用现有核心选样谱系与生化路由分数；保留原32中核心/扩展身份。新增核心靶点按冻结rank/384，PTGS1按生化rank/367。没有把64个实验靶点重新排名为rank/64，也没有混入selected或ContextPocket分数。
- 现有Open Targets 26.06的215靶点缓存覆盖草案中46个；其余18个是**本地缓存未覆盖**，不能写成无疾病关联。已导出可获得关联，Top3仅作未审阅原始线索。

## 4. 不能按Open Targets分数机械扩展

现有缓存中BCHE、DHODH、EZH2等最高关联包含缺失或变异致病的综合征，PTGS1含出血表型。这说明“高关联”不代表“抑制有治疗价值”。应逐项区分人类遗传、药物机制、表达/文献关联、预期干预方向和有无负面试验。

两个例子本次不进入新增32优先草案：BACE1与阿尔茨海默病关联充分，但verubecestat临床试验没有改善、部分指标恶化；IDO1有肿瘤免疫机制，但epacadostat联合pembrolizumab在ECHO-301中未改善主要疗效结果。它们仍可用于特定机制研究，不能仅因热门疾病而优先。[BACE1原始试验](https://pmc.ncbi.nlm.nih.gov/articles/PMC6776078/)、[IDO1原始试验](https://pubmed.ncbi.nlm.nih.gov/31221619/)

这些实例不是对全部32个新增靶点已经完成临床负面证据审查的声明。新列表仍需疾病方向、实验可做性和具体药靶证据共同复核。

## 5. 下一步如何把草案变成可执行选择

1. 原32和新增32都接受同一套疾病方向、构建体及对照审查；原32不因已经入选就自动保留。
2. 对各靶点从冻结模型原候选范围重新构建可选药物，执行FDA实体、活性物种、已知关系/训练关系、文献和化学审查；高排只保留排名和具体关系证据均有依据的对象，不强凑5个。
3. 对448候选做药物复用、骨架与理化分布约束；保留中低排和对照。原120药及每药2–6靶点约束不能默认在新设计中仍可行，应重新求解和验证。
4. 原方案中已有32个对照仅继承文献身份，新增32对照尚未选定；全部需要实验端确认。分批实施时保留完整靶点单元，先验证可做性，之后按预设规则执行后续批次。
5. 最终生成新版本实验清单与模型/选样快照后，才视为64靶点选择完成。若原实验已执行，原结果按原谱系统计，不追溯改为新方案。

**建议采用“64靶点评审、512对设计上限”的方向，但不把翻倍本身当成质量升级。** 近期先筛掉缺少合格高排候选或无法建立解释清楚实验体系的靶点；最终高排质量优先于恰好64个的整齐数字。
