# Palinova A/B 与原 SPR384 排序器的同样本比较

2026-09-14。**已用冻结的新 A/B 推荐权重补跑原评价面板。完整旧面板上新模型分数提高，但大量配对已经进入新 A/B 训练；排除训练及验证重叠后，新模型并未在这个老药筛选场景全面胜过原组合。** 不应把新模型在大测试集上的 AP≈0.96 直接移用于原384，也不应由新旧排名分歧判定原候选错误。

本次是实际推理与回顾性对照，没有重训、调权重、选择新384或更新网站。Palinova A/B 指 BioMaster 九月多任务实验中已经收敛的神经网络，**不是正在后台训练的 DTIAM A/B**。

## 实际比较的权重与任务

- 原 SPR 排序器：冻结的 `independent_validation_rank_score`，历史 S5 神经五模型＋阳性化学近邻＋靶点先验。保留原始分数。
- 新 A：Kd/Ki＋明确失活，二分类，种子20260921；训练337,570对。
- 新 B：全部端点＋明确失活，二分类，种子20260922；训练1,116,270对。
- 另列 A 排序＋回归参照：种子20260923，非事后从本轮结果挑选。模型身份与哈希来自此前冻结的[推荐清单](../outputs/biomaster_model_consolidation_20260911/RECOMMENDED_MODELS.json)。

新模型统一使用两路分类 logit 的均值，GPU BF16，保持训练评估口径。这些是预先推荐的单个代表检查点，不是三种子均值或新融合模型。

三张原表的成员、身份、标签与旧分数不变；488对包含479对，不能算两个独立重复实验。S5是混合端点及失活标签测试，不能当成纯Kd/Ki；后两张是按原跨来源冲突规则保留的Kd/Ki面板。九月BindingDB指累计快照，不代表九月新发生的实验。

## 共同未见配对：更有参考价值的比较

对每个面板，四个模型在完全相同的剩余成员上比较。未见定义为**不在A或B任何训练/验证池中的同连接骨架＋同精确序列配对**；它仍不证明文献、药物、靶点或公共编码器预训练独立。

| 面板 | 剩余配对（阳性/阴性） | 随机AP参考 | 原SPR组合 AP/AUROC | 新A AP/AUROC | 新B AP/AUROC | A排序＋回归 AP/AUROC |
|---|---:|---:|---:|---:|---:|---:|
| 历史S5 | 620（95/525） | 0.153 | **0.578 / 0.816** | 0.323 / 0.758 | 0.432 / 0.760 | 0.417 / 0.795 |
| 合并亲和证据 | 180（45/135） | 0.250 | **0.658 / 0.757** | 0.574 / 0.794 | 0.533 / 0.783 | 0.503 / 0.824 |
| BindingDB覆盖切片 | 175（41/134） | 0.234 | **0.624 / 0.743** | 0.571 / 0.801 | 0.529 / 0.783 | 0.490 / 0.826 |

粗体仅标记这张表中AP点估计最高者，不代表所有差异均有统计支持。

对BindingDB的175对，按32个药物进行1,000次配对聚类bootstrap：A相对原组合的AP差为−0.053，95%区间[−0.163, 0.134]；B为−0.095，区间[−0.210, 0.088]。AUROC差的区间也都跨零。因此不能宣称原组合在该小面板稳定胜过A/B，也不能宣称A/B已经胜出。

历史S5的620对中，A相对原组合的AP差为−0.255，区间[−0.376, −0.147]；B为−0.146，区间[−0.314, −0.009]。在本次配对药物bootstrap假设和固定检查点下，这个老药子集上的AP下降更明确；仍不应推广到所有端点和所有靶点。

进一步要求其分子所属训练划分组也未进入任何A/B训练/验证，BindingDB剩160对（36正/124负）：原组合/A/B的AP为0.596/0.544/0.517，AUROC为0.736/0.800/0.776，仍没有全面替换原组合的证据。这是更小的敏感性切片，未认证公共预训练或文献来源独立。

## 每药找靶点和前段排名

全局AUROC、全局AP和药物内排序是不同指标。AUROC衡量所有正负配对的相对次序；AP更受靠前位置的阳性排列影响。全局结果还受不同药物分数是否可横向比较影响，不能替代实际每药TopK。

BindingDB共同未见175对只形成8个同时有正负样本的药物查询。药物内AP：原组合0.615、A0.595、B0.638、A联合0.694。只有5个查询有至少5条实测记录，样本太少，不用这里的P5确定长期模型赢家。历史S5共同未见620对有21个药物查询，药物内AP分别为0.805、0.755、0.762、0.816。

保持每药完整384个靶点的排名分母，对共同未见175对观察：

| 评分器 | 每药前10内已测阳性/已测配对 | 第11–20内已测阳性/已测配对 |
|---|---:|---:|
| 原组合 | 18/23（78.3%） | 1/9（11.1%） |
| 新A | 10/14（71.4%） | 5/11（45.5%） |
| 新B | 8/11（72.7%） | 8/12（66.7%） |
| A排序＋回归 | 8/15（53.3%） | 3/9（33.3%） |

这些分母是恰好有历史测量的配对；不同模型进入该分母的成员不同，存在文献选择偏倚。不能称作模型真实Top10精度、384命中率或匹配成本的前瞻比较。全479对中A的前10已测阳性比例88.6%包含训练重叠，尤其不能直接外推到未知实验。

## 输入一致性与完成核验

720个目录分子的SMILES重新计算身份全部匹配；蛋白按精确序列SHA256映射。487个药物有已完成的新A/B训练特征缓存，优先复用；其余233个使用已保存的同身份目录特征，无零填充未完成缓存。新旧已完成缓存中15个药物的全局特征有差异，1个图均值、1个可用性标记有差异；蛋白公共行完全一致。评估面板中，S5的2,340对、合并亲和面板389对使用新训练缓存，其余使用目录缓存。

另以全部旧目录输入重跑敏感性：BindingDB共同未见175对的A/B AP为0.567/0.529，与主分析0.571/0.529接近，未改变本次判断。不能把历史输入缓存未经检查直接套到新模型，具体记录见`FEATURE_AUDIT.json`、`DRUG_INPUT_AUDIT.csv`。

三份推荐权重各自重跑原已发布神经A/B测试的4,096行，和冻结预测的最大差均为0；这是推理一致性检查，不是新增测试成绩。原SPR三张表的AP、AUROC重新计算均在1e-12内复现，3,044个面板行无同面板标准化身份重复。输入、权重、原实验表哈希前后不变。本次没有读取后台DTIAM尚未开放的测试结果。

## 现在如何使用这个结果

1. **保留原384及其完整原组合评分作为实验基线有依据。** 原组合在老药配对的这些实测子集上仍有竞争力，不能因新A/B在较大面板分类分数高就将其推翻；本次仍未获得384自身的湿实验标签。
2. **新A仍是结合分类的重要模型，B保留活性用途；实际选样需要单独验证。** 大面板成绩与本次老药子集的分布、端点和阳性比例不同。数据扩大与模型目标改变并不保证每药TopK改善。
3. **下一步应受控比较新神经分数＋训练内化学近邻/靶点先验。** 本次没有把这两个原组合分量接到新A/B，尚不能把差异归因为单一数据量因素。组合权重需在验证数据重新拟合，不能沿用旧标准化常数硬拼，也不能在本次已经看过的旧面板上调完再称独立胜出。优先使用既定验证集并预留新的确认数据或后续湿实验批次。
