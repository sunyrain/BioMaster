## 页面使用

打开网站“SPR设计”，总览中可以查看全部候选，并按“优先验证／有条件保留／建议后置／信息不足／待审查”筛选。展开每个候选即可查看评价、支持依据、风险、下一步、来源链接和实际检索范围。单药与单靶点的SPR详情同步展示。

页面每15秒读取更新，不必重启服务。未完成条目明确显示待审查。导出当前筛选候选生成JSON，仅包含候选，不包含另计参考对照；导出不是修改或冻结基线名单。
