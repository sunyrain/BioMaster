# 七模型完整目录排名与补算

日期：2026-09-16。

## 排名范围修正

原页面在进入“七模型分歧”后，把范围切换成了SPR384实验清单。例如AR只剩7对，再按七模型共同覆盖实验配对的全局名次显示，因此选“ReTargetMap排序”并不会得到AR完整720药的Top10。

此外，冻结实验复核表使用ReTargetMap的药物→靶点正向分数；原网站的靶点药物排名使用其独立反向输出。两个方向不能混用。

现已统一：

- 药物、靶点概览与排名页均使用原 `/api/rankings` 完整目录接口。
- 默认矩阵七列、分歧图七条轴、模型选择七项、配对详情七模型，CSV同步输出七模型。
- ReTargetMap按查询方向使用原有对应输出；旧四模型的原始分数、排序和已知关系筛选规则保持原口径。
- AR默认范围为全部720药；“ReTargetMap 全目录 Top10”清除筛选并直接显示第1—10名。药物查询则在全部384核心靶点中排名。
- 搜索、已知关系筛选、分页都不重新计算排名。新模型不要求与其他模型共同覆盖，也不限定原384实验候选。
- 每个模型独立展示已评分数 / 目录总数。尚未评分的配对保留空值；覆盖不完整时名次标为“暂列”，不冒充完整Top10，也不纳入“完整模型Top20一致”计数。
- 原SPR冻结实验复核作为实验审计保留在SPR页面，不再代替实体的完整目录排名。

## 本轮计算范围

沿用网站原四模型比较核心 **720药 × 384靶点 = 276,480对**。888靶点是登记范围，另有已有的720×890单模型扩展结果；本轮不把该扩展误称为四个基线都已覆盖的七模型矩阵。

本轮三个新模型使用与前次复核相同的官方权重和输入流程，不训练。输入表分别保存为 `DRUGS.csv`、`TARGETS.csv`，SHA256与协议见 `outputs/catalog_seven_models_20260916/PROTOCOL.json`。

已完成的精确匹配预测被复用，其余按完整靶点逐一补算，AR优先。存储为SQLite，每批结果提交后即可由网站读取，页面每30秒刷新。SQLite有复合主键，不用重复行累计覆盖率。

### ProbeMatchDTI

补全211个此前没有缓存的蛋白表征及剩余药物表征，再逐靶点评估全部720药。保留官方窗口、融合系数、逐对确定种子。开始新增评分前重放5个已完成真实输入，与原适配器结果比较，误差须小于1e-6。

### DTBind

继续复用匹配的作者蛋白图，在每个可用靶点上评估全部720药。此前下载在读取压缩包时因TLS连接中断退出，额外的“下载未完成”不能误计为作者图谱不覆盖。本次恢复下载，并缓存已校验的HTTP分段，重试可复用，不保存38.7GB完整压缩包。

作者集合缺少蛋白、蛋白序列不一致、特征尚未下载、推理失败各自记录。图文件按临时文件原子替换，避免推理读取半个文件。发布新预测前同样重放5个已有输入；本次DTBind最大差异小于1e-15。

### Nesso-1

完整目录任务已建立，等待现有GPU评估队列结束后，先运行AR的全部720药，再运行其他靶点。等待期间持续把旧队列的新完成结果同步到目录数据库。

保留5次recycling、bf16、官方口袋处理、完整蛋白序列和原权重。每个靶点保存原始输出、YAML、命令与日志；完成后只清理可重新生成的中间文件，防止全矩阵占满磁盘。低于8GiB可用空间时暂停。

**这是实际推理任务，不是增加三个表头就能全部出分。** 前一阶段359对用时约3314秒，约9.2秒/对。简单外推276,480对约29.5个单卡日；蛋白长度、GPU等待和预处理复用都会改变速度，此数仅为量级估算，不能承诺精确完成日期。当前不宣称三个新模型已完成全矩阵。

## 运行与恢复

所有命令在项目根目录执行；复跑复用数据库中已完成分数。

```bash
python scripts/prepare_catalog_dti_20260916.py
.venvs/frontier_dti/bin/python scripts/run_catalog_dti_20260916.py probematch
.venvs/frontier_dti/bin/python scripts/run_catalog_dti_20260916.py dtbind
.venvs/frontier_dti/bin/python scripts/fetch_frontier_dti_assets_20260916.py dtbind --catalog
python scripts/run_catalog_nesso_20260916.py --wait-pid <仍在使用GPU的原队列PID>
```

三个模型各自的 `STATUS.json`、`PID` 和 `RUN.log` 位于 `outputs/catalog_seven_models_20260916/<model>/`。网页查询不启动推理、不修改实验清单。
