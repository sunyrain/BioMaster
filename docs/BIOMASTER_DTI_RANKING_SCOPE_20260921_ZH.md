# 第一阶段：公开DTI模型的双向排序一致性与推荐分歧

方案日期：2026-09-21，范围修订v4。**主矩阵采用原888目录排除143个GPCR后留下的全部745个靶点，与既有720个分子条目交叉，共536,400对，开展双向筛选与排序比较。** 先研究排序有何不同，不使用Davis，谁对谁错留到第二阶段。机器规则见[当前范围配置v4](../configs/dti_ranking_scope_20260921/PROTOCOL_v4.json)，实体、来源、复核和文件哈希见[准备清单](../outputs/dti_ranking_720x745_20260921/MANIFEST.json)。已有部分模型结果曾被查看，本方案属于回顾性协议，不称外部预注册。

## 第一阶段的结果是什么

研究单位是“模型×查询对象×固定候选集合”。两个方向分开分析：给定一个靶点，从分子库选药；给定一个分子，从靶点库选靶点。

**排序不同本身就是可报告的结果。** 这一阶段把差异量化并检验其规律，不以找到性能冠军为目标：

1. 全排序相关性与Top5/10/20推荐重合度分别有多高？与随机排序相比如何？
2. 模型在两个方向上是否呈现不同关系，例如靶点内药物排序相近，但药物内靶点排序差异明显？
3. 分歧是普遍现象，还是集中在特定靶点家族、序列长度、输入形式或大量并列分数的查询？
4. 在相同候选集合上，哪些模型形成相近的推荐模式？改变候选池后，这些关系是否保留？
5. 表面上的一致或分歧，有多少受到覆盖缺失、截断、任务头和输入身份差异影响？

仅列出几个不一样的Top10还不足以支撑强论文。第一阶段的贡献应是可复现地量化差异的规模、分布和结构，说明这些现成系统在何种范围内可以或不可以互换使用。文章当前用“排序一致性/推荐分歧”定位，比直接用“可靠性”更准确，后者容易被理解为已经验证正确性。

这些问题无需把未测配对标成阴性。第一阶段不报告准确率冠军、假阳性率、实验命中率或疗效优劣，也不从“两个模型相关”推出它们学到了同一机制。架构与分歧的对应关系先作为描述性关联，因果解释留给后续受控实验。

## 主矩阵来源：888 → 745，与720个分子完整交叉

**888不是人类全部蛋白，也不是全部已知可成药靶点。** 它来自本地ChEMBL37原库：`target_dictionary.organism='Homo sapiens'`、`target_type='SINGLE PROTEIN'`，且该靶点至少有一条`drug_mechanism`记录；再连接`target_components`、`component_sequences`得到精确序列。这里允许任意药物分子类型的机制记录，不能误写成“888个都有小分子MoA”。本轮已用只读SQL重新提取并核对888个ID、UniProt组件和序列。

### 为什么之前是384，现在不以它为主范围

旧384来自更早的实验/结构筛选：888排除GPCR得到745，要求小分子MoA后450，要求五类实验靶点后408，再按实验口袋逐级筛到338；后来恢复了46个“无合格实验口袋”的靶点，得到**338＋46＝384**。本轮逐ID复核了这个集合，与既有384目录完全一致。

因此384有历史实验设计来由，但会排除295个缺小分子MoA、42个其他实验类别，以及24个未过后续口袋质量门槛的非GPCR靶点。**本研究恢复这361个靶点，不让历史实验可做性决定排序研究的主候选池。** 旧384和其96靶点家族平衡子集只保留作补充与流程核对；SPR384实验候选配对不变。先前考虑的人类全蛋白组路线按用户最新决定不作为当前主范围。

## 具体比较规则

**固定候选集合。** 靶点→分子请求720个候选；分子→靶点请求745个候选。单模型筛选与跨模型比较分开：单模型在实际完成评分的候选中排序，同时标注已评分/请求数量；模型对比只在相同候选身份上计算秩。每个查询至少20个共同有分数的候选，这个统计门槛不删改745实体目录。各模型全请求覆盖、当前已就绪模型共同交集、两两交集分别报告分母和排除数量。新增模型没有结果前不进入“全模型共同交集”。

**分开描述全排序与头部选择。** 计算逐查询Spearman、Kendall tau-b和Top5/10/20重合。秩使用平均并列秩；TopK边界同分使用分数化成员权重。常数输出的相关性记为未定义并报告数量，不能静默填0，也不能因为同样常数就认为具有有意义的一致推荐。

**使用与实际分母一致的随机参照。** 无并列、独立随机排序的两个Top10集合，在720候选中的期望交集为100/720≈0.139，在745候选中为100/745≈0.134。若共同覆盖少于请求数，必须按实际共同候选数N计算100/N；不能拿745作未完成计算的分母。补充机会校正重合度，并单列常数输出。需要显著性判断时在固定查询内置换，并考虑靶点同源簇及分子相关性。

**保留任务与输入差异。** 本轮模型包括分类器、连续亲和回归器和口袋检索器。按预先固定的头及方向比较排序，不能称所有列都在预测相同Kd。序列截断、口袋/结构来源、构建体和作者置信告警作为描述性分层，不把缺失分数变成低分。

**正确解释候选池敏感性。** 对独立逐对打分的确定性模型，增加候选可以改变名次和TopK，但共享候选间的相对顺序应保持。正常的新增候选竞争不是“模型不稳定”。区分三种现象：TopK成员因池扩大变化；共同候选相对顺序变化；相同配对原始分数变化。后两种才需要核查推理是否依赖批次/上下文或流程不一致。

当前主矩阵不因模型分歧大小而删除已知关系。若后续需要“排除已知关系的老药探索视图”，使用预先冻结的关系掩码另报分母，不根据结果挑选更容易出现分歧的候选。

## 第一阶段可以说什么

可以说：“在固定目录及共同覆盖的候选中，模型间存在多少排序差异；差异在两个方向、靶点家族和输入条件下如何分布；哪些模型呈现相近推荐模式。”

暂不说：“低相关的模型是错的”“一致推荐更准确”“某架构天然更优”“选中的药物具有新适应症”。这种阶段划分是研究范围的选择，不是阻止先报告分歧。
