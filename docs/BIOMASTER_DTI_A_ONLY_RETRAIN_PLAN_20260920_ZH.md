# A为主线的DTI研究：哪些模型需要重训

日期：2026-09-20。承接用户决定：用A的训练/验证/测试规模开展主研究，取消大规模新增B训练。**本轮调整计划及登记，不启动训练。**

官方权重同时保留为用户场景比较：训练数据不同是现成系统的一部分，但不能据此单独归因架构或宣称未见关系泛化。两条线的条件、训练暴露及覆盖规则见[官方权重比较协议](BIOMASTER_OFFICIAL_WEIGHTS_COMPARISON_20260920_ZH.md)。

参赛范围修订v3：ReTargetMap不列入本轮现成模型比较。官方DTIAM下游权重未确认，按用户最新授权复用本地A版并单列训练来源；不启用本地B版。已有六个分数通道，四个优先新增模型见[最终模型矩阵](BIOMASTER_DTI_FINAL_MODEL_MATRIX_20260920_ZH.md)。A中的共同输入全局MLP是重新训练的中性架构对照，不是ReTargetMap生产权重参赛。

当前执行入口是 [ACTIVE_PROTOCOL.json](../configs/dti_reliability_20260920/ACTIVE_PROTOCOL.json)，指向[A-only v2协议](../configs/dti_reliability_A_20260920_v2/PROTOCOL.json)。原87项计划留作历史快照；主线调整为45项A拟合，先做其中30项，条件实验另列。原B/AB的24项新拟合延期，已有B数据、权重和结果保留。

## 1. A能支撑什么结论

A适合研究配对计算形式、实体偏好、分类/排序/回归目标和双向推荐之间的关系。当前数据量足以开展这些受控实验，但总配对数不能保证所有蛋白家族或冷启动情形的统计把握度。

| 集合 | 配对 | 阳性 | 阴性 | 其中明确失活 |
|---|---:|---:|---:|---:|
| A原骨架训练 | 337,570 | 188,799 | 148,771 | 105,368 |
| A原骨架验证 | 41,806 | 24,419 | 17,387 | 11,719 |
| A原骨架测试 | 39,507 | 23,190 | 16,317 | 10,649 |

训练中另有192,469行精确Kd/Ki端点标签，可作为分端点回归辅助；它们覆盖191,189个训练配对，不是新增192,469个独立配对。明确失活继续保留为二分类监督，不编造数值Kd。

主线结论限定在**Kd/Ki证据＋明确失活**及相应适用范围，不扩展为“所有IC50/EC50混合数据都无用”。旧B成绩作为已有补充证据；停止大规模B重训，也意味着暂不继续追求A/B增量来源的全面因果分解。

原A测试可用于双向查询AP，但每药有足够多实测目标的覆盖仍稀疏：至少10个测量且正负皆有的查询，靶点方向593个、药物方向77个。外部实测面板与来源审计仍有必要。历史测试已被查看，新方案继续明确其回顾性属性。

## 2. 第一阶段：必须新训的30项

所有模型使用相同A原骨架成员，三个seed为101、202、303。基础编码器冻结，训练任务层；原始配对与明确失活保留，不采用永久150对删减。

| 模型/对照 | 拟合数 | 为什么需要 |
|---|---:|---|
| 药物单侧 | 3 | 检验药物本身的倾向能解释多少成绩 |
| 蛋白单侧 | 3 | 检验蛋白本身的倾向能解释多少成绩 |
| 两侧加性 | 3 | 建立无配对交互项的强参照 |
| 双塔余弦 | 3 | 检验独立编码后匹配的限制 |
| 低秩双线性 | 3 | 检验显式乘性交互的增量 |
| Palinova式全局交互MLP | 3 | 全局配对主干，作为目标函数对照的基础 |
| LightGBM | 3 | 相同表示上的强树学习器 |
| 上述MLP＋排序 | 3 | 排序辅助是否改变双向正确性及模型关系 |
| 上述MLP＋Kd/Ki分头回归 | 3 | 连续监督是否增加配对选择性 |
| 上述MLP＋排序＋回归 | 3 | 检验两种辅助目标是否互补 |
| **合计** | **30** | 先得到架构与目标函数的受控结果 |

共同输入采用BerMol768＋同版本ESM21280；单侧对照只使用对应一侧。旧生产Palinova使用DrugCLIP/Morgan/图均值等输入，因此这里明确命名“Palinova式共同输入MLP”，不能把改输入后的网络冒充旧生产模型的原版复现。

同样，共同输入双塔代表匹配机制，**不等同完整原版ConPLex**；后者使用Morgan/ProtBERT及其原训练流程。LightGBM是树学习器参照，也不等同完整DTIAM AutoGluon集成。旧系统仍作为历史/部署对照单列。

## 3. 需要补一个真实局部交互模型：DrugBAN

建议选DrugBAN，完成A原骨架3个seed，再进入冷靶点。其作者实现直接使用分子2D图和蛋白序列，通过分子GCN、蛋白CNN及双线性注意力建模局部交互，适合在现有SMILES/序列资源上开展重训。[官方实现](https://github.com/peizhenbai/DrugBAN)

这3项在图/序列身份映射、截断和覆盖审计、原生前向与梯度检查、吞吐测试通过后执行。采用vanilla监督版本，**不使用测试输入做域自适应**。不能将某模型输入失败的样本静默移除，再与其他模型全量成绩比较。

DrugBAN与共同输入MLP的比较同时改变了输入表示、编码器和交互结构，只能解释为两个学习体系的差异。若要证明“局部注意力本身”的因果贡献，后续还需同编码器下去掉/替换交互层的对照；不能仅凭DrugBAN获胜或失败概括所有局部交互模型。

## 4. 保留12项冷靶点对照

A冷靶点划分为训练369,213、验证26,047、测试23,623对，与原A处于同一量级。成员已按同源簇重新划分，需新初始化监督模型，原骨架权重不能直接充当未见靶点的模型。

固定两侧加性、共同输入MLP、LightGBM、DrugBAN四个代表，各3seed，共12项。选择在看新测试结果前固定，不挑原骨架测试分数最好的四个来伪装预设。

这一步检验原骨架结果能否转移到新蛋白群。主线总数为 **30＋3＋12＝45项**；先执行30项共同输入实验，后续按适配和资源准备程度推进。次数不等于计算成本，ETA仍需实际吞吐及验证开销测试。

## 5. 哪些模型先复用，哪些暂不重训

| 模型 | 当前处置 | 理由与边界 |
|---|---|---|
| **DTIAM A** | 复用验证集已选出的A版；16对复算通过；不新增拟合 | 明确标为本地A训练；当前权重只对应原骨架历史划分，不冒充冷靶点重训；纯架构对照用共同输入LightGBM |
| **旧ReTargetMap / Palinova A** | 保留生产权重及已完成A消融供历史追溯 | 原ReTargetMap不参赛；新共同输入MLP按中性架构对照命名，与旧生产模型分开 |
| **ConPLex** | 保留官方推理，先重训共同输入双塔 | 原版完整重训不是当前第一阶段的前提；原始特征/目标与受控双塔分别标明 |
| **DrugCLIP** | 不列新增主线训练 | 依赖分子/口袋3D和原对比学习体系；A标签本身不能补齐口袋与训练输入 |
| **Nesso** | 复用分类/连续头，先完成现有推理 | 原生模型重训及输入准备投入需单独评估；同主干两头现象可先用现成输出研究 |
| **ProbeMatchDTI / DTBind** | 保留现成权重，暂缓全量原版重训 | 首轮局部交互由DrugBAN代表；具体归因这两个系统仍需其自身匹配实验，不能由DrugBAN替代证明 |
| **EviDTI / SCOPE** | 先验证作者权重和输入适配 | 任务/目标覆盖未完全对齐，先解决“能否公平评测” |
| **TAPB** | 条件升级 | 若要验证先验去偏，做有/无干预的匹配训练，各3seed；单独训练一个TAPB不足以归因去偏模块 |
| **DeepDTA** | 暂缓 | 经典参照可后补，当前计算形式已有CNN局部模型及强全局基线覆盖 |
| **JEPA** | 后续独立方法线 | 不把新表示必须获胜设为本次可靠性研究成立的前提 |
| **TxGNN** | 继续疾病推理 | 与直接结合架构归因是不同任务 |

TAPB官方代码围绕靶点先验干预设计，因此它适合在实体偏好问题明确后进行针对性机制实验；该方法定位不能替代我们自己数据上的效果验证。[官方实现](https://github.com/GaomingL1n/TAPB)

## 6. 条件实验和结论边界

另外登记15项，**不自动加入主线队列**：来源去重下加性/MLP各3seed共6项；共同输入双塔ReLU对照3项；TAPB有/无干预各3seed共6项。是否激活及具体配置应在查看相应测试结果前记录。来源去重还会改变训练规模；其成绩变化不能全部解释为泄漏。

取消B扩量后，文章主线是：实体先验解释多少预测表现；同一输入下配对计算增加什么；排序/连续监督是否改善双向选择；这些结论在冷靶点上是否稳定。七个现成模型继续提供部署场景的分歧和共同错误证据。受控小模型结论不能自动变成对所有公开模型的原因分解。

Kd/Ki与失活继续按原审计规则使用；未知配对不作阴性。验证集决定检查点和阈值；测试不决定模型去留或可报告指标。双向宏AP、明确失活误报率、种子稳定性和实际可评价查询数一并报告。
