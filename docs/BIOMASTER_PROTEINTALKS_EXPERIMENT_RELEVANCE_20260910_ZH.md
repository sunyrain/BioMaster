# ProteinTalks实验对BioMaster SPR384的用途

结论：可复用公开细胞扰动蛋白质组，优先用于SPR后的细胞效应和机制验证。不能把蛋白丰度变化当成直接结合证据，也不据此自动重排冻结384。

## 最有用的现成数据

Table S8：PTPC有716扰动标识、708个不同化合物名称，提供5个非乳腺癌细胞系的实验元数据和蛋白丰度矩阵，包含6及24小时处理。细胞系为A375、HCT116、NCI-H1975、NCI-H2170和Panc 10.05。不是每药×每细胞的完整笛卡尔实验。

直接解析S8B的SMILES生成完整InChIKey，并与S8A实验元数据对应后：

| 与本项目交集 | 数量 |
|---|---:|
| 注册720药中精确结构匹配 | 69药 |
| 冻结384涉及的药物匹配 | 26药 |
| 上述26药涉及的冻结候选 | 40对 |
| 112靶点中UniProt出现在S8C表头 | 39靶 |

未去盐或放宽立体化学匹配，实际可通过进一步身份审查扩展，但本次不算入。40对仅表示候选药物有该数据集的细胞扰动记录，绝非40条直接结合证据。39靶表头覆盖不表示每个样本均有可用定量。本轮未进行差异蛋白或通路重分析。

例：布洛芬–CA4、尼莫地平–CA7、恩西地平–BRAF、沙利度胺–MIF均有对应药物的HCT116扰动记录；不能据此推定变化由这些新靶点引起。跨疾病项目使用癌细胞数据时需限定细胞背景。

## 实验思路如何借鉴

1. 药物处理后的时间序列蛋白质组：对可靠SPR命中的小批候选，比较候选药、机制匹配参考药及溶剂对照的细胞变化，控制普遍毒性和应激。时间点应按目标生物学设计，原研究的时间点不自动适合所有通路。
2. 靶点依赖验证：补充图3及S17使用HCC38的PALLD siRNA敲低联合用药；可借鉴为新靶点敲低/扰动后药物效应是否变化的实验逻辑。对具体候选应设置适当对照，必要时用恢复表达等设计支持归因；后者是本项目建议，不宣称原文均已实施。
3. 剂量反应和患者来源类器官：适用于已经形成肿瘤适应症假设的后续少量命中，不宜让全方向384直接进入乳腺癌类器官。S14的3000化合物库是用于预测筛选的清单，不能当成3000药全部做过类器官实测。

建议先利用现成重合数据定位可复查样本，SPR照当前计划分批推进；优先对重复确认的命中做对应酶活/受体功能与细胞靶点依赖实验，再为少量机制价值较高的候选投入动态蛋白质组。没有必要为了利用这篇文章先重训一个虚拟细胞模型。
