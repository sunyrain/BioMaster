# 原先SPR实验候选的质量复核

复核对象：2026-09-04冻结的SPR512 V2方案。原始清单和盲化交付文件未修改；不是9月7日中止的PocketPrecision候选重新推荐的名单。

**判断：这是一批有模型排序依据、选样设计较完整的探索性实验候选，尚不能称为已验证的高命中率候选。近期结构模型升级失败，不会自动推翻这批更早模型给出的候选；同样，旧模型的离线AP也不能直接换算为这批SPR的命中概率。**

## 1. 已独立复核的选样质量

| 项目 | 复核结果 |
|---|---|
| 总规模 | 32靶点、512个不同pair |
| 待测候选 | 480对、120种药物；每药2–6个靶点 |
| 模型高排／中排／低排 | 320／96／64对；每靶点固定10／3／2对 |
| 已知阳性对照 | 每靶点1个，共32个，不计入发现命中率分母 |
| 排名区间 | 逐对符合原先冻结规则 |
| 药物连接结构去重 | 通过 |
| 与当时FULL_FIT训练关系的精确交集 | 独立重算为0 |
| 实测结果 | 冻结交付包内未发现KD结果或sensorgram；无法计算真实命中率 |

高、中、低组和阳性对照有助于判断模型是否富集结合事件，优于只保留高分候选的不可比较清单。但64个低排候选是背景组，**不是预先确认的生物学阴性**。同一药物和同一靶点被重复使用，实验后统计也不能把480对当作完全独立样本。

32个靶点均为当时训练已见靶点；120种药中77种已见、43种未见，对应316个双端已见候选与164个药物冷启动候选。它们都是未见精确关系，但并非相同泛化难度，宜分别报告实验后的表现。

原冻结设计的FDA映射、外部关系排除和化学骨架统计有历史清单可追溯；本次没有重新穷尽最新文献或专利，因此不会将“快照中无精确关系”升级成“截至今天首次发现”。

## 2. 模型证据的强弱不能混合

| 子集 | 候选总数 | 高排数 | 原推荐依据 |
|---|---:|---:|---|
| 冻结384核心发现组，20靶点 | 300 | 200 | S5独立drug→target排序，完整rank/384；高排≤20 |
| 扩展367生化路线组，12靶点 | 180 | 120 | FULL_FIT生化路由rank/367；高排≤30 |

核心组的排序模型有冻结S5开发/测试谱系。此前0.7521的药物宏AP是在有正负标签的稀疏实测候选集合上计算，不能解释为Top-20未知关系有75.21%的SPR命中率。

扩展组有模型排序和靶点可实验性依据，但不能继承核心S5的性能。12个扩展组靶点中只有6个在旧384目录之外；“实验分组属于扩展路线”和“靶点在目录之外”也应区分。两种排名的候选分母不同，不宜直接混算排名与KD的相关性。

这批候选的准入和优化没有使用DTIAM；内部表中的DTIAM列是事后标注。此次复核也没有依据外部模型重选候选。

## 3. 目前最具体的质量薄弱点

### 阳性对照的证据强度需要更准确地表述

原先“29个对照有Kd或Ki支持”成立，但进一步拆分为：

| 对照证据 | 靶点数 |
|---|---:|
| 记录包含Kd | 14 |
| 有Ki、没有Kd | 15 |
| 只有IC50 | 3 |

Ki和Kd不能当作相同终点，既有记录也不等于本批构建体的SPR表面已经验证。只有IC50记录的三个对照是AKR1B1–zopolrestat、TPH1–telotristat、NT5E–quemliclustat；它们在原方案中已经要求先验证对照适用性。蛋白构建边界仍是实验组待确认项。

### 化学规则筛选不能代替实验质量

原规则在120种药物中标记7种，涉及15个候选pair：serdexmethylphenidate、ospemifene、vericiguat、resmetirom、calcitriol、cefepime、tazemetostat。它们都仅为原规则1分，不能据此认定无效，也不能把其余0分药物视为已经排除非特异性。

例如ospemifene和calcitriol的计算cLogP分别约5.65和5.70，是需要核查实际溶解度的线索。聚集和非特异性可影响结合实验，因此候选成为“确认命中”仍需实际质量控制；本次没有新增药物级聚集实验。[NCATS/Eli Lilly《Assay Guidance Manual》聚集干扰说明](https://www.ncbi.nlm.nih.gov/books/NBK442297/)

### 结构证据是有限支持

冻结表中390/480对标记局部结构模型可用，90对走相应全局路径；该mask不能解释为390对有实验结合结构。靶点表中ELANE、FKBP1A、REN未达到当时严格预测口袋门槛，其他29个通过。这不否定这些靶点可实验，只表明结构支持并不均匀。

“有预测口袋”也不是“这个药物已被证明能占据该口袋”。目前没有逐对实验结构或新SPR结果支持把这480对提升为确认作用关系。

## 4. 与新架构训练的关系

本次另行核查≤2020关系训练数据及同assay对照：能映射到当前384靶点登记空间的390个冻结候选，没有精确测量监督交集；另90对的靶点不在当前训练目录内。没有用候选名单中的高、中、低排名生成伪标签，也没有读取实验结果训练。

这些候选可以继续保留原冻结身份，供实验返回后评价原推荐模型。新架构属于新的开发实验；它的成绩和推荐不能覆盖原名单的模型谱系。此前反复查看过的2023–2025和KIRHub集合也不能作为新架构选择集。

本次独立审计的12项选样检查全部通过；其中“训练关系无精确交集”是对历史训练表重新计算，外部BindingDB/GtoPdb排除状态则沿用原快照审计。没有声称重新完成480对的全面新颖性审查。
