Accession 与去重口径

UniProt accession 是数据库记录编号，不等同于结合位点或突变位点。ChEMBL 表中多个 accession 可能对应完全相同的氨基酸序列，因此它们对 ConPLex 和当前 wild-type receptor docking 来说是重复计算对象。

去重键是 drug_id + protein sequence。不同药物不会被合并，同一药物面对不同蛋白序列也不会被合并； 只在同一药物面对完全相同蛋白序列时选取一个结构代表执行 DiffDock，再把结果回填到对应的 UniProt accession 行。
