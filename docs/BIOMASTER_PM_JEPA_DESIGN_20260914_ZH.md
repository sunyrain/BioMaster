# 蛋白—分子基础嵌入到组合表征 z：JEPA 设计草案

现有数据与硬件已实查，具体的昂贵模态选择、训练集交集、实验结构缓存存续及 512 维表示建议见 [模态与资源盘点](BIOMASTER_PM_JEPA_MODALITIES_AND_RESOURCES_20260914_ZH.md)。其中模板口袋、真实复合物及预测姿态分别计数，以下接口保持不变。

用户确定的推理接口是：每次提供蛋白基础嵌入 `e_P` 与分子基础嵌入 `e_M`，模型生成组合表征 `z`，再由 `z` 预测亲和及相关性质。原子/残基级输入、遮蔽原始序列、完整结构重建均不是此接口的前置要求。此设计尚未实现或启动训练，DTIAM 继续原计划。

**固定的部署流程**

```mermaid
flowchart LR
    P[蛋白基础嵌入 e-P] --> C[组合上下文编码器 C]
    M[分子基础嵌入 e-M] --> C
    C --> Q[表征预测器 Q]
    Q --> Z[预测的组合表征 z]
    Z --> H[亲和及性质预测头]
```

`h = C_theta(e_P,e_M)`；`z = Q_phi(h)`；`y_hat_e = H_e(z)`。C 与 Q 可以对外封装为 `encode_pair(e_P,e_M)`。按此方案，部署时保留 Q，因为用户需要它预测的 z；不机械套用某些图像 JEPA 下游丢弃 predictor 的做法。每次输入双方嵌入即可，不要求推理阶段提供已知亲和标签、教师信息或另行运行对接。

这个流程在工程上合理，与已有缓存兼容。“最优表示”应理解为通过训练和独立评估，找到对既定亲和/性质任务更有效的表示；不存在预先给定、普遍最优的真实 z，也不保证优于已有模型。

**融合结构和 JEPA 训练目标分别定义**

融合提供组合信息，JEPA 则通过预测目标视图的潜在表示来训练。单独的 `e_P,e_M → z → y` 配合亲和损失，已经是合理的监督表示学习模型；加入明确的目标表示、预测损失和防塌缩机制，才构成本草案中的 JEPA 扩展。JEPA 并不要求输入一定是多模态，也不保证自动找到最优表示。[I-JEPA](https://arxiv.org/abs/2301.08243)

Mol-JEPA 展示了将已有向量等模态送入可训练模块、预测潜在表示并用于下游任务的路径；它可作为方法参照，不能直接等同于本项目的 `(P,M)` 模型。[Mol-JEPA](https://arxiv.org/html/2608.22642v1)

**训练时，z 的目标从哪里来**

需另有组合目标编码器 `T_xi` 产生 `z_target`，而不是宣称教师已知“最优解”。可研究两种目标构造：

1. 使用同一组合的不同编码视图或信息更丰富的组合视图。现有 ESM2、DrugCLIP、BerMol、Morgan 等是可核查的候选；教师/目标编码器必须融合双方信息，不能仅以孤立蛋白或分子表示作为最终组合目标。额外向量是模型表征，不冒充新增实验事实。
2. 若确有可靠且可对齐的组合级结构或实验上下文，可作为训练专用的补充目标信息；只在实际有该信息的成员上使用，并区分实测与预测来源。第一版不以取得此类数据为前提。

目标编码器使用停止梯度及适当的更新/防塌缩机制，具体采用 EMA 或带正则的联合目标需在实验前定义。若双方总看完全相同信息、只要求复制表示，任务可能退化为复制或常数解；预测损失下降本身不能证明 z 含有交互知识。不同视图、正则、真实任务监督与泛化诊断共同约束训练。

本草案的基础训练形式是：

`L = lambda_repr * D(z,z_target) + lambda_task * L_properties(H(z),y) + lambda_reg * L_anti_collapse`

分类、分端点回归及排序的具体取舍通过受控对照确定，不预先认定全部辅助目标一起加最优。亲和监督应作用于实际部署使用的预测表征 z，避免只把性质头训练在教师 z_target 上，推理却改用学生 z。

教师不预先读取验证/测试或 SPR 留出标签。若未来将训练测量值本身编码为教师信息，应明确称为带特权信息的混合监督/蒸馏方案，并单独比较，不能声称无标签自监督。仅预测由单个亲和值编码出的向量也不自动获得通用组合表示。

**输入与性质边界**

第一版从现有固定全局嵌入起步，学习 C、Q 与性质头；局部 token、结构视图和上游编码器微调是后续可选扩展。以可学习的交互融合保留双方依赖，但不将 attention 或潜在距离当成物理接触或亲和力本身。

Kd、Ki、IC50、EC50 分头、按有标签的位置计算监督。精确值和删失界限分别处理；来源失活不作为任意条件下绝对不结合的证明。推理只有基础嵌入时，模型不能恢复未输入且无法从身份推断的实际实验条件，应保留适用范围与不确定性。缺失性质不补成 0，未测配对不造阴性。

**可用数据与最小对照**

A 有 337,570 个训练配对；B 有 1,116,270 个训练配对。现有 B 回归辅助视图为 799,246 条配对—端点记录、766,314 个不同配对。B 中 181,182 个分子测过至少两个靶点，48,036 个分子兼有原定义的已测两类，可帮助检验交互特异性。交叉覆盖审计见 [PAIR_COVERAGE.json](../outputs/biomaster_pm_jepa_design_20260914/PAIR_COVERAGE.json)；端点适用的正负及排序成员仍需按新任务定义核对。

直接对照应使用相同基础嵌入、C/Q/性质头架构、训练成员与计算预算：一组只用性质监督，一组增加组合目标表示预测。后续再对比先 JEPA 预训练后微调。DTIAM 作为外部参照，不能代替上述判断 JEPA 增益的直接对照。

评价包括同靶点及同药物排名、低误报操作点召回、分端点回归及严格来源/新骨架泛化。固定 z 后用相同简单预测头评估，可辅助判断表征是否可迁移。仅蛋白、仅分子及双方输入的受控对照，用于检查是否忽略一方；表示方差与有效秩用于检查塌缩。

后续交付目标明确为 `encode_pair(e_P,e_M) → z` 与 `predict_properties(z)`。当前已完成接口和训练目标讨论，尚未声称训练了 JEPA，也没有运行成本或性能的实测结论。
