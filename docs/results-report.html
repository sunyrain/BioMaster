项目目标

BioMaster 的目标是建立一个可复现的药物再定位计算筛选流程，从已批准小分子药物中发现值得进一步机制分析和实验验证的药物-靶点组合。

本阶段以 pan-cancer 为疾病方向，先进行广覆盖 AI-DTI 主筛选，再引入靶点疾病证据、药物疾病图谱信号和结构对接证据，最终形成候选优先级。该结果是计算假设，不是药效或机制的实验证明。

流程思路

01药物库与靶点库标准化
02915000 个 pair 的 AI-DTI 互作预测
03Open Targets 与 STRING 靶点疾病证据融合
04TxGNN 药物疾病图谱信号补充
05Top 候选 DiffDock 结构增强与共识排序

这种分层设计的重点是先保证覆盖面，再用疾病证据和结构证据逐步收敛。不同证据源回答的问题不同，因此最终排序应理解为综合优先级，而不是单一模型输出。

证据解释

ConPLex

回答药物是否可能与某个蛋白发生相互作用。

Open Targets

回答某个基因/蛋白是否与 cancer 疾病概念存在数据库关联。

STRING

回答靶点是否位于疾病相关蛋白互作网络中。

TxGNN

回答药物是否具有 cancer 方向的图谱推断信号。

DiffDock

回答高优先级候选是否具备可解释的结构姿态线索。

结果如何使用

当前结果可用于候选筛选、文献审阅、机制假设生成和实验设计。更适合的使用方式是从结构增强 Top100 中进一步筛选 20-50 个候选 pair，再结合药物可获得性、安全性、具体癌种背景和实验可操作性进入验证设计。

Open Targets 口径

Open Targets 分数是靶点-疾病层面的关联证据，不表示所有蛋白都有 cancer-specific site，也不表示药物已被证明对癌症有效。若后续聚焦具体癌种、突变或分子亚型，应切换到更具体的 disease ID 或引入突变/亚型数据重新排序。
