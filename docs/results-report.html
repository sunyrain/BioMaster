项目目标

BioMaster 的目标是建立一个可复现的药物-靶点计算筛选流程，从已批准小分子药物中发现值得进一步机制分析和实验验证的药物-蛋白组合。

本阶段采用 ChEMBL druggable target 表作为蛋白范围，先进行全量 AI-DTI 亲和预测，再按肿瘤、感染、心血管、神经/精神、免疫/炎症五个方向进行疾病证据收敛和结构对接增强。该结果是计算优先级，不是药效或机制的实验证明。

流程思路

01FDA 已批准小分子与 ChEMBL druggable protein 标准化
02按唯一蛋白序列执行 ConPLex 亲和预测
03扩展回 4854990 个完整 drug-target pair
04五个疾病方向分别形成 Top10000 候选并按 drug + sequence 收敛为结构代表
05AlphaFold receptor 准备、DiffDock 对接与中文候选合理性解释

这种分层设计的重点是先保证药物相关蛋白空间内的覆盖面，再通过序列去重和结构证据逐步收敛。不同模型回答的问题不同，因此最终排序应理解为综合优先级，而不是单一模型输出。

证据解释

ConPLex

回答药物是否可能与某个蛋白发生相互作用。

ChEMBL target set

限定当前筛选空间为已有 druggability 背景的药物相关蛋白。

Sequence de-duplication

减少重复蛋白记录带来的冗余预测和冗余对接。

AlphaFold

为结构代表提供可输入 DiffDock 的 receptor 结构。

DiffDock

回答高优先级候选是否具备可解释的结构姿态线索。

代表性结果解释性

结果中出现多组已知药理关系，例如 Naltrexone/Naloxone - OPRK1、Dorzolamide - CA2、Gefitinib - EGFR、 Cyclosporine - PPIA 和 Octreotide - SSTR2。这些关系可作为流程阳性对照和一致性证据，说明模型能够从大规模组合中找回可解释的药物-靶点信号。

也有部分同家族扩展候选，例如 kinase 或 GPCR 家族内的高分结果。它们适合作为文献审阅和二次 docking 的入口， 但不能直接视为已验证作用靶点。高亲和但 missing-output 的候选应作为结构准备和参数补跑队列单独审计。

结果如何使用

当前结果可用于候选筛选、文献审阅、机制假设生成和实验设计。更适合的使用方式是从结构增强 Top100 中进一步筛选 20-50 个候选 pair，再结合药物可获得性、安全性、疾病背景和实验可操作性进入验证设计。

Accession 与对接位点

UniProt accession 是蛋白记录编号，不是结合位点。当前只合并同一药物面对完全相同蛋白序列的重复记录； 不同药物仍分别对接，同一药物面对不同蛋白序列也分别对接。若要研究突变位点或特定 pocket，需要引入对应突变结构或口袋约束后单独建模。

Open Targets 口径

Open Targets 是靶点-疾病层面的关联证据，不是当前 druggable-proteome 主筛选的必要前置条件。若后续聚焦具体癌种、突变或分子亚型，应切换到更具体的 disease ID 或引入突变/亚型数据重新排序。
