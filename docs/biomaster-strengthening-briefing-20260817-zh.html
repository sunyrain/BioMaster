03 · Frozen design space

从888个官方靶点到384个部署靶点：每一步为什么删？

这里的“删”不是说靶点没有生物学价值，而是说明它不满足当前这条“标准小分子、非GPCR、可解释、可执行、可审计”主线。被删目标仍保留在888全集和排除审计中，不得被误称为真实阴性。

最重要的分区恒等式：480 + 338 + 46 + 24 = 888；最终活动部署空间为 338 + 46 = 384。因此“888→480→408→24→384”应理解为：先排除480个硬门槛目标，408个进入口袋审计，再排除24个口袋质量不足目标，剩下384个由严格主线与恢复分支共同组成。
阶段数量保留 / 排除条件为什么要删或单列对模型与实验的含义
官方起点888ChEMBL 37；Homo sapiens；SINGLE PROTEIN；至少一条 drug mechanism/MoA 记录。这是可追溯的官方靶点全集，不是根据模型分数挑出的候选。全部进入上游审计；不代表全部适合本项目的同一实验协议。
硬门槛排除（143+295+42=480）480143 GPCR + 295 无 ChEMBL Small-molecule MoA + 42 不在五类标准实验家族。GPCR需要独立膜蛋白/构象协议；没有直接小分子MoA就缺少本项目的蛋白结合锚点；胞外/表面/结构/其他非常规类别缺少统一 assay lane，硬塞进主线会把可测性差异误当模型能力。永久退出本版384部署，但仍保留在888排除审计；不等于“不可成药”或“没有活性”。
硬门槛后（888−480=408）408非GPCR、有 ChEMBL 小分子 MoA，且属于激酶、酶、核内/表观遗传蛋白、离子通道或转运体。这一步不是再按预测分排序，而是得到统一可解释的 target-engagement 实验家族。408是口袋和结构证据审计的正式分母。
口袋审计中永久排除（21+3=24）2421 个没有“优先实验口袋”；3 个虽有优先实验位点，但只有辅因子/功能片段、没有 drug-like holo 口袋（DNMT3A、ODC1、TXN）。“有一个结构”不等于“有适合常规小分子建模的口袋”。若位点不是药物映射高质量实验口袋或专业数据库确认位点，模型可能在错误位点上产生稳定但不可解释的高分；辅因子/片段位点也不能直接替代药物样配体口袋。永久排除，避免把结构证据不足的目标混入严格主线；后续若补到更高质量结构，应建立新版本重新审计。
最终活动空间（338+46=384）384338 strict experimental-pocket mainline + 46 recovered no-experimental-pocket branch。384不是384个同等证据等级的靶点，而是“严格主线 + 明确标注风险的恢复分支”的联合部署空间。338可进入实验holo口袋主线；46只能使用序列/化学/数据库和计算口袋证据，并配套更保守的W1验证，不得直接称为实验结构靶点。
338 · strict mainline

为什么能进主线？

每个目标都有 preferred experimental pocket：来自药物映射的高质量实验口袋或专业口袋库确认位点，并且至少有 drug-mapped / drug-like holo 配体证据。当前338个中，160个为药物映射高质量实验口袋，178个为专业口袋库确认位点。

46 · recovered branch

为什么没有直接删掉？

这46个目标已经通过非GPCR、小分子MoA和支持家族硬门槛，唯一缺口是没有合格实验口袋。为避免把“数据库尚未有结构”误判成“没有可成药口袋”，项目使用P2Rank/fpocket一致位点或几何救援；但它们必须单列、先做口袋/对照验证。

重要边界

删掉意味着什么？

删掉的是“进入当前计算与实验主线的资格”，不是生物学阴性标签。所有未进入384的目标都仍可能有价值，只是不能在当前证据等级下与338个主线目标并列排序。

顺序核对：408个目标中，362个有至少一个合格实验口袋；46个因此进入恢复分支。362个中341个达到优先实验口袋；21个被永久排除。341个中338个还有 drug-like holo 证据；3个（DNMT3A、ODC1、TXN）被永久排除。故 46 + 21 + 3 = 70 个从严格338主线退出，但其中46个被明确恢复，最终活动空间仍为384。

汇报时建议的准确说法

“我们从888个ChEMBL37人源单蛋白MoA靶点出发，先以非GPCR、直接小分子MoA和标准实验家族三个硬门槛排除480个目标，得到408个结构审计分母；再因口袋证据质量排除24个，形成338个严格实验口袋主线，并对其中仅缺实验口袋的46个目标建立计算恢复分支，最终冻结384个活动部署靶点。”

04 · Old-drug cohort construction

720个“老药”到底是怎么筛出来的？

720不是从全部FDA化合物里随机抽样，也不是模型看到标签后临时挑出来的。它是一个冻结的、可追溯的标准模型药物池：先从FDA原始NDA产品窗口做实体和结构清理，再用ChEMBL直接蛋白MoA与标准非共价模型适用域收敛，最后按InChIKey生成唯一模型结构。

严格口径要分三层说：844 个通过FDA实体/结构/安全硬门的标准单一结构药物 → 747 个有ChEMBL直接蛋白MoA → 683 个至少有一个物种进入标准非共价模型适用域 → 732 条给药/活性配体物种映射 → 按唯一InChIKey折叠为 720 个唯一模型配体结构。
阶段数量保留规则为什么删除 / 暂缓最终用途
FDA实体起点8442005-01-01至2026-08-03快照中的原始NDA产品窗口；RxNorm active-moiety、GSRS/UNII和结构字段可追溯；单一化学结构。删除未解析mixture、诊断/显像、气体/电解质/聚合物、物理吸附或主要依赖非特异化学反应的实体；重大安全hold和保守DNA/广谱细胞毒实体不进入标准老药新靶点主线。原因是这些实体没有一个可解释、可复现的单一蛋白配体表示。形成标准单一结构药物母池；被删实体进入 exclusion/safety hold 审计，不被当作阴性。
直接蛋白MoA门（844→747，删97）747至少一个ChEMBL直接蛋白MoA；允许人源单蛋白、其他人源蛋白或非人源蛋白MoA作为药理先验。没有直接蛋白MoA的药物可能通过核酸、膜扰动、代谢物、免疫或其他非标准机制起效；若直接塞入本项目，会把“没有蛋白结合先验”与“模型预测失败”混在一起。只保留有蛋白结合成药先验的老药；非人源MoA并不自动删除，因为它们仍可能有未报告的人源靶点。
标准模型适用域门（747→683，暂缓64）683至少一个给药/活性配体物种可用标准非共价协议处理，结构可解析、可生成构象并满足常规模型范围。64个药物暂缓：反应性/共价机制、高极性或核苷酸样、分子过大或过度柔性、气体/非特异小信使等需要专门协议；当前没有建立统一协议就不生成“假装可比”的分数。683个进入严格亲和主队列；64个保留在 deferred 清单，未来若建立专项模型再单独回收。
配体物种层（683个实体→732条映射）732678条 administered/approved active moiety + 54条 ChEMBL-annotated active species，全部通过标准非共价协议。一个FDA实体可能对应前药/活性代谢物/标注活性物种；若只保留商品名，会漏掉真实作用物种；若不区分物种，又会把前药和活性体错误合并。先保留物种级追踪，记录 project_entity_id、ChEMBL物种ID、角色和SMILES。
唯一模型结构层（732→720，折叠12）720按完整InChIKey去重；使用canonical model SMILES；每个结构必须有有效Morgan2048指纹。跨药物共享同一活性结构时只计算一次，避免重复任务和人为放大某一化学实体的权重；当前708个结构对应单一项目实体，12个结构由两个项目实体共享。形成720×384笛卡尔部署矩阵；720是唯一模型结构数，不能简单等同于720个互不相同的FDA批准分子。
实体主键

InChIKey决定“是不是同一个药物结构”

项目实体用于追溯FDA药物，完整InChIKey用于模型去重，SMILES用于化学表示。盐型、前药和活性代谢物不凭名字强行合并，只有在结构和物种映射规则下才折叠。

模型表示

Morgan2048是计算输入，不是标签

720个结构全部通过RDKit解析并生成2048位Morgan指纹；指纹只描述化学结构，不能把“进入模型”解释成“已经有活性”。

冷启动保护

训练时排除了这些老药

S5训练集不包含720个部署药物实体，也不包含它们的Bemis–Murcko骨架；因此部署是老药实体/骨架冷启动，而不是在已知老药上复读训练标签。

汇报时可以简称“720个老药”，但严格说法是“720个唯一标准模型配体结构，来自683个严格FDA药物实体及其732条给药/活性物种映射”。这样既保留直观表达，也不会掩盖实体、物种和结构三个层级的差别。

老药筛选的科学边界

这720个实体池代表“项目冻结、可计算、具有直接蛋白药理先验的老药空间”，不等于所有上市药物总体，也不等于所有临床可用药物。它提高了结构计算和W1实验的可执行性，但也带来适用域偏倚：结果首先适用于这批被标准化、去重和模型化的老药，而不是自动外推到所有药物。

08 · Leakage and validity audit

Architecture detail · ODTI V2

从一行药物–靶点对到最终部署分数

模型的基本处理单位是一个 pair：一个模型化药物结构、一个靶点、一个靶点家族以及可选的靶点辅助视图和口袋上下文。训练时再附加标签与分组字段；推理时只提供特征，不提供已知关系标签。

一句话概括：Morgan 2048 和 ProtBERT 1024 先分别编码到 192 维；随后通过拼接、逐元素乘积、绝对差、可学习双线性交互和家族嵌入构成 984 维 pair representation，经 256 维 trunk、共享 head 和 6 个 pair-conditioned experts 得到 base_logit；ESM2 与结构信息只作为带 mask 的 residual，缺失时严格回退。

2. 药物与靶点编码器

Drug encoder：Morgan 2048 → 512 → 192；可选 drug_aux 768 → 512 → 192，并通过 sigmoid(gate([drug_base,drug_aux])) 作为残差加入。缺失或关闭时 drug_aux gate 为0，不改变默认Morgan路径。
Target encoder：1024 → 512 → 192，结构相同。得到 d∈R192 与 t∈R192。

3. 可选靶点增强

pooled ESM2 1280 → 512 → 192，经 sigmoid(gate([t, esm2])) 控制后加到 target embedding。token 分支则将 residue token 编到192维，用4-head cross-attention接收 query=d+t，再经过独立 gate 加回 target；它是实验分支，不是当前默认结构。

4. Pair interaction trunk：模型真正判断“这个药和这个靶点是否匹配”的地方

对每个 pair 构造：

pair = [d, t, d⊙t, |d−t|, Bilinear(d,t), family]

其中前四项分别表示两侧实体、逐元素相似/互补和距离；Bilinear(d,t) 是 V2 相对 V1 的核心交互升级；family embedding 提供实验家族上下文。五个 192 维向量加 24 维家族向量，得到 984 维 pair feature；随后经过 984 → 256 → 256 的 pair trunk。

5. 共享 head + 6 个专家

trunk hidden 同时进入一个 shared head 和 6 个 expert heads。每个 expert 输出一个标量；另一个 gate 网络读取 [d,t,family]（408 维）并输出 6 个 softmax 权重。最终 routed score 是 6 个 expert score 的加权和，因此不同药物–靶点 pair 可以使用不同的专家组合，而不是所有 pair 共用一个固定分类器。

6. Base logit 的三部分

base_logit = shared_head(hidden) + routed_expert_score + exp(dot_scale) × cosine(d,t)。cosine 项提供全局表示相似度；shared/expert 项负责非线性和家族条件交互。当前 V2 默认不读取 ConPLEx pair score；ConPLEx 只保留在独立审计/对照路径。

7. 结构 residual：只增加证据，不覆盖 sequence/chemistry base

19 维结构上下文经过 19 → 256 → 192 的 structure encoder，与 drug、target、structure、drug⊙structure、|target−structure| 和 family 组成另一组 984 维结构 pair feature，再经 256 维 structure trunk 和 structure head 得到 residual。最终：

final_logit = base_logit + structure_mask × structure_gate × residual_logit

因此 structure_mask=0 ⇒ final_logit=base_logit 逐元素成立。当前部署中 181,440 行有结构 mask，95,040 行没有结构并严格回退；没有结构不会被编码成“负相互作用”。

8. 模型输出：训练输出、单 pair 输出与部署输出

输出含义用途与边界
base_logit不使用结构 residual 的 sequence/chemistry 基线 logit。检查结构分支增量；缺结构时就是最终 logit。
final_logit融合可用 ESM2/结构 residual 后的原始活动 logit。先用于排序；不是概率。
temperature-scaled probabilitysigmoid(final_logit / T)；T 只在 validation 上拟合。用于候选排序、Top-K 和 rediscovery；S5 的 ECE 仍较高，不能当真实结合概率。
affinity辅助亲和力回归头；配套 affinity_log_variance 表示异方差不确定性。用 Ki/Kd/IC50 的 exact、lower/upper 或 interval 观测训练，不替代主 activity label。
observation_logit被数据库/实验观察到的倾向性。当前 ChEMBL37 校准表没有显式 observation indicator，因此默认不产生有效监督；为后续 OFER-DTI 保留接口。
gate / structure_gate6 个专家的 pair 路由权重，以及结构 residual 的门控强度。用于解释模型依赖哪类专家/结构证据，不应直接解释成活性概率。
ensemble mean/std5 个独立 seed 的概率均值、标准差、上下界。部署时按 mean 排名，用 std/spread 做 uncertainty triage；不是 conformal guarantee。

9. 训练标签与总损失

主标签来自 ChEMBL37：mean pChEMBL ≥6 为正，≤5 或 explicit inactive 为负；5–6 灰区和冲突关系剔除。总损失为：

BCE + 0.12×within-target ranking + 0.06×censored affinity + 0.10×observation + 0.05×bidirectional contrastive

within-drug ranking、expert-balance 和 target-wise listwise ranking 已实现，但默认权重为 0；它们必须通过新的 paired suite 才能晋级。

10. 当前正式配置与未晋级分支

当前 S5 部署：Morgan2048 + ProtBERT1024 + family embedding + pooled ESM2 1280 auxiliary + 19-D structure context；5 个 seed 集成；token cross-attention 关闭，ConPLEx 不作为当前 V2 输入。
未晋级原因：residue-token cross-attention 短预算 micro-AUPRC 相对 V2.1 下降约 0.00710；dual-query/within-drug ranking screening 低于同 seed baseline。

部署时一行 pair 最终产生的是“activity score + rank + uncertainty + provenance”，而不是一个经过实验确认的 binder 概率。276,480 个 pair 全部评分后，按每个老药内部的 384 个靶点排序；真实未知关系仍需外部来源或 W1 湿实验确认。
