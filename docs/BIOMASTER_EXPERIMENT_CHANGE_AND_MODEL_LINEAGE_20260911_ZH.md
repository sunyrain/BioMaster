# 实验是否调整、A/B收敛及历史模型分歧的来源

2026-09-11。补充核对实际模型、训练记录、部署矩阵和原384分数来源。本次不重训、不修改已交付实验表；输出安排复核辅助表，供调整尚未开始的实验使用。

**建议调整执行批次与核查顺序，先处理已有具体问题，再决定替换哪些配对。目前不足以依据A/B排名整批换掉384。保存原384作为研究基线，只要求保存原名单和分数，不要求继续消耗全部384个实验名额。**

## 1. 必须分清三个“旧模型”概念

| 对象 | 实际训练或评分来源 | 在本项目中的作用 |
|---|---|---|
| 原384的历史神经分量 | 5个S5模型，每个训练65,276对；验证16,668对、测试2,556对 | 输出`biomaster_ensemble_logit`，作为原组合的一项 |
| 原384使用的完整初始评分 | 历史神经分数＋训练阳性近邻＋靶点训练先验 | `independent_validation_rank_score`决定原药内Top20；之后还有图谱、逐对审核与资源选择 |
| 2026-09-06选定的较新神经检查点 | 383,638对、362个监督靶点的full fit | 后来做新端点测试和矩阵补全时使用的旧生产神经模型；不是上一行的评分器 |

38万对训练的模型确实存在。**但原384不是直接由这个38万模型单独生成的。** 将不同版本都称作“旧模型”，会造成“同一个模型从30万扩展到百万以后突然推翻旧384”的错误印象。

实际来源链：

1. `biomaster_odti_routed_ranker_v1/S5_OLD_DRUG_ENTITY_COLD__fold_-1__seed_20260813..20260817__CORE/RUN_SUMMARY_V1.json`逐个确认训练65,276对。
2. `biomaster_odti_deployment_v1/BIOMASTER_ODTI_DEPLOYMENT_SUMMARY_V1.json`确认5个S5种子及训练/验证角色；部署CSV包含历史神经、近邻和先验原始列。
3. `scripts/build_biomaster_drug_centric_ranker_v1.py`读取该部署CSV，将`biomaster_ensemble_logit`作为`biomaster_logit`，应用旧验证集冻结的标准化与权重。
4. 原384的`binding_rank_384`来自这个结果，前轮已精确复现原最终选择。本轮再次从三个原始分量重构全部276,480个分数，与保存组合分数最大允许绝对误差1e-10内一致。

这些文件路径位于`outputs/old_drug_target_sota_v1/`。38万模型另有`outputs/biomaster_best_model_20260906/retargetmap_selected_v1/training_data.json`记录，不能互换。

## 2. 不改变数据，只拆原组合，排名已经会明显改变

固定同一720药×384靶点、原384配对、原行序和并列处理。在每个药物内重算排名，仅去掉或保留原评分分量：

| 使用原历史评分的哪些分量 | 原384中仍在Top20 | 排名中位数 |
|---|---:|---:|
| 历史S5神经分数单独 | 148 | 31 |
| 阳性化学近邻单独 | 231 | 13 |
| 历史神经＋阳性化学近邻 | 332 | 8 |
| 历史神经＋靶点先验 | 114 | 40 |
| 原完整组合 | 384 | 11 |

原组合使用验证集标准化后的权重：神经1、近邻2.5、靶点先验0.25。权重不是概率、解释度或贡献百分比，不能说近邻“贡献了2.5倍成功率”。

这个实验表明：即使完全没有九月新增数据，仅把历史组合改成其自身的纯神经评分，也会有236对跌出Top20。它证明排序对组合组成敏感；原384本来就是经完整组合挑出的，不能用其384/384或近邻高保留证明某个分量更准确。

该表只重算前端排名，没有声称重新运行整套最终选样或给出新的SPR命中率。不同分量有交互、候选又经原组合选择，不能把236与A/B的334/335直接相减，当作各因素的因果归因比例。

## 3. A/B是否已经收敛

**目前没有证据证明两者已经收敛。能够确认的是：两组完成了预定的固定计算预算，所有训练行都被使用过。**

| 项目 | A | B |
|---|---:|---:|
| 实际训练配对 | 337,570 | 1,116,270 |
| 优化步数 | 6,000 | 6,000 |
| 每种子累计样本曝光 | 6,144,000 | 6,144,000 |
| 等效完整遍历次数 | 18.20 | 5.50 |
| 第4501–5000步训练损失，三种子均值 | 约0.0296 | 约0.1277 |
| 第5501–6000步训练损失，三种子均值 | 约0.0219 | 约0.1094 |
| 训练中的逐检查点验证 | 未执行 | 未执行 |
| 停止与输出 | 固定6000步的最终EMA | 固定6000步的最终EMA |

训练脚本每500步记录训练损失，但仅在循环结束后评分共同验证集、拟合校准和阈值。没有验证AP/P@K曲线，也没有基于验证平台期的早停。因此不能证明已经充分训练，也不能由训练损失下降证明继续训练会提高泛化；A可能继续拟合而不再改善验证，B也可能同时受端点混合或其他因素限制。

这六次实验应称为“固定预算的A/B初步对照”，不是“两个方案各自充分优化后谁更强”的终局比较。后续收敛检查需要固定数据与目标，记录多个训练检查点的验证指标，预先指定检查点选择规则并报告所有种子。测试集不能用来选轮次。

历史S5五模型曾按验证表现选择最佳epoch（20/18/18/11/15），分别在28/26/26/19/23轮结束；其训练目标包含靶点类别平衡BCE、靶点内排序0.12和pChEMBL Huber辅助0.06。A/B为共同架构从头训练、冻结编码器、实测标签类别平衡BCE，并对两路输出使用相同标签；数据与目标均与这条历史路线不同。

## 4. DTIAM、ConPLex、DrugCLIP各自是什么状态

### DTIAM

目前矩阵中DTIAM分数来自`DTIAM_OFFICIAL_REPRESENTATION_COMPATIBLE_RETRAIN_S5`：

- 训练65,276对，其中35,684阳性、29,592阴性；48,057个化合物、423个靶点。
- 官方BerMol与ESM2冻结表示，11个基学习器＋WeightedEnsemble；本地AutoGluon 1.4.0兼容复训，非原论文0.5.2环境逐位复现。
- RUN_SUMMARY记录`time_limit_seconds=null`，完成了约1609秒的拟合，不能描述成设置了短时限而被迫停止。
- 这条用于720×384矩阵的路线没有用九月A/B数据重新训练。项目也有其他DTIAM时间/分割对照，不能将该65,276推广为每次DTIAM实验的样本量。

它的数据覆盖明显小于新A/B，**值得用相同A/B数据和共同划分重训对照**；但是没有DTIAM自身的学习曲线或同条件数据扩张消融，不能断言旧分歧完全因为DTIAM数据不足。BerMol预训练与下游65,276对监督是不同层次。方法定义和官方资源见[DTIAM论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11910601/)与[官方实现](https://github.com/CSUBioGroup/DTIAM)。

### ConPLex

本地严格338靶点及恢复46靶点推理脚本都调用`third_party/ConPLex/models/BindingDB_ExperimentalValidModel.pt`。本地下载模块将该文件对应到官方`ConPLex_v1_BindingDB`资源；这是公开BindingDB权重推理的路线，没有在当前九月数据上重训该评分器。项目存在其分数校准/融合，不等于更新了它的神经权重。

公开项目同时提供预训练推理和重新训练入口，见[ConPLex官方说明](https://github.com/samsledje/ConPLex)。本轮核实了运行脚本与资源映射，未重新下载官方权重认证字节一致性，也未审计该公开权重全部训练成员。不能把其原始数据量、我们的38万模型和新A/B当成同条件训练。

### DrugCLIP

本地比较使用既有公开六折的药物—口袋检索余弦分数；完整核心矩阵中按精确SMILES和序列可比映射覆盖548药×269靶点。本次没有用新BindingDB重新训练这条完整检索路线。

DrugCLIP依靠药物—口袋表示对齐，不能把其结构配对数据量与标量亲和标签行数直接比较。官方2023训练资源含PDBbind与HomoAug，后续公开项目另提供权重与推理资源：[DrugCLIP原实现](https://github.com/bowen-gao/DrugCLIP)、[Drug-The-Whole-Genome](https://github.com/THU-ATOM/Drug-The-Whole-Genome)。将BindingDB用于这类适配还需处理靶点—口袋映射与输入可靠性，不是把百万条SMILES＋序列直接等同于百万条可信口袋监督。

尤其要区分：**旧38万神经模型和A/B借用了DrugCLIP的冻结分子特征，蛋白侧用ESM2；它们没有直接复用完整DrugCLIP药物—口袋打分函数。** 因此共享特征不要求最终排名一致，多模型同意也不代表独立实验重复。

## 5. 分歧为何这么大：已知差异和待验证原因

已知同时改变的因素包括：历史评分版本、是否加入近邻/先验、训练数据成员、靶点范围、端点混合及正负组成、排序/辅助目标、训练预算和种子集成方式。当前A/B不是在原组合模型上只追加新数据继续训练。

其中，原评分组成的敏感性已经由本轮拆分直接演示；A/B的收敛状态缺少必要验证记录；端点混合、预算、排序目标各自贡献多大仍需受控消融。没有证据能把总分歧归因为单独的“原30万不够”或“新百万更正确”。

前轮相关靶点分层提供积极证据：排除旧模型见过的配对后，在本轮112靶点中满足测试条件的31个靶点上，旧神经/A/B的靶点内AP为0.804/0.890/0.891，P@5为73.55%/85.16%/85.38%。这是事后子集、主要使用其他已测药物，不是证明原384有85%的命中率，也尚未包含原历史组合在新面板上的完整公平对照。

## 6. 现在如何调整尚未开始的实验

原实验表的既有审核状态是223对“仍可探索”、149对“先解决具体问题”、12对“有证据支持降低投入”。“仍可探索”不等于高置信或已经测通；其他两类也不是统一的不可结合标签。

建议按下面的执行判断处理，而非根据A/B排名一刀切换出：

1. **先核12个降低投入项的原始依据。** 有些涉及弱活性或选择性，有些只涉及疾病用途解释；只在证据与本次分子、蛋白构建、浓度和研究目标匹配时决定后置或替换。疾病转化理由不足不能直接判SPR结合阴性。
2. **149个条件项逐项分清。** 身份、构建、溶解度或测定背景等操作前提需要实际确认；仅缺文献或支持来自近邻属于证据问题，不能自动变成实验禁令。既有LLM意见也需要核验，不能当成实验完成记录。
3. **223个探索项中，有52个至少被A/B之一排进原药内Top20。** 其中12个A/B均支持、23个仅A、17个仅B。它们可以作为优先核对靶点是否测通的候选组，但不是直接确认的首批。原17个双模型支持项里另有5个属于条件项，不能因共识越过其问题。
4. **分批使用资源，并保留分歧组的代表。** 其余171个探索项没有A/B Top20支持，仍可能有原组合和疾病证据。先基于已测通靶点、原证据和实验目标安排一批，再决定剩余部分；不必为了“基线”做完所有384，也不必为了凑新384而放入未审核的新配对。
5. **替换需要同靶点、同成本下的明确增益依据。** 当前A/B新池多数尚缺逐对审核；候选通过分数门槛不等于能直接替换。先完成共同数据的评分对照与候选核查，再形成具体替换表。

本轮提供`SPR384_SCHEDULING_REVIEW_AID.csv`，保留原排序、审核事项、A/B排名和安排复核建议；它不是新的实验发布表，也没有自动修改网站或通知实验人员。用户确认实验仍可调整，因此“先前已交付”不构成保持未来安排不动的理由。

## 7. 后续模型比较的优先顺序

最优先是A/B的验证学习曲线、DTIAM在同数据上的重训对照，以及原完整评分器与新模型的同条件评价。随后才检验端点分开的多任务、实测正负排序损失和训练内化学近邻组合。每次固定其他因素，保存所有种子，按实际取样深度比较P@K及阴性误报；对已经反复查看的测试结果保持事后诊断口径，并另留新的确认数据。

ConPLex先核对官方路线在共同面板上的表现和输入覆盖，再决定项目适配；DrugCLIP先保证口袋映射与有效对照，再比较其完整检索结果。不要把多个未经共同训练、共同评估的模型当作等权投票裁判。
