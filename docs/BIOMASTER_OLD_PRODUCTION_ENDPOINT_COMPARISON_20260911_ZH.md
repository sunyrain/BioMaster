# 旧生产模型在当前端点测试集上的直接对照

日期：2026-09-11。已完成旧生产检查点评分，没有重训或替换生产模型，也没有修改已交付的 SPR384 实验表。

**结论：当前 Kd/Ki 测试集上，新 A（Kd/Ki＋明确失活）的整体 AUROC、AP 高于旧生产模型；即使保留旧模型监督训练见过的配对，结论仍成立。新 B（全端点＋明确失活）在 IC50、EC50 和全端点联合测试中表现最好。** 这是本次回顾性测试的实测比较，不等于所有应用场景都优于旧模型。

## 评分方法

- 旧模型：`outputs/biomaster_best_model_20260906/retargetmap_selected_v1/model.pt`，严格加载原始权重。
- 复用上一轮相同特征、测试配对、标签和顺序；两路输出 logit 取平均，使用相同 bf16 推理方式。
- A、B 复用已冻结的六次训练预测，各自报告三个种子的指标均值；旧模型为实际部署的一个检查点，没有伪造重复种子。
- 主指标 AUROC、AP 直接从原始分数计算。阈值指标另在共同 Kd/Ki 验证集上拟合 Platt 校准并选最大 F1 阈值，不使用测试标签调参。该验证集有 7,592 对旧训练见过的配对，阈值结果仅作辅助，不是旧模型原部署概率或前瞻误报率。
- “旧训练见过”按旧监督训练中的分子连接结构＋完全一致的蛋白序列判定；不代表精确立体化学一致。未见配对不等于未见分子、骨架、靶点或文献。

## 全部当前测试配对：不排除旧模型已见关系

各格为 **AUROC / AP**。面板存在配对重叠，不能相加计算独立样本量。

| 测试面板 | 配对数 | 旧生产模型 | A：Kd/Ki＋失活 | B：全端点＋失活 |
|---|---:|---:|---:|---:|
| Kd/Ki | 34,327 | 0.7914 / 0.8885 | **0.8874 / 0.9357** | 0.8494 / 0.9087 |
| IC50 | 85,704 | 0.7842 / 0.9171 | 0.6919 / 0.8592 | **0.9465 / 0.9805** |

| 全端点联合 | 132,331 | 0.7998 / 0.9014 | 0.7423 / 0.8568 | **0.9163 / 0.9580** |

Kd/Ki 主测试中，A 相比旧模型 AUROC 增加 **0.0959**，AP 增加 **0.0472**；A 的三个种子均高于旧模型。B 的三个种子也均高于旧模型，但低于 A。

## 旧训练曝光分层：Kd/Ki

| 配对范围 | 配对数（阳性 / 阴性） | 旧模型 AUROC / AP | A AUROC / AP | B AUROC / AP |
|---|---:|---:|---:|---:|
| 旧训练已见 | 6,888（5,116 / 1,772） | **0.9950 / 0.9977** | 0.8728 / 0.9451 | 0.8395 / 0.9272 |
| 旧训练未见 | 27,439（18,074 / 9,365） | 0.7206 / 0.8228 | **0.8893 / 0.9327** | 0.8499 / 0.9026 |

已见关系上旧模型近乎完美，未见关系上成绩明显降低。因此，旧模型对已见关系的强表现确实抬高了完整测试集成绩。即便如此，其整体区分能力仍低于新 A。不能仅凭这个分层把所有差异归因于记忆：两组的靶点、化学空间与标签分布也不同。

旧模型单独第 0 / 第 1 路输出在完整 Kd/Ki 上分别为 AUROC 0.7919 / 0.7905、AP 0.8886 / 0.8877；切换单路输出没有逆转整体结论。这里仍是汇总配对评价，不是逐查询的全目录双向检索评价。

A 的主优势是整体区分能力，以及未见关系的较宽排序前列；不能宣称每一个截断点都显著更好。尤其未见关系前 1% 的差异很小。本次没有新增置信区间或独立确认集，这些差值为观察值。

这些精确率是在已测、有标签且阳性比例较高的测试池内计算。不能解释为 720×890 所有未知配对或 SPR384 的实验命中率。

## 明确失活标签与使用建议

10,649 对明确失活测试在各模型共同验证策略选定阈值下，误报率旧模型 **49.47%**、A **43.75%**、B **47.13%**。这三个阈值各自按 Kd/Ki 验证 F1 选择，并非固定同一召回率；不能用此结果单独宣称失活识别全面改善。失活面板 Brier 旧模型 0.1900、A 0.3174、B 0.2986，旧模型反而更低；概率校准和选择阈值仍需关注。

针对直接结合/SPR研究，现有证据支持把 A 作为更值得继续验证的候选模型；活性端点任务继续保留 B。旧生产模型在已知关系和完整测试最前列仍有优势，应保留作基线。当前证据已不再是“没有旧模型对照”，但仍不构成前瞻湿实验命中率或全面部署替换的证明。
